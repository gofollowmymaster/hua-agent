## ADDED Requirements

### Requirement: 按租户提供 DS 订单 Mock 查询
系统 SHALL 在当前租户内提供订单分页、详情和日志查询，并保持不同租户的内存状态相互隔离。

#### Scenario: 组合筛选订单
- **WHEN** 当前租户按状态、平台和时间范围分页查询订单
- **THEN** 仅返回同时满足条件的当前租户订单和正确分页总数

#### Scenario: 查询其他租户状态
- **WHEN** 两个租户先后访问或修改相同 Mock 订单号
- **THEN** 每个租户看到各自独立的数据副本

### Requirement: 模拟审核和取消状态流转
系统 SHALL 校验订单当前状态后执行审核或取消，并为成功操作追加日志。

#### Scenario: 审核待审核订单
- **WHEN** 待审核订单审核通过或驳回
- **THEN** 状态分别变为处理中或已驳回，且详情和日志立即反映变更

#### Scenario: 审核取消申请
- **WHEN** 取消待审核订单通过或驳回
- **THEN** 状态分别变为已取消或恢复取消前状态

#### Scenario: 非法状态操作
- **WHEN** 对不允许审核或取消的状态执行写操作
- **THEN** 返回明确业务错误且不改变订单和日志
