POA列表

## 功能介绍

当亚马逊平台因客户投诉等原因，向卖家发出要求提交**行动计划**的邮件时，相关产品的ASIN可能会受到销售限制。为解除限制，供应商需配合服务商完成行动计划申诉流程。

## 注意事项.

1. 收到POA消息后，需要3个工作日内完成上传。
2. 上传的文件大小总和，尽量保持在10兆以内。所有附件总和超过10兆，会被亚马逊退回。

## 操作步骤

1. 当有需要处理的POA数据时，系统会发送一条POA消息。可以在站内信中查看。
2. 收到消息后，可至【商品】-【行动计划】-【POA列表】中查看对应的数据。

![图片展示的是亚马逊POA列表页面。页面上方有搜索栏及筛选条件，如ASIN、商品平台、Office状态等。列表中显示了多个POA行动计划，包括ASIN、商品平台、Office状态、截止日期、创建时间、更新时间、处理状态等信息，如ASIN为B08M2QH34P7的行动计划，状态为已上传，处理状态为已上传，更新时间为2025 - 12 - 26 16:48:09。该图与上下文介绍的收到消息后可查看POA列表的内容相契合，直观呈现了POA列表页面样式及信息展示情况。](./assets/images/图片展示的是亚马逊POA列表页面-3826ec4f932e.png)

1. 状态说明：

 1. 未开始：服务商已接收到亚马逊关于指定ASIN的合规审查邮件（行动计划要求），但运营经理尚未开始处理分发。
 2. 待上传：运营经理已分析邮件内容，并将具体的整改要求与文件清单正式下达给对应的供应商，等待供应商上传所需材料。
 3. 已上传：供应商已按要求将行动计划上传至系统。此时材料处于就绪状态，等待运营经理审核并向亚马逊提交申诉
 4. 已结束：申诉流程完结。此状态为最终状态，涵盖两种结果：**申诉成功**（ASIN限制已解除）或**申诉失败**（根据既定策略，流程关闭）。
2. 点击上传按钮，可查看运营经理分发的整改要求，在右侧POA回复中，填写回复内容并上传行动计划文件，点击确定后，则交给运营经理审核并提交给亚马逊。

![图片展示的是POA列表中“已结束”状态下的申诉流程界面。左侧显示AON、Offer状态、反馈状态及POA证明等信息。右侧为POA回复区域，有“填写POA回复”输入框，下方有“上传文件”按钮，支持上传100MB以内的文件，支持的文件类型为全部类型。该界面与上下文介绍的已结束状态下的申诉流程相关，用户可在此填写回复内容并上传行动计划文件，提交给运营经理审核。](./assets/images/图片展示的是POA列表中“已结束”状态下-415ff2122a1d.png)

1. 点击详情按钮，可查看运营经理分发的整改要求，已经供应商回复内容和上传的附件。

![图片展示的是POA行动计划界面。界面显示行动计划ID、ASIN、企业环境、违反政策、要求时间、截止日期、更新人、创建时间等信息。其中，ASIN、企业环境、违反政策、截止日期、更新人、创建时间等信息被红色框线突出显示。界面底部有“查看数据”和“查看数据”按钮。该图片与上下文介绍的POA行动计划相关，直观呈现了行动计划的详细信息。](./assets/images/图片展示的是POA行动计划界面-2ecff25d46a5.png)

1. 上传结束后，最快5个工作日内得到反馈。可根据“处理状态”和“Offer状态”查看处理结果。
