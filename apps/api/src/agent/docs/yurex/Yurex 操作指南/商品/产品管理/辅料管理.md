# 飞书文档：辅料管理

辅料管理

## 功能介绍

辅料管理：该模块主要是维护一些包装材料或宣传资料等产品信息，便于出入库，库存管理

## 页面路径

【商品】-【产品管理】-【辅料管理】

## 注意事项

1. 新增产品资料时，请如实填写产品资料；
2. 请注意产品条码的输入规则；

## 操作指南

### 查看辅料列表

1. 功能描述：展示所有已新增的辅料列表信息
2. 产品状态说明：

 1. 草稿：新增时将产品数据保存为草稿，还未提交
 2. 待审核：提交了产品数据，等待客服审核
 3. 已生效：客服审核通过
 4. 驳回：客服审核驳回

### 编辑

1. 功能描述：产品状态为 “草稿、已生效、已驳回” 时，可编辑辅料信息说明：使用平台仓的产品状态为 “已生效” 时，需等待平台仓返回审核结果，才可编辑

 - 产品状态为 “草稿、已驳回” 时，所有字段均可编辑；编辑后提交，产品状态为 “待审核”
 - 产品状态为 “已生效” 时，仅可编辑部分字段，置灰字段不可修改；编辑后提交，产品状态不变
2. 操作步骤：

 1. 选择需编辑的产品信息，点击【编辑】按钮

 ![辅料管理界面，左侧为功能导航栏，右侧是辅料列表。列表右侧有“详情”“编辑”“更多”操作按钮，其中“更多”按钮旁有红色框突出显示。](./assets/images/图片展示的是辅料管理界面-c7e8a56e7577.png)

## 常见问题

### 为什么提交后不能继续编辑？

若您刚提交数据，状态为审核中，请不要着急，这时不能编辑，需等待我司审核后才能进行下一步操作，我司将尽快审核；
