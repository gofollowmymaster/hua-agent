# 飞书文档：货品管理


## 功能介绍

货品列表：该模块主要是支撑一些多包裹商品，录入相关的包裹产品信息，进行出入库，库存管理；多包裹商品必须先录入货品信息才可添加

## 页面路径

【商品】-【产品管理】-【货品管理】

## 注意事项

1. 新增产品资料时，请如实填写产品资料；
2. 请注意产品条码的输入规则；

## 操作指南

### 查看货品列表

1. 功能描述：展示所有已新增的货品列表信息
2. 产品状态说明：

 1. 草稿：新增时将产品数据保存为草稿，还未提交
 2. 待审核：提交了产品数据，等待客服审核
 3. 已生效：客服审核通过
 4. 驳回：客服审核驳回

![YUREX平台货品管理中查看货品列表的界面。右侧上方有搜索、筛选、导出等操作按钮。](./assets/images/图片展示的是YUREX平台货品管理中查看-21a2d3946269.png)

1. 功能描述：手工新增货品信息
2. 操作步骤：说明：支持货品信息必填字段未填写完整时，点击【存为草稿】，退出新增页面

 1. 下载Excel导入模版至本地，将货品信息填入模版中，点击保存

 ![“平台仓附加信息”为必填项，用于区分平台仓货品。“平台仓附加信息”处有红色框突出显示，其下方有“是”“否”选项，且“是”选项被红色框包围。](./assets/images/图片展示-addCriterion-ad-a1b0e34f35bd.png)

 1. 返回批量上传弹窗，点击【上传文件】，选择保存好的Excel 文档

 ![YUREX系统中货品管理页面。产品状态为“待审核”的货品被红色框突出显示。](./assets/images/图片展示的是YUREX系统中货品管理页面-11ca5acd65a6.png)

### 编辑

1. 功能描述：产品状态为 “草稿、已生效、已驳回” 时，可编辑货品产品信息说明：使用平台仓的产品状态为 “已生效” 时，需等待平台仓返回审核结果，才可编辑

 - 产品状态为 “草稿、已驳回” 时，所有字段均可编辑；编辑后提交，产品状态为 “待审核”
 - 产品状态为 “已生效” 时，仅可编辑部分字段，置灰字段不可修改；编辑后提交，产品状态不变
2. 操作步骤：

 1. 选择需编辑的产品信息，点击【编辑】按钮

 ![货品管理界面。红框标注“已生效”、“已驳回”。](./assets/images/图片展示的是货品管理界面-cd937b4c270d.png)

 1. 进入编辑产品页面，修改完毕相关信息后，点击【提交】按钮，页面字段相应更新

 ![货品管理中编辑产品页面。页面右上角有“取消”和“提交”按钮，其中“提交”按钮被红色框突出显示。](./assets/images/图片展示的是货品管理中编辑产品页面-e7e9b6ce4189.png)

 ![货品管理中删除操作的二次确认弹窗。弹窗右侧有“取消”和“确定”两个按钮，其中“确定”按钮被红色框线突出显示。](./assets/images/图片展示的是货品管理中删除操作的二次确认-611ec1e64e01.png)

## 常见问题

### 为什么提交后不能继续编辑？

若您刚提交数据，状态为审核中，请不要着急，这时不能编辑，需等待我司审核后才能进行下一步操作，我司将尽快审核；
