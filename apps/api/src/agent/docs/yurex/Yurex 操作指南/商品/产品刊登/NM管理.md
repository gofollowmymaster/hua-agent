# 飞书文档：NM管理


## 功能介绍

1. Newer Model属于关联流量的一种，卖家可以在原始SKU的Listing详细页面中设置Newer Model，并在旧SKU页面下显示新产品的链接，以方便新SKU的流量转换。

## 注意事项

1. 若您的产品需要Newer Model，此模块为您提供了Newer Model文件模版，您只需填充文件后进行上传即可。
2. 上传Newer Model文件时请注意：

 1. 必须先下载指定的Newer Model模版文件，然后填充该文件，并将文件名改为“Newer_version_template”后再上传；
 2. 文件格式要求：.xlsx .xls，文件大小不超过3Mb，一次仅支持上传单个文件；
3. 填写产品ASIN时，需与模版文件中的ASIN保持一致。
4. 当您上传Newer Model文件后，我们将进行审核，检查您上传的产品是否符合Amazon规范。若收到“审核通过”，意味着Newer Model申请成功；若收到“审核失败”的提示，请根据提示内容重新修改内容后再次上传。
5. 若您不清楚Newer Model要求，可点击“帮助文档”查看Newer Model要求与规则。
6. Amazon审核Newer Model需要一定的时间，请耐心等待。
7. 考虑到兼容性，请使用谷歌浏览器。

> 进入上传Newer Model页面

### 点击【下载模版】

> 根据表头填写产品信息

![“上传Newer Model”页面。页面中部有“点击或拖动文件按钮”区域，提示可上传CSV、XLSX文件。](./assets/images/图片展示的是“上传Newer-Model-aac061f1b978.png)

### 文件上传

> 点击或将文件拖动至文件上传区域

![在上传Newer Model操作中上传文件的界面。画面中有一个红色框突出显示的区域，内有“点击或拖动文件到此区域上传”的提示文字，下方还有“点击或拖动文件到此区域上传”字样。](./assets/images/图片展示了在上传Newer-Model操-fd84bd7280a5.png)

### 填写产品ASIN

> 为了让您在Newer Model列表页能更快捷地查询到已上传Newer Model的ASIN，请在该步输入上传文件中的所有ASIN。
>
> 提交成功后，您可在列表页通过搜索ASIN查询到历史上传文件以及审核状态等。

![NM管理中上传Newer Model的页面。](./assets/images/图片展示了NM管理中上传Newer-Mo-4ad714f98ab1.png)

### 点击【提交】

> 提交成功后将直接跳转至Newer Model列表页，并自动生成该条申请。

![上传Newer Model的页面。右上角有一个明显偏亮且被红框突出显示的“提交”按钮。](./assets/images/图片展示的是上传Newer-Model的-ccaf178e59cd.png)

### 点击【更多】

> 可查看上传时输入的所有产品ASIN。

![在NM管理中上传Newer Model后的操作界面。箭头标注“审核中”。](./assets/images/图片展示的是在NM管理中上传Newer-a37de6835f4c.png)

### 点击【下载文件】

> 可通过【下载文件】查看历史上传文件。

![NM管理界面中 ， 上传Newer Model操作路径下的“点击【下载文件】”内容。画面中“操作”列下有“下载文件”按钮，箭头指向该按钮，提示可通过点击此。](./assets/images/图片展示了NM管理界面中-5fea17992ffb.png)

### 运营审核中

当此条数据状态变为【运营审核中】时，表示您的Newer Model已提交成功，并已提交至管理端。

![亚马逊平台Newer Model管理界面。中间区域显示Newer Model列表，包含申请编号、ASIN、数据提交时间、产品负责人、联系人、状态、操作等列。](./assets/images/图片展示的是亚马逊平台Newer-Mod-817ba582c722.png)

### 审核通过

当此条数据状态变为【审核通过】时，表示您的Newer Model产品已经审核通过。

![NM管理中上传Newer Model的操作界面。界面中列出了相关数据信息，其中一条数据的“状态”列以红色框突出显示为“运营审核中”。](./assets/images/图片展示的是NM管理中上传Newer-M-67cccc5d0847.png)

### 审核失败

当此条数据状态变为【审核失败】时，表示您Newer Model在Amazon审核失败。

> 若审核失败，您可以根据反馈的失败原因修改产品Newer Model信息重新提交。
>
> 也可点击“帮助文档”，查Newer Model要求。

![Newer Model管理端界面。状态栏有“审核失败”标识，操作栏有箭头指向“重新 失败”字样。](./assets/images/图片展示的是Newer-Model管理端-be173962d6e9.png)
