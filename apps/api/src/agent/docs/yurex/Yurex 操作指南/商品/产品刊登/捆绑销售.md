# 飞书文档：捆绑销售


## 功能介绍

Virtual Bundle（捆绑销售）允许您将多个ASIN的商品组合成一个新的虚拟ASIN进行销售，通过捆绑销售功能，您可以灵活组合商品，通过热销商品带动冗余库存或新品销售，提升销量。

## 注意事项.

1. 您提交申请后，亚马逊审核需3-5个工作日，请您耐心等待；
2. 审核失败的申请，您可以重新再次发次申请；
3. 填写模板时，请您注意，带有“REQUIRED”字段为必填项，否则上传会提示您失败；
4. 考虑到兼容性，请使用谷歌浏览器。

## 操作步骤

### 申请Virtual Bundle

#### 菜单路径【商品】-【产品刊登】-【捆绑销售】

![在“商品”分类下“捆绑销售”功能的界面。左侧导航栏中，“商品”分类被红色框突出显示，其下“捆绑销售”功能也被红色框标注。](./assets/images/图片展示了在“商品”分类下“捆绑销售”功-d104b6bf138d.png)

#### 申请 Virtual Bundle

点击【申请Virtual Bundle】，获取Bundle模板，模板保存至本地，填写完成后上传，上传模板后需再次点击右上角【提交】按钮

![亚马逊平台捆绑销售申请界面。“申请Virtual Bundle”按钮被红色箭头突出显示，与上下文介绍的申请Virtual Bundle操作步骤相关，对应点击该按钮获取Bundle模板。](./assets/images/图片展示的是亚马逊平台捆绑销售申请界面-5d49efb24d8b.png)

![上传Virtual Bundle的操作界面。界面右上角有“新建”按钮。](./assets/images/图片展示的是上传Virtual-Bund-de799ed2e9bb.png)

#### 查看申请

提交完成后，列表会生成对应的数据，您可以查看您提交的申请

![在商品管理中捆绑销售的申请页面。页面上方有搜索栏及筛选条件，下方是申请列表，显示了申请编码、Base ASIN、Component ASIN、Virtual ASIN、产品负责人、审核人、申请。](./assets/images/图片展示的是在商品管理中捆绑销售的申请页-7da92c769680.png)

#### 上传模板报错处理

##### 模板不符合要求

模板不符合要求，不是我们提供您的模板，请您【下载Virtual Bundle】模板完成填写后再次上传

![捆绑销售操作步骤中上传模板报错处理的界面。](./assets/images/图片展示的是捆绑销售操作步骤中上传模板报-d7d0e1c7b4a3.png)

##### 必填项缺失

必填项未填写，会有此报错，您需检查您模板中，带有“REQUIRED”字段的内容，按照要求输入，再重新提交

![在执行捆绑销售的“上传模板”操作时出现的报错提示界面。画面中间有一个红框圈起的提示框，提示框左上角有红色警示图标，内有“错误提示”字样，具体内容为模板不符合要求。](./assets/images/图片展示的是在执行捆绑销售的“上传模板”-e11794fc1cde.png)
