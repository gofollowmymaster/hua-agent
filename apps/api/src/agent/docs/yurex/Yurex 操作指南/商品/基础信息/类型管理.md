类型管理

## 功能介绍

新增产品类型选项，用于新增商品数据时使用

## 页面路径

【商品】-【基础信息】-【类型管理】

## 注意事项

1. 新增产品类型时，请正确填写；

### 删除

1. 功能描述：删除产品类型说明：产品类型若被商品关联，不可删除；若未被商品关联，可删除
2. 操作步骤：

 1. 鼠标悬浮在【更多】上，点击【删除】按钮，二次弹窗点击【确定】
 2. 删除成功，产品类型从页面上移除

 # 常见问题

 ## 类型名称不能重复
