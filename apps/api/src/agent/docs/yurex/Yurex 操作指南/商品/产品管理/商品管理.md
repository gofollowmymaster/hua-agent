商品管理

## 功能介绍

商品列表：该模块主要是商品的基础数据录入，普通商品、组合商品、多包裹商品等，可同时录入报价数据，一起提交至系统进行审核

## 页面路径

【商品】-【产品管理】-【商品管理】

## 注意事项

1. 新增产品资料时，请如实填写产品资料；
2. 请注意产品条码的输入规则；

## 操作指南

### 查看商品列表

1. 功能描述：展示所有已新增的商品列表信息
2. 产品状态说明：

 1. 草稿：新增时将产品数据保存为草稿，还未提交
 2. 待审核：提交了产品数据，等待客服审核
 3. 已生效：客服审核通过
 4. 驳回：客服审核驳回
3. 报价状态说明：

 1. 未报价：新增时未填写采购报价信息
 2. 报价审核中：新增时已填写采购报价信息，等待客服审核
 3. 报价待确认：客服已审核通过报价，等待产品负责人确认
 4. 报价已生效：产品负责人确认报价后，报价信息生效
 5. 报价未通过：客服未审核通过报价
 6. 报价已拒绝：客服已审核通过报价，但产品负责人拒绝报价
4. 平台仓合规审核状态说明：

 1. 审核中：平台仓合规信息审核中
 2. 审核未通过：平台仓合规信息审核未通过，无法开展平台仓业务（无法在系统创建目的仓为平台仓的预约入库单及使用平台仓出库）
 3. 审核通过：平台仓合规信息审核通过，可开展平台仓业务
 4. 未完善信息：商品勾选使用平台仓，但是未填写平台仓附加信息，需及时完善平台仓附加信息

##### 新增多包裹商品

什么是多包裹商品？

商品体积过大时，无法用一个包裹发出，需要拆分成多个包裹。例如：桌子

需要拆分为二个包裹；

- 包裹1：组装桌子的零部件，桌面，不可单独销售

 - 桌面：是不可单独销售的；
- 包裹2：组装桌子的零部件，桌腿，不可单独销售
- 在本系统中包裹是否货品组成
