# 飞书文档：平台映射


## 功能介绍

平台映射：该模块主要是维护产品基础数据与其他渠道站点的数据关系映射、便于开展其他渠道业务；

## 页面路径

【商品】-【基础信息】-【平台映射】

## 注意事项

1. 新增平台映射时，请如实填写渠道商品编码

## 操作指南

### 查看平台映射列表

1. 功能描述：新增、禁用、启用平台映射

### 新增映射

1. 功能描述：手工新增平台映射数据
2. 操作步骤：

 1. 点击【新增映射】按钮

 ![“平台映射”页面。页面左侧有导航栏，中间上方有搜索栏，可按名称、型号、类别、品牌、渠道站点等条件搜索。](./assets/images/图片展示的是“平台映射”页面-d3660f8dd3bd.png)

 1. 进入新增页面，选择【商品名称、渠道站点】，输入【渠道商品编码】，点击【确定】按钮

 ![平台映射新增映射操作界面。弹窗中商品信息栏显示商品名称为零食柜，渠道站点为亚马逊-US，，渠道商品编码为1111。](./assets/images/图片展示的是平台映射新增映射操作界面-1eb5cefafb67.png)

 1. 提交成功，新增的平台映射数据状态默认为 “启用”

 ![“平台映射”页面，显示了商品信息列表。列表包含商品名称、品牌/型号、类别、渠道站点/渠道商品编码、创建人、创建时间、状态、操作等列。](./assets/images/图片展示的是“平台映射”页面-680119f83e50.png)

### 禁用

1. 功能描述：禁用 “启用” 状态的平台映射数据
2. 操作步骤：说明：禁用后不影响已使用该数据改映射的单据，但该映射数据将不能被新单据关联

 1. 选中需禁用的映射数据，点击【禁用】按钮，二次弹窗点击【确定】，状态更新为【禁用】

### 删除

1. 功能描述：删除平台映射数据说明：映射数据若被单据关联，不可删除；若未被单据关联，可删除
2. 操作步骤：

 1. 点击【删除】按钮，二次弹窗点击【确定】
 2. 删除成功，映射数据从页面上移除

 ![“平台映射”页面，可查看平台映射列表。页面上方有搜索、筛选、排序等操作按钮。](./assets/images/图片展示的是“平台映射”页面-f5e0b6b90101.png)

## 常见问题

### 渠道商品编码不能重复

若您已创建产品与渠道的映射关系，则再次创建其他产品与渠道的映射关系时，所录入的渠道商品编码，不能重复，如重复（则不能关联正常产品，影响业务）；
