类目管理

## 功能介绍

1. 供应商可在“类目管理”模块中对产品的类目进行增删改查；
2. 当您申请类目修改后，我们会对其进行审核，确认修改的类目符合Amazon的要求，若提示审核失败，请根据提示信息对产品类目进行修改后重新发起申请。
3. 通过对类目进行增删改的方式，既能确保商品能够准确归类，提升用户体验，还能重新获取新类目排名，以此获取更多的曝光度、点击率、以及Listing流量，从而提高转化率和销售额。

## 注意事项

1. 修改类目时请注意：

 1. 产品列表中生效成功的Offer可对类目进行修改、新增与删除。
 2. 原类目和新类目都只展示一级类目和最小类目。
 3. 新增类目时，若想保留1个原类目，需同时将原类目填入新类目中。
 4. 填写表单时，请分别填写一级类目和最小类目。
 5. 关于Node ID展示位置，在系统中有提示，可点击下载PDF文档查看。
2. 考虑到兼容性，请使用谷歌浏览器。

## 操作步骤

##

#### 操作路径

【商品】-【产品刊登】-【类目管理】

![亚马逊卖家中心“类目管理”页面。左侧导航栏中“类目管理”被红色框突出 出突出显示。](./assets/images/图片展示了亚马逊卖家中心“类目管理”页面-e37a90e5fbbc.png)

#### 点击【类目修改】

![亚马逊卖家平台中“类目管理”页面。页面左侧有导航栏，其中“类目管理”选项被红色框线突出显示。](./assets/images/图片展示的是亚马逊卖家平台中“类目管理”-342d50ad874e.png)

#### 填写【产品信息】、【原类目】、【新类目】

生效成功的Offer可以对类目进行增删改，ASIN可选择的范围也来源于生效成功的Offer；

Node ID可根据帮助文档内的提示去填写；

![商品类目管理界面，其中“类目修改”操作步骤中填写产品信息、原类目、新类目后的页面。画面中突出显示了“Node ID”输入框，提示输入类目名称对应的Node ID，且有“Node ID”和“类目名称”两个输入框。](./assets/images/图片展示的是商品类目管理界面-1a6540ff4ecc.png)

#### 选择完ASIN后，可填写【原类目】、【新类目】

最多可填写2个新类目；
