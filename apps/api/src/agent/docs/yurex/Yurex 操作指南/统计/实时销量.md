# 飞书文档：实时销量

实时销量

## 功能介绍

实时销量是统计产品在近三天内在亚马逊网站产生的销量和销售额数据的报表，实时销量数据来源于亚马逊VC【Report】-【Real time sales】报表中。

![实时销量页面，上方有“实时销量”标题及“实时销量”按钮，下方有“日度统计”“趋势图”“列表数据”“历史逐小时数据查询”四个部分。红色箭头指向“实时销量”按钮，与上下文“查看实时销量”操作流程中“日度统计”部分的内容对应，直观呈现了查看日度统计的操作入口。](./assets/images/图片展示了实时销量页面-616beac302d4.png)

## 注意事项

1. 实时销量报表数据目前每半小时更新一次。
2. 实时销量中的销量和销售额数据是终端用户在亚马逊网站上下单产生的销售数据，不跟业务类型的订单挂钩。

## 操作流程

##

1. 实时销量页面主要由三部分数据组成：**日度统计、趋势图、列表数据、历史逐小时数据查询**
2. **日度统计**注：当日数据仅统计了0点到最新更新一小时的汇总，前两日数据统计了0点到23点完整的销售数据。

 ![实时销量页面的日度统计部分。页面右上角有红色箭头指向“最近更新时间”，显示为2025年12月25日04:00:00（UTC+8）。](./assets/images/图片展示了实时销量页面的日度统计部分-38a9211deba7.png)

 1. 分为今日、昨日、前日三种卡片，统计已配置的产品当日产生的销量和销售额总和，以及环比值。
3. **趋势图**

 ![实时销量页面中的趋势图。](./assets/images/图片展示的是实时销量页面中的趋势图-16399c494564.png)

 1. 根据近三天每小时的的销量横向对比，目的是帮助识别销量高峰和低谷时段，通过对比不同日期的同一时段销量，分析是否存在规律性波动，如工作日与周末的差异。
 2. 可控制折线图隐藏或展开。

 ![实时销量功能中按产品维度的列表数据界面。有一条红色箭头指向“隐藏图表”按钮。](./assets/images/图片展示的是实时销量功能中按产品维度的列-740917c19024.png)
4. **列表数据**

 1. 提供两种维度的列表查看维度，进入默认选中【按产品】展示数据，可手动切换为【按品牌】展示数据。

 ![实时销量中按产品、按品牌、历史逐小时数据查询三种维度的选项。按产品和按品牌选项被红色框突出显示，按产品选项对应“按产品”文字，按品牌选项对应“按品牌”文字。](./assets/images/图片展示了实时销量中按产品-edafd08e9994.png)

 1. **按产品**

 1. 一条数据对应一个产品，产品不区分业务类型。

 ![实时销量功能中按品牌查询的数据界面。表格中包含产品信息、品牌、产品负责人、每小时趋势、总计等列。](./assets/images/图片展示了实时销量功能中按品牌查询的数据-dd37048f50ff.png)
 2. **按品牌**

 1. 一条数据对应一个品牌，仅汇总已配置的产品去重后的品牌数据。

 ![实时销量功能中按品牌数据统计界面。界面分为三部分，左侧显示今日数据，销量72，销售额852.00美元；中间显示昨日数据，销量22，销售额250.00美元；右侧显示前日数据，销量0。](./assets/images/图片展示的是实时销量功能中按品牌数据统计-ce9f46641ec2.png)
 3. **历史逐小时数据查询**

 1. 可以查询实时销量记录的历史逐小时的数据集合。由于是快照数据，所以【历史逐小时数据查询】可能存在缺失和误差，如需历史逐日准确销售情况请前往【销量报表】

 ![实时销量功能中按品牌查询数据的界面。下方按时间顺序列出2023年12月24日10:00 - 23:00的实时销量数据，如10:00 - 10:05销量为0.00。](./assets/images/图片展示了实时销量功能中按品牌查询数据的-6d94fb56837b.png)
 4. **时间范围定义**：数据展示的时间范围包括两部分：

 - **当天**：从0点开始到最新一小时的数据（即当天已过时间段）。

 ![实时销量功能中“今日合计”数据的界面。下方红色框突出显示“今日合计”数据为72。](./assets/images/图片展示了实时销量功能中“今日合计”数据-bc3a1f5c5b9b.png)

 - **前两天**：完整的48小时数据（即前两天的0点到24点）。

 ![“昨日销量”数据，时间范围为00:00 - 23:00。数据以橙色背景突出显示。](./assets/images/图片展示的是“昨日销量”数据-f1722a370970.png)

 ![实时销量功能中历史逐小时数据查询的界面。上方显示“前日销量”，下方按小时从23:00到00:00排列，各小时销量均为0。](./assets/images/图片展示的是实时销量功能中历史逐小时数据-14bca7f3f4ac.png)

## 常见问题

##

答：亚马逊数据每小时更新一次；系统每隔半小时请求一次亚马逊的数据。

##

答：亚马逊没有给出对于实时销量统计的准确定义，目前已知的是实时销量包含了PO和DF销量，并且包含了退货数量的，这也是其中有些数据表现为负数的原因。
