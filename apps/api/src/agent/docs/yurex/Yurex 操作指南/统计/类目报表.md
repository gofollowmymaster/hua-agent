类目报表

## 功能介绍

1. 此报表展示了每个ASIN下所属的产品类目、产品上线时间、亚马逊提供的补货类别；
2. 同步亚马逊更新日期，每日定时拉取；

![图片展示了亚马逊卖家中心中“类目报表”的页面。页面左上角有“类目报表”标题，左下角有“统计”图标。页面上方有搜索栏及多个筛选条件，如全部、SKU、品牌、产品负责人、产品类目、补货类别等。页面中部显示产品信息，包括产品名称、ASIN、产品负责人、品牌、产品类目、产品上线时间、补货类别等。该图片与文档中“操作流程”部分对应，直观呈现了进入“类目报表”页面的操作路径及页面布局。](./assets/images/图片展示了亚马逊卖家中心中“类目报表”的-dd5737374e14.png)

## 注意事项

1. 仅显示ASIN的最新更新的数据，没有历史情况的查询；
2. 产品上线时间取用的是，商品->Catalog中，多个offer中最早的创建时间，作为该产品的上线时间；

## 操作流程

### 页面路径

1. 统计->销售分析->类目报表
