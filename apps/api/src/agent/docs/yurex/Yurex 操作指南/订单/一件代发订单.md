# 飞书文档：一件代发订单

一件代发订单

## 功能介绍

一件代发（Drop Shipping）订单是指卖家将散件商品存储在海外仓，由卖家负责订单处理、仓储、打包、配送、客服及退换货等全流程服务的订单模式。

注：仅当使用”平台仓“发货至买家时，创建一件代发订单

## 页面路径

【订单】-【渠道订单】-【一件代发订单】

## 系统流程

## 操作指南

### 一件代发订单列表

1. 功能描述：展示您所有的一件代发订单信息
2. 订单状态：

 1. 草稿：订单已创建未提交
 2. 待审核：客户创建并提交订单，待客服审核
 3. 已驳回：客服驳回客户订单创建申请
 4. 处理中：审核通过的订单，系统正在执行定时任务给仓库
 5. 配货中：仓库配货中
 6. 运输中：订单已出库，且物流轨迹还未被签收
 7. 已完成：订单已签收
 8. 取消待审核：订单状态为”处理中、配货中“时，客户取消订单，等待客服审核
 9. 已取消：一件代发订单被取消

### 撤回

1. 功能描述：订单状态为 “待审核、取消待审核” 时，可操作撤回

 - 订单状态为 “待审核” 时，撤销成功，订单状态更新为 “草稿”
 - 订单状态为 “取消待审核” 时，撤销成功，订单状态更新为操作取消时的状态（处理中或配货中）
2. 操作步骤：

 1. 选中需撤回的订单，点击【撤回】按钮

 ![一件代发订单管理界面。右侧有“编辑”“详情”“撤回”“取消”按钮，其中“撤回”按钮被红色框突出显示。](./assets/images/图片展示了一件代发订单管理界面-dbbc21c6fb6c.png)

 1. 二次弹窗点击【确定】，撤回成功，订单状态更新为 “草稿” 或 “处理中” 或 “配货中”

 ![订单管理界面中一件代发订单操作撤回的弹窗提示。弹窗背景为灰色，中间以红色圆角矩形框突出显示“确认要撤回订单”字样，下方有“取消”和“确定”两个按钮。](./assets/images/图片展示的是订单管理界面中一件代发订单操-4008d85f9818.png)

 ![一件代发订单管理界面。红色框突出显示了“撤回”按钮，对应文档中“撤回”操作步骤里选中需撤回订单后点击该按钮的操作说明，直观呈现了操作位置。](./assets/images/图片展示了一件代发订单管理界面-3b9f1208edd0.png)

### 取消

1. 功能描述：订单状态为 “草稿、已驳回、配货中” 时，可取消订单

 - 订单状态为 “草稿、已驳回” 时，提交取消，订单状态直接更新为“已取消”
 - 订单状态为 “处理中、配货中” 时，提交取消，订单状态更新为“取消待审核”，等待客服审核

 - 处理中、配货中时取消订单，可能会产生拦截费用
 - 客服审核通过，订单状态更新为 “已取消”
 - 客服审核驳回，订单状态不变，仍为操作取消时的状态
2. 操作步骤：

 1. 选中需取消的订单，点击【取消】按钮

 ![“一件代发订单”管理界面。订单编号为DL_01的订单右侧有红色框突出显示的“撤回”按钮。](./assets/images/图片展示的是“一件代发订单”管理界面-a04fdb20237c.png)

 1. 在取消订单弹窗中填写取消原因后，点击【确认】按钮

 ![“一件代发订单”操作指南中“取消”操作步骤的弹窗界面。弹窗标题为“取消订单”，内容提示取消订单后订单状态将更新为“已取消”，并列出取消订单的注意事项。](./assets/images/图片展示的是“一件代发订单”操作指南中“-41995b367796.png)

 1. 取消成功，订单状态更新为 “已取消” 或 “取消待审核”

 ![“一件代发订单”管理界面。“配货中”状态的订单被红色框突出显示，对应操作栏有“取消”按钮，与上下文“取消”操作步骤中选中订单点击“取消”按钮的内容相呼应。](./assets/images/图片展示的是“一件代发订单”管理界面-e653ec696414.png)
