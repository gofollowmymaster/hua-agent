# 飞书文档：FBA订单


## 功能介绍

亚马逊 FBA（Fulfillment by Amazon）订单是指卖家将商品存储在亚马逊海外仓，由亚马逊负责订单处理、仓储、打包、配送、客服及退换货等全流程服务的订单模式。

注：仅当使用”平台仓“发货至FBA仓库时，创建FBA订单

## 页面路径

【订单】-【渠道订单】-【FBA订单】

## 系统流程

![FBA订单系统流程画板：创建FBA订单后可暂存草稿或提交运营审核；审核拒绝时可修改后重新提交，也可取消订单；审核通过后创建物流货件和出库单，仓库完成出库运输，最终送达并签收。](./assets/whiteboards/系统流程-AgszwqF5ChOCtFbw1PtcK0rln7e.png)

## 操作指南

### FBA订单列表

1. 功能描述：展示您所有的FBA订单信息
2. 订单状态：

 1. 草稿：订单已创建未提交
 2. 待审核：客户创建并提交订单，待客服审核
 3. 已驳回：客服驳回客户订单创建申请
 4. 处理中：审核通过的订单，系统正在执行定时任务给仓库
 5. 配货中：仓库配货中
 6. 运输中：订单已出库，且物流轨迹还未被签收
 7. 已完成：订单已签收
 8. 取消待审核：订单状态为”处理中、配货中“时，客户取消订单，等待客服审核
 9. 已取消：FBA订单被取消

### 撤回

1. 功能描述：订单状态为 “待审核、取消待审核” 时，可操作撤回

 - 订单状态为 “待审核” 时，撤销成功，订单状态更新为 “草稿”
 - 订单状态为 “取消待审核” 时，撤销成功，订单状态更新为操作取消时的状态（处理中或配货中）
2. 操作步骤：

 1. 选中需撤回的订单，点击【撤回】按钮

 ![FBA订单管理界面，呈现了订单编号、产品名称、订单状态等信息。](./assets/images/图片展示的是-addCriterionF-1cd1855738ab.png)

 1. 二次弹窗点击【确定】，撤回成功，订单状态更新为 “草稿” 或 “处理中” 或 “配货中”

 ![FBA订单操作指南中撤回操作的二次弹窗界面。弹窗标题为“确定要撤回？”，背景为订单列表页面，列表中显示了订单编号、订单状态、商品名称、商品数量、商品重量、订单金额等信息。](./assets/images/图片展示的是FBA订单操作指南中撤回操作-040d7caaf7ec.png)

 ![FBA订单操作界面。右侧有操作栏，其中“撤回”按钮被红色框突出显示。](./assets/images/图片展示的是FBA订单操作界面-ab539b4e047b.png)

### 取消

1. 功能描述：订单状态为 “草稿、已驳回、配货中” 时，可取消订单

 - 订单状态为 “草稿、已驳回” 时，提交取消，订单状态直接更新为“已取消”
 - 订单状态为 “处理中、配货中” 时，提交取消，订单状态更新为“取消待审核”，等待客服审核

 - 处理中、配货中时取消订单，可能会产生拦截费用
 - 客服审核通过，订单状态更新为 “已取消”
 - 客服审核驳回，订单状态不变，仍为操作取消时的状态
2. 操作步骤：

 1. 选中需取消的订单，点击【取消】按钮

 ![FBA订单管理界面。左侧有导航栏，可选择“FBA订单”“FBA库存”等。](./assets/images/图片展示的是FBA订单管理界面-4e309e50afeb.png)

 1. 在取消订单弹窗中填写取消原因后，点击【确定】按钮

 ![FBA订单操作指南中“取消”操作步骤的弹窗界面。下方有“取消”按钮，按钮被红色框突出显示。](./assets/images/图片展示的是FBA订单操作指南中“取消”-cbbdd36dd6a3.png)

 1. 取消成功，订单状态更新为 “已取消” 或 “取消待审核”

 ![FBA订单管理界面。列表中有“取消订单”和“详情”按钮，其中“取消订单”按钮被红色框突出显示，对应“取消”操作步骤中选中需取消订单后点击该按钮的操作说明。](./assets/images/图片展示的是FBA订单管理界面-1232088a3fe9.png)
