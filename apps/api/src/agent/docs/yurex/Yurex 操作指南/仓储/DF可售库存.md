# 飞书文档：DF可售库存


## 功能介绍

DF可售库存：可查看并能设置产品在某仓库的DF可售库存数量，且将此设置与VC后台保持同步。

## 页面路径

【仓储】-【库存管理】-【DF可售库存】

## 系统流程

![DF可售库存系统流程画板，包含系统与亚马逊两条泳道：针对执行成功或失败的普通产品，用户在系统填写DF可售库存，亚马逊接收并更新库存；系统随后获取亚马逊的更新结果并结束流程。](./assets/whiteboards/系统流程-GUnXwplVGhT9XdbHv5PczlL5nKd.png)

 1. 执行中：同步亚马逊的任务正在执行中

 ![“DF可售库存”页面，其中“可售库存执行状态”栏位被红色框突出显示。](./assets/images/图片展示的是“DF可售库存”页面-c1022479ee16.png)

 ![DF可售库存页面中执行。](./assets/images/图片展示的是“DF可售库存”页面中“执行-87d68a74ea55.png)

 1. 执行失败：同步亚马逊的任务执行失败

### 提交

1. 功能描述：维护单个产品ID+仓库的【DF可售库存】后，提交更新后库存至亚马逊
2. 操作步骤：

 1. 选中需要维护可售库存的产品ID+仓库，在【DF可售库存】栏位输入数量注意：

 - 可用库存＞0，且可售库存执行状态为 “执行成功”，且产品状态为 “正常” 时，可编辑【DF可售库存】
 - DF可售库存需 ≤ 可用库存，且不能为负数
 - DF可售库存、产品状态：会定时与VC同步，获取到VC最新的DF可售库存信息及产品状态

 ![“DF可售库存”页面。下方表格中，序号为1的产品ID、仓库、可用库存、DF可售库存等信息被突出显示，其中DF可售库存栏位被红框圈出，显示数值230。](./assets/images/图片展示的是“DF可售库存”页面-4e5e9f911e73.png)
 2. 点击【提交】按钮，产品ID+仓库的【DF可售库存执行状态】更新为 “执行中”

 ![“DF可售库存”页面。](./assets/images/图片展示的是“DF可售库存”页面-a45dc4c5d97e.png)

### 批量提交

1. 功能描述：批量维护【DF可售库存】后，批量提交库存至亚马逊
2. 操作步骤：

 1. 批量在【DF可售库存】栏位输入数量后，DF可售库存列表的复选框会默认勾选
 2. 点击【批量上传】按钮，DF可售库存执行状态更新为 “执行中”

 ![“DF可售库存”页面截图，展示“批量提交”的功能入口和操作区域。](./assets/images/图片展示的是-自动生成-fe76c3182b8c.png)

### 批量上传

1. 功能描述：在Excel 维护DF可售库存后，快速导入系统注意：

 - 请提前通过筛选条件查询后，确定需要更新DF可售库存的数据范围
 - 若未提前筛选，导入模板会默认导出下载所有DF可售库存数据，导致系统卡顿
2. 操作步骤：

 1. 按条件筛选后，点击【查询】按钮，确认需要变更DF可售库存的范围

 ![DF可售库存批量上传操作界面。](./assets/images/图片展示的是DF可售库存批量上传操作界面-baeb2e843ec4.png)
 2. 点击【批量上传】按钮，在批量上传弹窗中，点击【模板下载】，将Excel导入模板下载至本地说明：Excel模板 仅显示可售库存执行状态为 “执行成功”的产品ID+仓库

 ![DF可售库存库存中“导出”操作的界面。在“批量上传”操作中，有“批量上传”“导出”两个按钮，其中“导出”按钮被红色框突出显示。](./assets/images/图片展示的是DF可售库存库存中“导出”操-d1b4ed6016b3.png)

 ![“模板下载”弹窗。](./assets/images/图片展示的是-“DF可售库存”-操作指南-91a7b8b54055.png)

 1. 在Excel 模板表格中填写【变更后DF可售库存】后，保存Excel

 ![Excel模板界面，用于批量上传DF可售库存数据。ASIN、仓库、可用库存、DF可售库存字段为蓝色背景，更新后DF可售库存字段被红色框突出显示。](./assets/images/图片展示的是Excel模板界面-43cb73f2947e.png)
 2. 回到批量上传弹窗页面，点击【上传文件】，选择本地已保存的Excel

 ![DF可售库存批量上传操作中批量上传弹窗界面。弹窗上方有上传进度提示，下方有1 上传文件区域有“上传文件”和“...上传文件”按钮，分别用于上传本地文件和通过拖拽文件。](./assets/images/图片展示的是DF可售库存批量上传操作中批-4b71c8cccaf1.png)
 3. 系统自动校验Excel 填写内容，并在【校验预览】栏位显示校验结果

 !["批量上传" 操作的弹窗界面。下方有“上传文件”区域，显示文件名为“Inventory列表导出176177779798.xlsx”，并有“模板下载”和“下载结果文件”按钮。](./assets/images/图片展示的是-批量上传-操作的弹窗界-a49eb307e159.png)
 4. 点击【下载结果文件】，查看导入失败数据、失败原因，可修改后重新提交

 ![系统中“批量上传”操作的校验预览界面。右侧有“下载结果文件”按钮，用红色框突出显示。](./assets/images/图片展示的是系统中“批量上传”操作的校验-b43c5c5ede08.png)
 5. 点击【确定】，提交导入成功数据到DF可售库存

 ![DF 函数的代码示例。代码中定义了两个参数，分别是`data`和`params`，其中`data`是一个包含`id`、`name`、`type`、`value`等字段的列表。](./assets/images/图片展示的是DF-addCriterio-e852a82bbea9.png)

### 导出

1. 功能描述：批量导出DF可售库存数据
2. 操作步骤：

 1. 不勾选、按条件筛选、勾选DF可售库存列表后，点击【导出】按钮，自动导出Excel 格式的库存数据到本地

 ![“DF可售库存”页面。页面上方有筛选条件栏，可按产品状态。](./assets/images/图片展示的是“DF可售库存”页面-46b49679c9b7.png)

### 操作日志

1. 功能描述：查看DF可售库存的历史更新记录
2. 操作步骤：

 1. 点击【操作日志】按钮，弹窗显示历史更新记录

 ![“操作日志”弹窗。](./assets/images/图片展示的是DF可售库存操作指南中“操作-cac967827891.png)
