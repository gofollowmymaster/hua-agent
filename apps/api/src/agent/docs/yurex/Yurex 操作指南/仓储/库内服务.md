# 飞书文档：库内服务

库内服务

当前版本：v2.0.0

## 功能介绍

### 自营仓/平台仓库内服务

1. 当仓库在库产品，需进行额外的一些处理，可通过提交“自营仓/平台仓库内服务单”申请，仓库作业人员根据服务单的内容，进行库内作业

### 商家仓库内服务

1. 当仓库在库产品，需进行拆合箱，可通过创建”商家仓库内服务“，进行处理、完成商品拆合箱；

## 页面路径

【仓储】-【库内管理】-【库内服务】

## 注意事项

### 自营仓/平台仓库内服务

1. 您提交的服务单处理需要一定时间，请不要着急，若有疑问可联系我司
2. 建议您使用谷歌浏览器登录系统

### 商家仓库内服务

1. 您所能加工的仓库为（自己所创建的--商家仓）；
2. 整箱加工为散件时，只能整箱全部加工使之成为散件；
3. 建议您使用谷歌浏览器登录系统；

#### 自营仓/平台仓

1. 功能描述：展示客户 自营仓/平台仓的库内服务单
2. 服务类型说明：

 1. 商品拆箱：将整箱库存拆为散件库存
 2. 商品合箱：将散件库存、整箱库存 合并为整箱库存
 3. 其他服务：其他库内服务
 4. 商品尺寸重量复核：重新复核商品的尺寸重量
 5. 商品代发：完成不同平台的商品发货服务
 6. 更换箱唛：原箱唛贴错、丢失、损坏或原箱唛未与系统关联
 7. 包材服务：商品需要在平台仓加包材，比如纸箱、快递袋等
 8. 商品异常：sku标签异常、产品预包装封口不牢固或袋装单件预包装不规范等
 9. 更换标签：更换产品SKU，将更换产品的SKU标签和UPC，库内服务完成后旧产品库存将转换为新产品库存
 10. 货物弃置：平台仓负责弃置在库货物，该服务无法指定批次
 11. 商品拆箱换标：将整箱库存拆为散件库存的同时更换SKU标签，您可以理解为 “商品拆箱 + 更换标签” 的综合服务
 12. 商品合箱换标：将散件库存、整箱库存 合并为整箱库存的同时更换SKU标签，您可以理解为 “商品合箱+更换标签” 的综合服务
3. 状态说明：

 1. 待审核：库内服务单创建成功后的初始状态，等待客服审核

### 作废

1. 功能描述：库内服务单状态为 “处理中” 时，可作废终止服务
2. 操作步骤：

### 完成

2. 操作步骤：

 1. 功能描述：商家仓-库内服务状态为 “处理中” 时，可完成服务单（表示服务单库内已完成作业）
 2. 操作步骤：

 1. 选中已作业完毕的单据，点击【详情】按钮；

 1. 点击右上角的【完成】按钮，二次弹窗确认
