# 飞书文档：销售退货单


## 功能介绍

1. 销售退货单：可查看所有销售退货单，管理销售退货单数据，包括退货仓库、退货状态、退货产品、数量等信息。

## 页面路径

【仓储】-【销售退货】-【销售退货单】

## 系统流程

![销售退货单系统流程画板：业务触发退货后，系统自动创建销售退货单，完成单据生成并结束流程。](./assets/whiteboards/系统流程-Hgqewsbuch1SHMbsxhkcOf0Tnzg.png)

## 操作指南

### 销售退货单列表

1. 页面路径：【仓储】-【销售退货单】-【销售退货单列表】
2. 功能描述：展示亚马逊销售退货单数据，统一管理VC退货订单。
3. 销售退货单状态说明：

 1. 运输中：初始默认状态，退货货物正在运输途中

 ![销售退货系统中销售退货单列表界面。界面显示了业务类型、退货数量、销售退货单ID、关联入库单、退货仓库、产品ID、产品名称、退货数量、已入、状态等信息。](./assets/images/图片展示的是销售退货系统中销售退货单列表-10da6a6ca23d.png)

 1. 收货中：已创建入库单且部分货物已入库（0 < 入库数量 < 退货数量）

 ![销售退货单界面，呈现了多条退货记录信息。每条记录包含业务类型、退货类型、销售退货单ID、关联入库单、退货仓库、产品ID、产品名称、退货数量、已入数量、状态等字段。](./assets/images/图片展示的是销售退货单界面-b77ead915728.png)

 1. 部分收货：已关闭退货单且部分货物已入库（0 < 入库数量 < 退货数量）

 ![销售退货单列表界面。界面中列出了多条退货记录，包括业务类型、退货类型、销售退货单ID、关联入库单、退货仓库、产品ID、产品名称、退货数量、已入数量、状态等信息。](./assets/images/图片展示的是销售退货单列表界面-6f1d9b03ab74.png)

 1. 已收货：入库数量等于退货数量

 ![销售退货单列表界面。界面中列出了多条销售退货单信息，包括业务类型、退货类型。](./assets/images/图片展示的是销售退货单列表界面-b09e6ba8b756.png)

 1. 已关闭：手动关闭退货单，且入库数量为0

 ![销售退货单界面，呈现了退货单列表。列表中包含业务类型、退货类型、销售退货单ID、关联入库单、退货仓库、产品ID、产品名称、退货数量、已入、状态等信息。](./assets/images/图片展示的是销售退货单界面-e0686c7f3263.png)

#### 导出

1. 功能描述：在运输中状态下，当后续退货产品无法到仓或仓库无法找到产品时，可关闭退货单结束流程
2. 操作步骤

 1. 点击【导出】按钮
 2. 系统自动导出当前筛选条件下，以Excel格式的销售退货单列表到本地。如有勾选数据，优先导出勾选数据；否则导出当前搜索条件下的数据
