库存管理

当前版本：v1.0.0

## 功能介绍

1. 库存管理：可查看仓库中所有产品库存汇总、库存动态、库存明细等（也可区分查看：整箱库存、散件库存）。

### 库存快照

#### 汇总

1. 功能描述：仓库类型为自营仓/平台仓时，展示SKU的库存快照。可查看SKU的期初库存、总入库库存、总出库库存、期末库存，默认展示近一个月的数据。

![图片展示的是库存管理中库存快照汇总页面。页面上方有“实时库存”“库存快照”“库存动态”三个选项卡，当前选中“库存快照”。页面中部有筛选条件区域，可按SKU、产品名称、操作单号、操作批次次、仓库类型、仓库、快照生成日期筛选。下方列表显示SKU、产品名称、产品属性、仓库、期初库存、总入库库存、总出库库存、期末库存等信息，如ASPH、MSK等SKU在演示仓库的库存数据。页面底部有分页显示共2条记录，当前第1页。](./assets/images/图片展示的是库存管理中库存快照汇总页面-d92d005fb601.png)

#### 明细

1. 功能描述：仓库类型为自营仓/平台仓时，按入库批次维度显示SKU在过去某一天的在库库存。

![图片展示的是库存管理中库存快照功能的汇总页面。页面上方有“库存快照”“库存动态”两个选项卡，当前选中“库存快照”。下方表格显示了产品名称、产品属性、货型、仓库、仓库类型、库存类型、装箱数量、操作批次号、操作批次次号、入库等信息，如产品名称为“yanoshi0”，货型为M，仓库类型为平台仓，库存类型为整箱库存，装箱数量为2等。页面右上角有“导出”按钮，下方有分页显示共25条记录，当前为第1页。该页面与 addCriterion](./assets/images/图片展示的是库存管理中库存快照功能的汇总-fe76bde70441.png)

### 库存动态

1. 功能描述：SKU产生入库、出库、拆箱、合箱等影响库存变化的操作后，在此页面记录的变动情况，以便追溯

![图片展示的是库存管理中库存动态页面。页面上方有搜索、筛选、通知等操作按钮，可按SKU、产品名称、操作类型等条件筛选。下方列表显示操作单号、操作类型、产品SKU、产品名称、产品属性、仓库类型、仓库类型ID、库存类型、装箱数量等信息，如“其他入库”操作的SKU为yanshi，产品名称为演示商家仓 - test，仓库类型为商家仓，库存类型为整箱库存，装箱数量为2。页面底部有分页显示共21条记录，当前第1页，每页20条。](./assets/images/图片展示的是库存管理中库存动态页面-d305b0937539.png)

### 导出

1. 功能描述：批量导出库存数据
2. 可导出范围：实时库存、库存快照、库存动态
3. 操作步骤：

 1. 按条件筛选、批量选中后，点击【导出】按钮，自动导出Excel 格式的出库明细到本地

 ![图片展示的是库存管理中库存动态页面。页面上方有搜索栏及用户信息。左侧有导航栏，选中“库存动态”。中部显示库存变动列表，包含操作编号、操作类型、产品SKU、产品名称、产品属性、仓库类型、仓库、库房类型、装箱数量等信息。右侧有筛选条件栏，可按SKU/ASIN/MSKU、产品名称、操作类型、操作日期等条件筛选。页面右上角有“导出”按钮，用于按条件筛选、批量选中后导出库存数据。](./assets/images/图片展示的是库存管理中库存动态页面-671f08de9d24.png)
