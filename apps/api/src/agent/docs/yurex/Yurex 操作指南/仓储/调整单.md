调整单

## 功能介绍

1. 当手动操作入库/出库填写数量或者尺寸/重量错误、仓库盘点账面与实际库存不符等异常情况，需要调整库内库存数量或者尺寸重量时可用调整单进行调整（仅限平台仓）

## 页面路径

【仓储管理】-【库存管理】- 【调整单】

## 操作指南
