# 飞书文档：调整单


## 功能介绍

1. 当手动操作入库/出库填写数量或者尺寸/重量错误、仓库盘点账面与实际库存不符等异常情况，需要调整库内库存数量或者尺寸重量时可用调整单进行调整（仅限平台仓）

## 页面路径

【仓储管理】-【库存管理】- 【调整单】

## 操作指南

### 调整单列表

1. 功能说明：显示已完成的调整单

 ![“调整单”列表页面。下方列表显示了调整单相关信息，包括调整单号、调整类型、来源单号、仓库、完成时间、创建时间、单态及操作等，如“ACD202034201”调整单为尺寸重量调整。](./assets/images/图片展示的是“调整单”列表页面-66217a3fd08c.png)

### 调整单详情

1. 功能描述：查看调整单详情
2. 操作步骤

 1. 点击【详情】按钮，显示调整单详细信息

 ![“调整单”页面，显示已完成的调整单列表。列表中包含调整单号、调整类型、仓库、创建时间、创建人、状态等信息，如“ADD20200304001”调整单号对应“尺寸重量”调整类型，仓库为“深圳仓”。](./assets/images/图片展示的是“调整单”页面-37310788b6e7.png)

 ![调整单详情页面。上方显示调整单号、状态、创建人、创建时间等信息，下方有产品信息表，列出入库和出库的序号、操作单号、入库/出库公司、产品名称、规格型号、供应商、库存类型、条形码。](./assets/images/图片展示的是调整单详情页面-e8d6c086b238.png)
