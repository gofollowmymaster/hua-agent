月度账单

当前版本：v1.0.0

## 功能介绍

财务会根据合同约定的结算范围的业务数据，生成对应的月度账单。供应商可对月度账单进行审核，审核通过后，则会纳入付款计划中，按照付款计划进行打款。

## 名词解释

| 名词 | 释义 |
|-|-|
| 月度账单 | 根据合同约定生成对应结算范围的月度总账。月度账单含有的款项暂为VC渠道费用+仓储费用。 |
| 申诉 | 对月度账单存在异议，可提交工单进行申诉。 |

## 注意事项

1. 若对生成的月度账单存在疑问，可提交工单也可以联系对应的运营人员进行询问。

### 审核账单

当接收到月度账单后，可对推送的月度账单进行审核（申诉或通过）。

#### 申诉

若对生成的月度账单存在异议，则可点击【申诉】，申诉将联动工单。进行申诉后，会有对应的财务人员跟进处理申诉问题，同时，月度账单的状态也会扭转为【申诉中】。

![月度账单页面，右上角有“申诉”和“撤销申诉”按钮。页面上方显示月度账单编号、日期范围及金额等信息。](./assets/images/图片展示的是月度账单页面-0cb4b780e188.png)

![月度账单申诉界面。底部有“上传附件”按钮和“取消”“确定”两个操作按钮。](./assets/images/图片展示的是月度账单申诉界面-7882024246b2.png)

且可以在工单中查看对应的处理情况。

![月度账单操作流程中“撤销申诉”步骤前的路径导航界面。左侧为功能导航栏，显示“设置”选项被红色框突出显示。](./assets/images/图片展示了月度账单操作流程中“撤销申诉”-745cfd14f4a6.png)

#### 撤销申诉

申诉后，若发现月度账单无问题，可点击【撤销申诉】，对应月度账单的状态将会扭转为【待审核】，需要您重新进行审核确认。

![显示了一个撤销申诉的确认弹窗。](./assets/images/图片显示了一个撤销申诉的确认弹窗-37dca1421d4a.png)

#### 确认

若对生成的月度账单没有异议，则可点击【确认】。

![月度账单页面。右上角有“导出出回执单”“下载回执单”按钮，右下角有“撤销申诉”“确认”按钮，其中“确认”按钮被红色箭头突出指向。](./assets/images/图片展示的是月度账单页面-6e55c3615fb7.png)

需上传对应的回执单进行确认，可下载**回执单模板**进行**参考**。

回执单：点击**导出回执单**即可下载对应的月度账单信息，**进行盖章即为回执单**。**需注意上传应为PDF格式。**

![确认月度账单时的弹窗界面。上方有“回执单下载”区域，显示“导出回执单.pdf”；下方“上传回执单”区域，上传参考为“回执单模板.pdf”，并有提示支持.pdf格式且文件大小小于50MB。](./assets/images/图片展示的是确认月度账单时的弹窗界面-2a7c065d2498.png)

![月度账单操作界面，界面中有各类账单数据信息。右上方有一个红色箭头指向的“导出明细”按钮，这是图片核心内容。](./assets/images/图片展示了月度账单操作界面-b616b1544407.png)

1. 在月度账单详情里点击【导出回执单】，即可导出该月度账单进行盖章后上传确认。
