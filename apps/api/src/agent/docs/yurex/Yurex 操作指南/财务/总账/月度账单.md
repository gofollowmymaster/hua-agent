月度账单

当前版本：v1.0.0

## 功能介绍

财务会根据合同约定的结算范围的业务数据，生成对应的月度账单。供应商可对月度账单进行审核，审核通过后，则会纳入付款计划中，按照付款计划进行打款。

## 名词解释

| 名词 | 释义 |
|-|-|
| 月度账单 | 根据合同约定生成对应结算范围的月度总账。月度账单含有的款项暂为VC渠道费用+仓储费用。 |
| 申诉 | 对月度账单存在异议，可提交工单进行申诉。 |

## 注意事项

1. 若对生成的月度账单存在疑问，可提交工单也可以联系对应的运营人员进行询问。

### 审核账单

当接收到月度账单后，可对推送的月度账单进行审核（申诉或通过）。

#### 申诉

若对生成的月度账单存在异议，则可点击【申诉】，申诉将联动工单。进行申诉后，会有对应的财务人员跟进处理申诉问题，同时，月度账单的状态也会扭转为【申诉中】。

#### 撤销申诉

申诉后，若发现月度账单无问题，可点击【撤销申诉】，对应月度账单的状态将会扭转为【待审核】，需要您重新进行审核确认。

![图片显示了一个撤销申诉的确认弹窗。弹窗左上角有一个橙色感叹号，右侧文字为“您是否确定撤销对当前月度账单的申诉？”。弹窗底部有两个按钮，左侧是白色背景的“取消”按钮，右侧是黑色背景的“确定”按钮。该图片与前文“撤销申诉”的上下文相关，展示了点击【撤销申诉】后系统弹出的确认界面，用户可在此选择是否真的要撤销对月度账单的申诉。](./assets/images/图片显示了一个撤销申诉的确认弹窗-37dca1421d4a.png)

#### 确认

若对生成的月度账单没有异议，则可点击【确认】。

![图片展示的是月度账单页面。页面上方有“月度账单编号”等信息，下方有“账单状态”“账单周期”等选项。中间部分详细列出应收款、应付费用等各项费用明细，如应收款包含平台使用费、服务费等，应付费用包含平台使用费、价值增长费用等。右上角有“导出出回执单”“下载回执单”按钮，右下角有“撤销申诉”“确认”按钮，其中“确认”按钮被红色箭头突出指向。该图片与上下文关于月度账单操作流程中确认环节的内容相关，展示了确认操作的页面位置。](./assets/images/图片展示的是月度账单页面-6e55c3615fb7.png)
