# 飞书文档：其他VC费用



## 功能介绍

为维护财务结算数据的完整性，当存在系统中暂未上线的费用项需进行结算时，财务可在其他VC费用中进行人工录入，录入后会在User端进行对应展示。

## 注意事项

1. 若对新增的其他VC费用明细存疑，可联系运营进行咨询。

## 对账思路

可通过其他VC费用明细中的**ASIN**及**费用名称**及对应的**备注**进行业务核对。

## 操作流程


### 操作路径

【财务中心】-【应付账款】-【其他VC费用】

### 搜索及展示

进入页面，可对数据进行搜索。

下方的列表可按创建时间进行正倒序排序。

![“其他VC费用”页面。上方有搜索框，可输入“其他VC费用编号”“费用名称”等进行。](./assets/images/图片展示的是“其他VC费用”页面-ab00ccd9c919.png)


- 可批量导出或指定数据导出，可按需进行导出。

 - 导出所选：勾选对应数据，导出勾选数据。
 - 导出全部：根据筛选展示内容，导出所有数据。

![“其他VC费用”页面，上方有搜索栏等筛选条件，下方列表显示了费用编号、产品ID、费用单编号、结算范围、结算周期、结算状态、费用名称、费用金额、备注、创建时间等信息。](./assets/images/图片中展示的是“其他VC费用”页面-944dd262318a.png)
