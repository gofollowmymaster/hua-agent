# 飞书文档：其他平台仓费用



## 功能介绍

1. 本功能用于查询供应链产生的相关费用信息，您可以通过本功能页面查询和导出所有其他平台仓费用及附件文件下载查看费用明细。

## 对账思路

1. 该模块为其他未进行收取的仓储类费用，为财务手动录入。
2. 客户进行核对时可根据产品+费用名称进行核对，或者可**下载附件**，进行费用核对。

## 操作流程


### 操作路径

【财务】-【应付账款】-【其他平台仓费用】

![飞书电商后台财务模块中“其他平台仓费用”的操作路径。左侧为功能导航栏，点击“财务”后，右侧出现多个费用类别，其中“其他平台仓费用”被红色框线突出显示。](./assets/images/图片展示了飞书电商后台财务模块中“其他平-647315259dc3.png)

### 默认数据加载

进入页面，会默认加载计费日期为最近三个月的数据

### 搜索及展示

进入页面，可对数据进行搜索，列表展示对应数据。

![“其他平台仓费用”页面。上方有搜索、筛选、导出等操作按钮，下方是数据列表区域。](./assets/images/图片展示的是“其他平台仓费用”页面-6afd752dc3e7.png)

### 附件下载

可通过页面列表附件列点击下载附件

![其他平台仓费用页面，可对数据进行搜索并列表展示。下方列表中显示了其他平台仓费用单号、结算账单编号、结算范围、结算账期、结算状态、费用金额、备注、创建时间、附件等信息。](./assets/images/图片展示的是其他平台仓费用页面-994275c36821.png)


点击【导出】可导出其他平台仓费用数据。

导出根据筛选条件进行导出，导出内容与列表数据一致。

![“其他平台仓费用”页面。下方列表显示了其他平台仓费用单号、产品ID、产品负责人、费用名称、仓账单编号、结算范围、结算账期、结算状态、计费日期、费用金额（USD）及备注等信息。](./assets/images/图片展示的是“其他平台仓费用”页面-c04207b0b1ed.png)
