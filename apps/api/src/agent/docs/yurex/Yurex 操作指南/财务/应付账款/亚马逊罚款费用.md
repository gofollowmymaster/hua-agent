亚马逊罚款费用

当前版本：v1.0.4

## 功能介绍

1. 当有不规范的业务行为发生后，可能会导致亚马逊产生对应的罚款信息。
2. 在当前模块中可查看亚马逊产生的罚款数据及对应罚款数据产生的费用。

## 注意事项

1. 产生原因：当您在运营过程中违反平台规则时，亚马逊系统将自动生成相应的罚款数据。
2. 核对方式：按照应付账款中【亚马逊罚款】查询结算日期数据，与月度账单中亚马逊罚款明细通过“罚款类型”核对。
3. 导出路径

 1. 月度账单-亚马逊罚款：财务

#### 操作路径

【财务】-【应付账款】-【亚马逊罚款】

##

1. 申诉条件：

 1. 结算日期在180天内。
 2. 罚款数据的支付类型为扣款。
 3. 在本平台未发起过申诉。
 4. 通过罚款编号无法匹配到回款数据。

 每条罚款仅可发起一次申诉，若申诉未被通过，将无法再次发起申诉，请谨慎提交。

2. 申诉入口：

 1. 批量申诉：点击主按钮【发起申诉】唤起申诉弹窗。
 2. 单个申诉：点击某条罚款操作栏的【申诉】唤起弹窗。
 3. 注：仅满足上一条申诉条件的数据才提供申诉入口，无申诉入口的数据即不满足条件，无法发起申诉。

 ![图片展示的是亚马逊罚款申诉操作流程中选择申诉图片的内容界面。左侧有“罚款申诉”选项，右侧列表呈现多条罚款申诉数据，包括产品编号、产品名称、订单编号、罚款日期、责任数量、应付金额等信息，部分数据被模糊处理。右侧列表下方有“确定”按钮。该图片与上下文紧密相关，直观呈现了选择申诉数据的操作界面，辅助说明选择申诉数据的步骤。](./assets/images/图片展示的是亚马逊罚款申诉操作流程中选择-825154d1fc09.png)
3. 选择申诉数据，勾选完成后点击确定。

 1. 勾选需进行申诉的数据，右侧列表会展示所有勾选的数据并计算预进行申诉的总金额。

![图片展示的是亚马逊罚款申诉界面。上方显示申诉条件，包括经期 addCriterion理日期在180天内且未发起 addCriterion过申诉的罚款数据。下方表格列出了多条数据，包括罚款编号、订单编号、罚款类型、罚款子类型、结果日期、罚款天数、罚款金额等信息，如订单编号为10223942936的罚款类型为全部支付，罚款子类型为发货数量少于确认数量，结果日期为2020 - 12 - 13，罚款天数为60，罚款金额为$4.4070 USD addCriterion](./assets/images/图片展示的是亚马逊罚款申诉界面-37c8b1e43552.png)

1. 输入申诉原因，若存在佐证材料，请一并提交便于帮助申诉审核。

注：若在第一步勾选了多条数据，您所填写的申诉原因和附件将应用于所有已选数据。此为批量操作，如需为不同场景分别申诉，请分开提交申请。

![图片展示的是亚马逊罚款申诉提交申请材料的界面。界面上方有“提交申请材料”标题，下方提示需填写完整有效的申诉原因并提交附件。有“单选题型”和“附件”两个输入框，其中“附件”框提示每次最多提交10个文件，每个文件大小不超过50MB。下方有“取消”和“确定”两个按钮。该界面与文档中“罚款申诉”操作流程上下文相关，用于指导用户在提交罚款申诉申请时填写材料。](./assets/images/图片展示的是亚马逊罚款申诉提交申请材料的-efb0a2bc8eb0.png)

1. 已提交申诉的数据将新增【申诉中】标签，可通过标签进行申诉状态的跟进。
2. 筛选区新增申诉状态的查询条件，您可通过此功能快捷搜索出所有发起过申诉的罚款数据。

注：若在您的设备上未显示申诉状态的查询，可点击漏斗展开被折叠的查询字段。

##

1. 可批量导出或指定数据导出，可按需进行导出。
2. 若进行筛选后，导出内容则会跟筛选条件一致。
3. 命名规则为：亚马逊罚款+日期。
4. 点击【导出】，若当前列表数据无勾选，则导出全量数据；若当前列表有勾选，则导出被勾选的数据。
