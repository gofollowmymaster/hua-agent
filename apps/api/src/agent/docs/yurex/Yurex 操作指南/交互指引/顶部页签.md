# 飞书文档：顶部页签


## 功能介绍

- 点击页签即可跳转对应页面

- 拖动页签可调整页签排序

- 右击页签可打开**页签的快捷管理菜单**：可快速完成页签的刷新、固定、关闭等操作

### **快捷管理菜单功能介绍：**

| **操作选项** | **功能作用** |
|-|-|
| 重新加载 | 刷新当前页签的内容（比如页面加载异常、数据没更新时，重新获取最新内容） |
| 固定/取消固定 | 固定页签后将位于未固定页签前面，并无法拖动，反之可取消固定 |
| 关闭当前标签 | 仅关闭当前右键操作的这个页签 |
| 关闭其他标签 | 仅保留当前右键的这个页签，自动关闭其他所有已打开的页签 |
| 关闭全部标签 | 关闭当前所有已打开的页签（首页为固定页签不可关闭） |
| 打开新浏览页签 | 会将当前页带入，在浏览器新开页面 |
