# 飞书文档：自定义表格+列拖动


## 一、自定义表格

**功能介绍：**自定义表格，可根据不同业务需求，保存列表配置，减少重复操作。用户可以自由选择表格要展示的字段，支持保存为专属模板，后续直接调用，同时能切换 “紧凑 / 正常”布局视图，适配不同的查看习惯。

![飞书自定义表格界面，呈现了“自定义表格”弹窗。弹窗左侧为“列配置表格”，可选择“默认显示”和“默认隐藏”的列，如“ID”“VCPO合同单号”“状态”等。](./assets/images/图片展示了飞书自定义表格界面-b51e0e008b43.png)

### 交互细节

#### 功能入口

自定义表格入口位于**每个列表页的表格右上方**，点击【齿轮图标】即可进入自定义表格弹窗进行列配置

![VCPO发货订单列表页，上方有搜索、筛选等操作栏。右上角有红色框标注，提示“点击打开自定义表格弹窗”，与上下文介绍的自定义表格入口位置对应，直观呈现了点击齿轮图标这一操作。](./assets/images/图片展示了VCPO发货订单列表页-ffde21c5513f.png)

#### 模块 1：左侧「列配置模板」

![飞书项目管理中自定义表格的列配置界面。左侧为“列配置模板”列表，有默认模板和保存为新模板选项，可编辑命名及配置。](./assets/images/图片展示了飞书项目管理中自定义表格的列配-85535c6984ba.png)

1. **默认模板**：系统预设的标准字段、排序及默认布局，可编辑命名及配置
2. **保存为新模板**：

 - 操作逻辑：当用户调整完字段 / 顺序后，点击【保存为新模板】按钮 → 弹出模版名称命名输入框 → 输入模板名，这套配置会被保存到 “列配置模板” 列表中，点击保存并应用后，下次进入该列表会自动调用该设置。
 - 场景：适合不同岗位（比如仓储岗 / 物流岗）保存专属字段模板

![自定义表格中“保存为新模板”操作界面。左侧为默认模板，可编辑命名及配置，右侧是已排序字段列表。](./assets/images/图片展示的是自定义表格中“保存为新模板”-e19b29f8f2b4.png)

![飞书项目管理中自定义表格的列配置模板界面。右侧是已选字段列表，如VCDP项目单号、ASN、PO No.等，部分字段有红色箭头指向。](./assets/images/图片展示的是飞书项目管理中自定义表格的列-87b80e3fe1e3.png)

#### 模块 2：中间「待选字段 + 视图控制」

1. **待选字段列表**：

 - 交互逻辑：点击字段前的复选框，**勾选 = 加入右侧已选字段**；**取消勾选 = 从右侧已选字段中移除**
2. **取消全选**：

 - 交互逻辑：点击后，所有已勾选的字段会自动取消勾选，同时右侧 “已选字段” 会被清空
 - 场景：适合 “从零开始重新配置” 的场景
3. **紧凑 / 正常切换**：

 - 交互逻辑：点击按钮后，**控制表格的显示密度**
 - 细节：【紧凑】视图会压缩字段间距，可提升数据展示密度，但视觉美观度会受一定影响；【正常”】视图间距宽松，可降低视觉疲劳，但数据容量会降低。

 ![自定义表格中“中间「待选字段+视图控制」”模块的界面。左侧为“列表预览表”，有“列预览表单”“列预览字段”“列预览操作”等选项，其中“列预览字段”被红色框突出显示。](./assets/images/图片展示了自定义表格中“中间「待选字段-aaabaf27f9c0.png)

#### 模块 3：右侧「已选字段」

![自定义表格中“已选字段”界面。左侧为可选字段列表，如VCPE的名称等，可勾选。](./assets/images/图片展示了自定义表格中“已选字段”界面-b6adabb158ea.png)

1. **字段排序**：

 - 交互逻辑：鼠标 hover 到字段左侧的「:::」图标 → 光标变成 “拖动小手” → 按住拖动到目标位置 → 松开后，表格中该字段的显示顺序会同步变化
 - 细节：拖动时会有 “占位条” 提示最终位置
2. **字段操作：**

 - 包含操作：可设置列表字段【固定在左侧/右侧】或【取消固定】
 - 固定在左侧：当表格字段较多时，会出现横向滚动，如果希望该字段不跟随滚动，就可设为固定左侧（如产品信息）
 - 固定在右侧：如操作按钮、状态类字段可固定右侧，不跟随列表进行滚动，方便浏览与操作

 ![自定义表格中“已选字段”界面。用红色框突出显示了“恢复默认”按钮，以及“已选字段”区域的“重新排序”按钮和“删除字段”按钮。](./assets/images/图片展示了自定义表格中“已选字段”界面-737bcabf5c46.png)
3. **恢复默认**：

 - 交互逻辑：点击后，右侧已选字段会**恢复到系统预设的字段 + 顺序**（覆盖当前所有修改）
 - 场景：配置混乱时快速重置

#### 模块 4：底部「操作按钮」

![自定义表格配置弹窗界面。左侧为“自定义表格”区域，可选择字段模板，当前选中“默认2”。](./assets/images/图片展示的是自定义表格配置弹窗界面-964b65eef29e.png)

1. **保存并应用**：

 - 交互逻辑：点击后，当前 “已选字段 + 排序 + 视图模式” 会**立即应用到列表页，并关闭配置弹窗**
2. **取消**：

 - 交互逻辑：点击后，弹窗直接关闭，**所有未保存的配置会被丢失**，列表页配置将保持之前的状态。
