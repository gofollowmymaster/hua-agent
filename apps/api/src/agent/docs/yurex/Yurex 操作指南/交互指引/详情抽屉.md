详情抽屉

## 一、功能介绍

详情抽屉功能提供给用户**不跳页、快速查看单条数据的详情**：

- 不用离开当前列表页，避免重复切换页面
- 一键触发，比点 “详情按钮” 更高效
- 详情会展示比列表更全的信息

## 二、操作步骤

1. **打开详情：**点击列表中该条数据整行**任意区域（除按钮区外），**页面侧边会弹出抽屉详情 （文字上下空白区域均可尝试）

![图片展示了详情抽屉功能的操作示例。在商品管理页面中，点击列表中某条数据整行任意区域（除按钮区外外），），页面侧边会弹出抽屉详情。图中以黄色文字标注“点击整行任意区域都可打开详情抽屉（按钮除外）”，并展示了打开的抽屉详情界面，包括产品名称、品牌、产品型号等信息。该图片与上文“打开详情”操作步骤对应，直观呈现了操作效果。](./assets/images/图片展示了详情抽屉功能的操作示例-b6f5b4832a0e.png)

1. **抽屉切换：**打开抽屉后，可点击抽屉左侧表格其他单元格，抽屉将切换至对应条目（只能切换列表当前页，可把页条数设大一点）

![图片展示了产品详情抽屉功能的操作示例。左侧为产品列表，其中“test_01”被红色框选突出显示。右侧是“test_01”的详情页面，包含产品信息、供应商信息、关联信息等。图片与上下文的关系是，直观呈现了打开详情的操作，即点击列表中该条数据整行任意区域（除按钮区外），页面侧边会弹出抽屉详情，此图对应操作步骤中打开详情的步骤说明。](./assets/images/图片展示了产品详情抽屉功能的操作示例-82893eef7b38.png)

1. **关闭抽屉：**方式 2 选 1：点击抽屉右上角的**「×」按钮**。或点击抽屉左侧列表内容区外的其他地方（顶部和菜单导航除外）

![图片展示了产品管理界面中详情抽屉功能的操作示例。左侧列表中选中“Sergio”后，右侧弹出详情抽屉，可查看产品信息等。抽屉右上角有“×”关闭按钮，点击该按钮可关闭详情抽屉。此外，图片还标注了“可点击除该内容区的其他地方，关闭详情抽屉”，提示用户除点击“×”按钮外，还可点击抽屉左侧列表内容区外的其他地方（顶部和菜单导航除外）关闭详情抽屉。此图与上文介绍的详情抽屉关闭操作步骤相呼应。](./assets/images/图片展示了产品管理界面中详情抽屉功能的操-afea9e5922d8.png)
