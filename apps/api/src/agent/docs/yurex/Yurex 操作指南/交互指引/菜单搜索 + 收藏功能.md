菜单搜索 + 收藏功能

## 一、功能介绍

该功能**帮助用户快速定位 + 一键访问常用功能的工具**，不用在长菜单里逐个查找：

- 「搜索」：输入关键词，模糊查询菜单名称包括其层级（定位到末级菜单）
- 「收藏」：把常用功能存到 “收藏区”，下次直接调用

## 二、操作步骤

#### 模块 1：菜单搜索（找功能）

1. **搜索菜单入口**：点击页面顶部的「 🔍 」图标，即可打开下拉搜索框

![图片展示了飞书管理后台首页界面，右上角有搜索图标（红框标注）。点击该图标后弹出搜索框，输入关键词可进行模糊查询菜单名称，包括其层级（定位到末级菜单）。此图对应文档中“模块1：菜单搜索（找功能）”的操作步骤，直观呈现了搜索菜单入口的界面位置及搜索框的打开方式，帮助用户了解如何通过搜索功能快速定位常用功能。](./assets/images/图片展示了飞书管理后台首页界面-e87355e9a3a3.png)

1. **输入关键词**：比如想找 “商品管理”，输入 “商品”或“商品管理”等关键词

![图片展示的是飞书管理后台中“商品”功能的菜单搜索界面。左侧有“商品”等导航栏，右侧显示“欢迎回来，bbddddd”及实时销量、实时广告等数据。右上角有“🔍”图标，点击后弹出搜索框，输入“商品”后，右侧功能菜单中“商品 > 商品管理”被红色框线突出显示，表明搜索结果。该图片与文档中“模块1：菜单搜索（找功能）”部分对应，直观呈现了搜索菜单入口、输入关键词及打开菜单的操作效果。](./assets/images/图片展示的是飞书管理后台中“商品”功能的-cd87e20a86ce.png)

1. **打开菜单**：点击搜索结果就能直接打开对应的功能页面

#### 模块 2：功能收藏（存常用功能）

1. **找到目标菜单**：展开左侧菜单，定位到要收藏的功能（比如 “商品管理”）
2. **点击收藏按钮**：功能名称右侧的「星星图标」，点击后星星会变成 “已选中状态”（变实心），同时会弹出 “已收藏” 提示

![图片展示了商品管理页面中功能收藏的操作示例。左侧菜单中“商品管理”功能被选中，其右侧有“收藏”按钮，点击后星星会变成“已选中状态”（变实心），同时弹出“已收藏”提示。页面右上角“🔍”图标处，已收藏的功能会显示在搜索结果中，直接点击即可打开。此图与文档中“功能收藏（存常用功能）”模块2的操作步骤对应，直观呈现了收藏和访问收藏功能的操作位置和效果。](./assets/images/图片展示了商品管理页面中功能收藏的操作示-907813a0b33c.png)

1. **访问收藏功能**：点击「 🔍 」图标，已收藏的功能会显示在这里，直接点击就能打开

![图片展示了“标题”菜单搜索+收藏功能的操作界面。页面右上角有“🔍”图标，点击后弹出搜索框，输入关键词可模糊查询菜单名称。下方是“收藏功能”区域，显示“Catalog”和“图片管理”两个功能，其右侧有星星图标，点击后星星变实心，弹出“已收藏”提示。该图片与文档中“功能收藏（存常用功能）”模块内容对应，直观呈现了收藏功能的操作步骤及效果。](./assets/images/图片展示了“标题”菜单搜索-收藏功能的操-0b4125d67bf2.png)
