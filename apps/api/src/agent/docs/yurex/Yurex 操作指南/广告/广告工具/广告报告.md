广告报告

## 操作流程

### 广告报告菜单

【广告管理】-【广告工具】-【广告报告】

![“广告报告”页面。](./assets/images/图片展示的是“广告报告”页面-630853223f61.png)

### 创建广告报告

- 点击【创建报告】，进入创建页面

![“广告报告”页面，左侧有导航栏，中间上方有“广告报告”标题及搜索框等。页面上方有“报告管理”“报告列表”“报告模板”“报告设置”选项，其中“报告管理”被红色框突出显示。](./assets/images/图片展示的是“广告报告”页面-964a98ef765a.png)

- 进入【创建报告】页面，填写报告名称，选择广告类型（SP/SB/SD），以及对应的报告类型、时间单位、报告的日期范围。

![“广告报告”操作流程中“创建报告”步骤的界面。在“创建报告”弹窗中，可选择“报告名称”为“亚马逊广告报告”，“报告类型”为“广告报告 - 商品广告”，“报告状态”为“生成中”。](./assets/images/图片展示的是“广告报告”操作流程中“创建-db80866dbb22.png)

### 广告报告列表

- 创建报告成功后，列表会生成一条“生成中”的数据；
- **此时正在亚马逊下载广告报告，具体在内可下载报告的时间，依据亚马逊系统生成该报告的时间而定。**

### 报告生成成功

- 广告报告的状态为“生成成功”后，您可【下载】、【复制】、【删除】该份报告；
- 点击【下载】，自动将报告excel文档下载到本地；

![广告报告列表界面。列表包含创建时间、广告类型、报告类型、时间单位、日期范围、报告名称、状态及操作等列。](./assets/images/图片展示的是广告报告列表界面-9f1c4a72b2b7.png)

- 点击【复制】，可快捷复制该份报告；复制成功后，列表也会生成一条数据

![“复制报告”弹窗界面。弹窗内有多个必填项，包括“AMZ广告子账户”“报告名称”“广告类型”“报告类型”“时间单位”“日期范围”，各字段后有对应输入框或下拉选择框。](./assets/images/图片展示的是“复制报告”弹窗界面-f2fb351f77ad.png)

- 点击【删除】，该条广告报告删除后不可再恢复；

![广告报告生成成功后，点击【删除】时弹出的确认删除提示框。](./assets/images/图片展示的是广告报告生成成功后-c7132a6d3eaa.png)

### 报告生成失败

- 若报告生成失败，您可重新修改报告后，等待再次生成报告，或删除报告；

## 常见问题

#### **Q1：为什么广告报告生成失败？**

A1：一般情况下，由于亚马逊接口波动，导致报告未能正常生成；若多次生成失败，请联系您的运营经理。

#### **Q2：为什么要选AMZ广告子账户？**

A2： AMZ广告子账户是用于投放和管理亚马逊广告的独立账户，报告也是独立的。

#### **Q3：创建了广告报告后，多久能下载报告？**

A3：创建后，具体在内可下载报告的时间，依据亚马逊系统生成该报告的时间而定。

#### Q4：为什么下载的广告报告有时是中文，有时是英文？

A4：因为报告的语言版本是依据当前亚马逊平台语言而定；后续会统一为中文报告。
