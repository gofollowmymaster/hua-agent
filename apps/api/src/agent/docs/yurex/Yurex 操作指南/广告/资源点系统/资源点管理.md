# 飞书文档：资源点管理



## 功能介绍

1. 核心定义：什么是“资源点”？

 - 定义： 资源点是本平台内的一种预付费虚拟货币，**专门用于兑换广告类（或其他监控类）的数据服务与功能**。
 - 特性：

 1. **与广告充值资金分属两个独立的账户体系，不能混用。**
 2. 用户需要先购买，后使用；消费时需要先扣点，再执行（避免超扣）。
 3. 原则上，购买的资源点不支持直接退款，但可在账户内长期持有并使用。
 4. 资源点的用途需进行区分，通用资源点可用于所有业务（广告监控、促销、listing监控等）的消费，广告资源点仅可用于广告任务。

## 注意事项

1. 资源点账户无需手动开户，完成购买后系统自动为您创建资源点账户。
2. 除购买以外，若您接收到平台的赠送资源点时，系统也会为您自动开户。
3. 目前单个供应商仅可持有一个资源点账户。
4. 资源点扣点优先级：

 1. 资源点属性

 1. 维度1：用途 - 广告（只能用于广告相关服务) - 通用 (可用于所有服务)
 2. 维度2：有效期 - 永久 - 有限期(有明确到期时间)
 3. 维度3：来源 - 购买点 (付费获得) - 赠送点 (免费赠送)
 2. **扣点基本原则**

 1. **优先使用专用点：先释放专用的点**
 2. **优先使用临近失效的：减少浪费，提高利用率**
 3. **优先使用成本较低的：赠送点先于购买点。**
 3. 扣点权重示例：

 | 用途 | 有效期 | 来源 | 扣点权重 |
 |-|-|-|-|
 | 广告 | 3天过期 | 赠送 | 0 |
 | 广告 | 3天过期 | 购买 | 1 |
 | 广告 | 永久 | 赠送 | 2 |
 | 广告 | 永久 | 购买 | 3 |
 | 通用 | 3天过期 | 赠送 | 4 |
 | 通用 | 3天过期 | 购买 | 5 |
 | 通用 | 永久 | 赠送 | 6 |
 | 通用 | 永久 | 购买 | 7 |

### 资源点消费

1. 当您在竞品监控、关键词排名监控页面创建监控任务后，监控任务执行之后会按照日消耗点数=产品数量\*监控邮编数\*关键词数量\*监控页数\*每天监控次数维度进行扣点。

 1. 流水号：交易流水唯一ID。
 2. 账户编码：指本条交易扣除点数的资源点账户。
 3. 服务名称：指本条交易是从哪个监控服务中产生的。
 4. 执行类型：频次执行/手动执行。
 5. 关联任务名称：监控任务的名称，可通过本名称指监控模块中进行搜索。
 6. 账单状态：账期为t+1，+1天聚合当天所有交易生成账单，若本条交易暂未纳入账单，则账单状态为未出账，若已纳入账单，则账单状态为已出账。
 7. 关联账单编号：该交易纳入的账单编号。

#### 账单说明

1. 账期：T+1
2. 出账节点：每日凌晨0点。
3. 出账维度：供应商+资源点账户。
4. 数据纳入准则：账期内所有类型的交易流水。
5. 注：仅在当前账期产生了交易才会自动出账，若未产生交易则该账期不生成账单。
6. 账单组成：

 1. 基础信息：

 1. 账单编号：账单唯一识别ID
 2. 扣点账户编码：账户唯一ID
 3. 账单点数：纳入账单的所有交易点数总和，期初点数+账单点数=期末点数。
 4. 期初点数：账期前的账户余额点数。
 5. 期末点数：账期后的账户余额点数。
 6. 账期：日期范围，为出账日的0点至23点59分59秒，时区为UTC+8。
 7. 出账时间：指该账单生成的时间。
