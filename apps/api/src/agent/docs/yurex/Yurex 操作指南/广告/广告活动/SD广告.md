SD广告

当前版本：v1.0.2

## 功能介绍

1. SD广告，即展示型推广广告。可以通过分析用户行为，主动在亚马逊站内外展示给客户的广告方式。同时，还可以通过潜在的消费人群回溯，把广告展示给他们，促进产品宣传和订单转化。
2. SD广告的价值：

 1. 它可以触达各个购买旅程的消费者，无论消费者处在认知了解，还是说考虑和对比，以至于说购买和复购的各个阶段，我们都可以用展示型推广来触达这部分的消费者。
 2. 并且，除了消费者在浏览和购买商品之外，我们依然可以使用展示型推广来触达那些不在亚马逊购物的消费者，也就是我们所谓的站外消费者。
3. 广告业务基于亚马逊广告活动功能，支持卖家创建广告活动、调整广告，所有数据实时同步亚马逊后台。
4. 通过广告系统，卖家可以完全脱离亚马逊后台，直接在系统中，完成与广告活动相关的所有分析与维护操作，并通过各个增益功能，实现精细化的广告投放，提高广告收益。

## 数据更新频率

1. **结构数据（曝光量前面的字段数据）更新频率：**

- 广告活动、广告组、商品：每10分钟一次

1. **报表数据（曝光量及之后的字段数据）的更新频率：**

- 广告活动、广告组、商品、商品投放：每1小时一次

PS：不同于亚马逊只保留65天(daily)的广告报告数据，会保留所有同步回来的广告数据，供卖家分析参考

因此，为确保广告活动的持续有效及权重不受影响，请务必维持账户内有足够的余额。

## 操作流程

- 展示型推广活动，可以在亚马逊桌面设备和移动设备上投放，并展示在商品详情页和其他亚马逊页面上。顾客点击展示型广告，将会转到对应商品详情页。
- 当广告商品缺货时，展示型推广广告将暂停。商品恢复有货状态后，只要处于既定广告活动的投放时段，广告活动就可以恢复到投放状态。恢复过程可能会有延迟，一般最多延迟 4 个小时。

##### 受众投放

①受众投放包含：浏览再营销与购买再营销。

添加方式：选择受众 -> 设置竞价 -> 设置创意

系统默认给4个受众类型：浏览再营销 - 推广的商品、浏览再营销 - 类似于推广的商品。购买再营销 - 推广的商品、购买再营销 - 与推广的商品相关。

受众类型：浏览再营销

添加本类型受众，需要先设置回溯期（7/14/30/60/90天），之后再找到要投放的受众类别，点击右侧的添加按钮，一键添加至投放列表。

受众类型：购买再营销

购买再营销策略使我们能够在指定的回溯期内，根据受众的历史购买行为吸引他们。

它的添加方式，和“浏览再营销”类似，也是先选择回溯期，不过比“浏览再营销”的范围要广，最长可以回溯近365天(近1年)的数据。

② 设置竞价

当添加好受众分类后，我们需要为它们单独设置竞价。

点击竞价输入框，可直接输入竞价，或者点击右侧的建议竞价旁边的【应用】按钮，一键应用其建议竞价。

##### 创意素材

**图片格式的配置素材包含：自定义图片、徽标、标题**

###### ①自定义图片（必填）

自定义图片规格：

- 图片大小：1200x628 像素或更大
- 文件要求：格式为PNG 或 JPG；大小为5MB 或 更小
- 内容：图片中不能包含文本、图标或徽标

## 常见问题

#### **Q1：为什么我在系统操作后（修改状态等），数据又变了呢？**

A1：因为亚马逊对数据存在波动，我们每10分钟会同步亚马逊数据，最终数据以亚马逊为准。

#### **Q2：广告组的有效开关和状态为什么会不一致，广告组的有效开关是启用，但是状态显示已暂停?**

A2：因为广告活动暂停后，相应的广告组状态也会变成已暂停；而有效开关按钮是人为操控的，并不会随之变化。若您想保持一致，可手动关闭开关。

#### **Q3：创建了SD广告活动后，多久能更新审核结果？**

A3：提交SD广告活动后，5分钟内可查询到广告活动审核结果。但是创意素材需要1～3个工作日的审核时间。若超过3个工作日请联系运营人员。

#### **Q4：广告活动状态是投放中，但是广告活动没产生曝光、点击量等数据？**

A4：原因一：SD广告会对您的推广商品进行审核，所以建议您投放广告后，及时检查商品状态是否处于投放中。

原因二：请检查您的出价是否过低，若出价过低也会造成广告活动未形成流量转化。

原因三：建议您不要经常关闭和打开有效开关，这会影响广告权重（您原来累计的自然排名不再有效）。

原因四：投放不精准，如果选择的商品投放与用户的搜索意图不相符，广告就不会被展示。

原因五：创建广告活动后，亚马逊可能需要至少12个小时的时间同步指标数据，最长可能需要72小时。如果超过72小时您的广告数据依旧为空，请优先检查您的竞价和预算设置，然后再联系运营进一步确认具体原因。

#### **Q5：商品报错：当前商品暂无法投放广告活动**

A5：可能是由于您的商品库存不足、Offer未生效成功、销量过低、商品类别不符合亚马逊投放广告规则。建议您在该广告组下重新添加推广商品。

#### **Q6：创建失败的情况下，我该怎么操作？**

A6：若广告活动、广告组、商品、商品投放中存在数据创建失败，那是因为亚马逊接口不稳定导致未能访问亚马逊，此时您可尝试一键重新提交。若多次提交不成功，可联系客服。

#### Q7：Ads处于“广告异常”状态是什么情况？

A7：您的ASIN被亚马逊抑制，暂无法正常投放广告，请您联系运营经理帮助您处理。
