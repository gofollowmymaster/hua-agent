# 飞书文档：广告货款划拨服务说明

广告货款划拨服务说明

## 一、功能说明

为优化广告充值体验，我司新增**“货款划拨广告费用”**功能，允许您将待支付的货款直接转为广告账户余额，以解决部分客户因支付渠道限制带来的不便。

请注意以下事项：

1. **手续费说明**：当前通过PingPong等第三方渠道充值广告费可能产生手续费，而通过货款转广告费不额外收取手续费，但实际到账金额以系统记录为准。
2. **支付限制**：该功能仅适用于符合资金划转条件的待支付货款，具体可操作金额以系统显示为准。
3. **账户要求**：使用货款转广告费功能需确保账户状态正常，且无未结清的争议款项。
4. **资金用途**：划转后的广告费仅限用于平台广告投放，不可转作他用。
5. **到账时效**：资金划转可能存在延迟，请以广告账户实际到账时间为准。

## 二、可划拨金额

1. 根据我司现行财务政策，系统仅支持将计划付款金额的50%划转至广告账户。剩余50%货款将正常参与结算。
2. **请注意：处于内部审核流程中的付款计划数据，因系统限制暂不支持划拨操作，将会被自动过滤展示。**
3. 分配原则：

 1. 时间优先原则：

 - 按照计划付款日期从远到近的分配原则。
 2. 金额匹配原则：

 - 从最大金额付款计划开始匹配。
 - 当单笔付款计划金额≥需划拨金额时，全额分配。
 - 当单笔付款计划金额＜需划拨金额时，先分配该笔付款计划全部金额，剩余金额继续向下匹配次临近日期的付款计划。

## 三、扣款原则

1. **扣款顺序**

**（1）第一优先级：转账充值余额**

- 扣款逻辑：当广告消费账单生成时，系统优先扣除转账充值余额（即客户通过主动线下转账充值的资金）。
- 执行场景：适用于所有广告投放扣费，确保客户自有资金优先使用。

**（2）第二优先级：货款划拨余额**

- 扣款逻辑：仅当转账充值余额≤0时，系统自动切换至货款划拨余额进行扣款。
- 执行限制：

 - 货款划拨余额仅用于广告消费。
 - 扣款后，剩余划拨余额仍保留在广告账户中。

## 四、余额调拨

在广告账户余额划拨业务中，系统将严格区分以下资金类型：

1. 转账资金来源构成：

 - 转账充值金额（客户直接充值）
 - 货款划拨金额（由货款账户转入）
2. 资金识别：

 - 系统自动识别转出账户中的资金类型比例.
 - 调拨时按照优先划转转账交易余额，转账交易为0时再划转货款划拨余额。
 - 按资金类型原属性进行分账处理。
3. 到账处理原则：

 - 转入账户接收后保持资金类型不变；
 - 转账金额与划拨金额分别独立记账；
 - 维持原有的扣款优先级规则；
4. 资金追溯：交易记录中提供完整的资金流向记录，可查询每笔转账的原始构成。
5. 使用限制：转账后的资金仍受原类型使用规则约束。
