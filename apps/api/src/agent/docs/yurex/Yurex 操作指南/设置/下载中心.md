# 飞书文档：下载中心


## 功能介绍

下载中心近30天的下载记录，当有查看下载记录，与再次下载文件的需求，可以进入该菜单进行查看。

## 操作指南

### 页面说明

1. 操作路径【设置】-【系统管理】-【下载中心】
2. 用户最近30天，在系统中所有下载记录，都在此处展示。点击下载按钮们可以再次下载该文件。
3. 下载中心也可以通过右上角点击下载按钮，快速进入。
