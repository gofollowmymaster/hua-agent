# 飞书文档：角色管理



## 功能介绍

角色管理作为系统的重要基座主要负责管理和控制系统中不同用户角色的权限和访问级别。

## 注意事项

1. 拥有此模块权限的账号允许修改和分配其他账号的角色权限，请谨慎分配。
2. 超级管理员和初始化角色为系统内置角色，权限不可修改，超级管理员默认拥有系统全部权限，初始化角色默认无权限。

## 操作流程


#### 操作路径

【设置】-【账号管理】-【角色管理】

![系统中“角色管理”页面。下方是角色列表，显示角色名称、联系邮箱、联系电话、状态及操作等信息，其中“超级管理员”角色被红框突出显示。](./assets/images/图片展示的是系统中“角色管理”页面-c839da014062.png)

#### 点击角色列表右上角的【新增角色】，展开弹窗

![系统中“角色管理”页面。页面中部显示“角色管理”标题，下方有“新增角色”按钮，其右侧有红色箭头指向。](./assets/images/图片展示的是系统中“角色管理”页面-0d974517f556.png)

![“角色管理”页面截图，展示“点击角色列表右上角的【新增角色】，展开弹窗”的功能入口和操作区域。](./assets/images/图片展示的是在-自动生成-721a2956ca99.png)

#### 输入角色名称和角色描述，点击确认

![角色管理中新建角色的操作界面。窗口右下角有“取消”和“确定”按钮，其中“确定”按钮被红色框突出显示。](./assets/images/图片展示的是角色管理中新建角色的操作界面-0ae77307b816.png)

#### 角色创建成功后，点击此角色可以查看此角色的详情，对角色进行编辑和删除操作。

![系统中“角色管理”页面，左侧为功能导航栏，右侧是角色列表。页面右侧操作栏有“批量操作”按钮。](./assets/images/图片展示的是系统中“角色管理”页面-2c3c7502a06b.png)


#### 选择对应角色，切换到【功能权限】，根据业务情况勾选需要分配给此角色的权限，勾选完成后点击【保存】即可生效。

![“角色管理”页面截图，展示“选择对应角色，切换到【功能权限】，根据业务情况勾选需要分配给此角色的权限”的功能入口和操作区域。](./assets/images/图片展示文档中-24d5eb1912e3.png)

![角色管理界面中“功能权限”页面。页面中部显示了多个功能权限选项，如“订单管理”“商品管理”等，每个选项右侧有多个权限选项，如“新增”“删除”等，部分权限前有勾选标志。](./assets/images/图片展示的是角色管理界面中“功能权限”页-d2a09f1de842.png)


选中左侧角色，进入数据权限，根据菜单勾选需要分配给此角色的数据权限。

数据权限是基于产品SKU进行配置，可至商品中心分配产品负责人。

可选配置项：

1. 全部可见：拥有所有SKU的数据权限
2. 负责人可见：拥有“自己”所负责产品SKU的数据权限
3. 部分可见：拥有“自己”和“选择产品负责人”所负责产品SKU的数据权限

![角色管理中新建及修改角色的操作界面。右侧功能权限部分，有全部可见、负责人可见、部分可见权限范围，以及快速设置按钮。](./assets/images/图片展示的是角色管理中新建及修改角色的操-1744d34abcad.png)

快速设置：

1. 第一步：页面支持多选快速配置，勾选需要配置的菜单，在上方选择批量设置的权限范围。
2. 第二步：点击快速设置按钮，则被勾选的菜单，全部配置为所选权限范围。
3. 第三步：点击页面右上角保存按钮，完成配置。

![角色管理中为用户分配角色的操作界面。箭头分别指向“权限配置”选项、右侧“保存”按钮及页面右上角“保存”按钮，突出操作关键步骤，与上下文介绍的为用户分配角色操作流程相呼应。](./assets/images/图片展示了角色管理中为用户分配角色的操作-176a59b4a626.png)


#### 选择对应角色，在【角色用户页面】，点击【新增用户】

![在【角色用户页面】点击【新增用户】后弹出的“新增用户”窗口。窗口右下角有“取消”和“确定”两个按钮，其中“确定”按钮被红色框突出显示。](./assets/images/图片展示的是在【角色用户页面】点击【新增-914ef7cea93b.png)

#### 勾选需要赋予此角色的账号，点击确认


#### 点击账号操作栏的【移除】，或勾选账号后点击批量移除

![飞书管理后台中角色管理页面。右侧上方有“角色管理”标题，下方有“新建角色”“角色账户”“功能权限”“数据权限”等选项，其中“角色账户”被红色框突出显示。](./assets/images/图片展示的是飞书管理后台中角色管理页面-eaa4ed03e858.png)
