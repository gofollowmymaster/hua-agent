# 飞书文档：工单管理



## 功能介绍

工单为联系客服寻求帮助的渠道，在使用系统的过程中您遇到任何问题，都可以通过工单管理向我们寻求帮助，我们会尽快为您解决问题。

## 操作流程

### 创建工单

#### 操作入口：点击头像旁的图标进入工单管理

![仪表盘界面，右上角有“工单管理”图标。该图标是创建工单的操作入口，点击后可进入工单管理页面，填写工单标题和类型等信息，向客服寻求帮助。](./assets/images/图片展示了仪表盘界面-3ef6bef1fafe.png)

#### 填写工单

点击页面右上角【创建工单】，填写弹窗内容。

1. 工单标题：简单描述一下您遇到的问题
2. 工单类型：商品、销售、统计、设置模块属于商家运营类型；订单、物流、仓储属于物流仓储类型；财务属于财务类型；非以上模块的问题，请选择其他。
3. 工单详情：请详情描述您遇到的问题
4. 优先级：根据问题的重要性和紧急程度进行优先级的选择，我们会优先处理优先级更高的工单。
5. 上传文件：最好能附带页面截图以便于我们更好帮助您解决问题

![工单创建界面。界面上方有“工单管理”等导航栏，下方是“创建工单”弹窗，包含“工单标题”“工单类型”“工单详情”“优先级”。](./assets/images/图片展示了工单创建界面-f3776853a916.png)

#### 提交工单

点击确认后，工单创建成功，我们将会尽快对工单进行处理

![“工单管理”界面，显示了工单编号、工单类型、优先级、上次回复时间、发起人、工单类型、创建时间、当前管理人等信息。](./assets/images/图片展示的是“工单管理”界面-d9b3a54f369f.png)

### 回复工单

#### 回复工单

当您需要回复工单内容或者有追加的信息，可以点击工单操作栏的【回复】，或者进入详情页直接回复。

![工单管理系统界面，显示有工单编号、工单标题、优先级等信息。“操作”列下有一个操作项被红色箭头指向，结合上文可知该操作项应为“回复”，用于当用户需要回复工单内容或有追加信息时，点击进行回复操作。](./assets/images/图片展示了工单管理系统界面-b2cfcc5bd213.png)

### 关闭工单

![工单管理界面。操作栏有“催办工”“详情”“置顶”“删除”等选项，其中“关闭工单”按钮被红色箭头突出显示。](./assets/images/图片展示的是工单管理界面-8473bee966f0.png)

#### 关闭工单

当工单问题已经被解决或者您不想再针对此问题发沟通时，您可以关闭工单，注意：工单关闭后双方都无法再发起回复。

![工单管理界面中关闭工单的操作提示框。框内以红色框线突出显示“该工单无法关闭工单问题”，并有“取消”和“确定”两个按钮。](./assets/images/图片展示的是工单管理界面中关闭工单的操作-f9668f443990.png)

### 催办工单

#### 催办工单

当您发起了工单，超过一个工作日还没有收到回复时，您可以使用催办功能。

点击工单操作区域的【催办】，输入催办原因并提交，此条工单将会指定，并显示催办标识，直到收到回复后催办状态才会消失，下次仍然可以对此工单催办。

![在表单系统中“工单管理”页面。](./assets/images/图片展示的是在表单系统中“工单管理”页面-9b301e755c79.png)
