# 飞书文档：用户管理



## 功能介绍

用户管理是系统的基本功能和重要组成部分，通过用户管理功能可以快速维护登录系统的用户信息，并根据用户信息维护用户的操作权限和数据权限。

## 内置角色

1. **超级管理员**

超级管理员拥有对系统的完全访问权限，可以执行任何操作，组织的拥有者默认为超级管理员角色且不可移除。

1. **初始化用户角色**

初始用户角色被设定为无权限角色，其访问权限仅限于个人中心页面。当某个账户的所有角色被撤销时，系统会自动赋予其初始用户角色作为备选。值得注意的是，初始用户角色是不可删除的，一旦某账户被赋予了这一角色，您可以选择为该账户分配其他权限的角色，而一旦成功分配，初始用户角色将会自动失效，不再显示于该账户的角色列表中。

## 操作流程


### 操作路径

【设置】-【账号管理】-【用户管理】

![用户管理页面。页面中部显示用户名称、账号ID、联系邮箱、联系电话、角色、状态、创建时间等信息，其中“联系邮箱”有红色箭头指向。](./assets/images/图片展示了用户管理页面-3bb8285e0c96.png)

### 新增用户

点击页面【新增用户】，填写新用户的邮箱号，为其分配角色。

注：邮箱号需可以接收邮件。

![用户管理界面，右上角有“新增用户”按钮，被红色箭头指向突出显示。](./assets/images/图片展示的是用户管理界面-7f6a21dddeea.png)

![用户管理中新增用户界面。界面中“联系邮箱”输入框被红色框突出显示，提示需填写新用户的邮箱号，且邮箱号需可接收邮件；“角色”下拉菜单被红色箭头指向，显示当前选中“活跃用户”。](./assets/images/图片展示了用户管理中新增用户界面-bb0467c9e2ee.png)

### 激活账号

确认后，告知用户查收激活邮件，根据邮件步骤进行账号的激活。

### 激活后账号生效。


### 冻结或启用账号

管理员可以控制子账号冻结或启用，如需限制某个子账号的使用权，可以将账号冻结，冻结行为可逆。

![用户管理界面。右侧有两个红框标识的操作选项，分别为“重置密码”和“查看明细”。](./assets/images/图片展示了用户管理界面-14e0765dda06.png)

### 重置密码

若子账号忘记密码无法登录，也无法接收验证码，可以在此模块重置密码。

![用户管理页面。页面中部显示用户信息列表，包含用户名、编号、联系邮箱、服务电话、角色、状态、创建时间等信息，部分邮箱号和电话号被。](./assets/images/图片展示的是用户管理页面-31dd8f57742e.png)

![用户管理中子账号管理模块下重置密码的界面。窗口右下方有“取消”和“确定”两个操作按钮，其中“确定”按钮有红色箭头指向。](./assets/images/图片展示了用户管理中子账号管理模块下重置-00302c4cee1f.png)
