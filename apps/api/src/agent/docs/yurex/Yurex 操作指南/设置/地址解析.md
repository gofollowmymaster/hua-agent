地址解析

## 功能介绍

解析DF订单收货地址增值服务。

当开通此服务后，系统会自动解析面单收货信息，将解析后的收货人姓名、地址等显示在DF货件单列表。

## 页面路径

【设置】- 【增值服务】-【地址解析】

## 注意事项

此为付费定制服务，计费标准请参考地址解析服务说明

1. 一个货件单解析成功，只收取一次解析费用，解析失败不收取费用
2. 若DF订单的发货仓库类型为平台仓/自营仓，系统将自动解析该订单的Shipping label，且不收取解析费用

## 系统流程

## 操作指南

1. 功能描述：开通/关闭解析地址增值服务
2. 操作步骤：

 1. 依次点击【设置】-【增值服务】-【地址解析】按钮

 ![地址解析功能的页面。左侧导航栏中“设置”选项被红色框突出显示。](./assets/images/图片展示了地址解析功能的页面-0dce0346d6e5.png)

 1. 开通服务：点击【开通服务】按钮

 ![地址解析服务开通页面。中间区域有“开通服务”“关闭服务”“查询开通记录”“计费解析次数/总解析次数明细”“导出详情”等操作按钮，其中“开通服务”按钮被红色框突出显示。](./assets/images/图片展示的是地址解析服务开通页面-7decf8d7b240.png)

 1. 开通服务：在二次弹窗中，勾选“我已阅读并同意《亚马逊DF数据保护政策》”后，点击【立即开通】按钮，开通成功，状态更新为“已开通”

 ![亚马逊地址解析服务中“数据保护政策”的弹窗界面。](./assets/images/图片展示的是亚马逊地址解析服务中“数据保-8619030c0190.png)

 ![地址解析服务的页面。](./assets/images/图片展示的是地址解析服务的页面-61fbb7520965.png)

 ![地址解析服务开通页面。页面右上角有“开通服务”按钮，用于开通地址解析增值服务，该按钮被红色框突出显示。](./assets/images/图片展示的是地址解析服务开通页面-e566f14a2f42.png)
