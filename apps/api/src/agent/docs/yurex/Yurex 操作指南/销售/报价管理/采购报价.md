# 飞书文档：采购报价



## 功能介绍

采购报价，该模块的目的是为某产品按照业务模式PO、DF分别制定MSRP和平台采购价；由贵司发起报价申请后，我司平台运营经理进行审核，审核通过后贵司再确认是否接受该产品的平台采购价；若您接受，则我司后续将以此价格采购或结算贵司的产品，若您拒绝此报价，也可重新为该产品发起新的报价。

## 注意事项

1. 添加报价入口：

 1. 【商品】-【商品管理】-【新增产品】
 2. 【销售】-【报价管理】-【采购报价】-【申请报价】-【添加报价】
 3. 【销售】-【报价管理】-【采购报价】-【申请报价】-【批量报价】
2. 添加报价前，请您先至【商品】-【商品管理】-【新增产品】申请产品，报价是针对商品列表已生效的产品才能进行报价的申请（若未先申请商品，请您先至【商品】-【商品管理】-【新增产品】，审核通过后即可申请报价。）；
3. 请您注意添加报价时，带【 \* 】为必填项，输入的价格最多为99999.99USD；
4. 申请报价需分别按照PO/DF单独进行报价的申请；
5. **请您务必注意：报价单生效后将不能修改任何信息，请您在提交报价前确认好您的报价信息是否输入正确，感谢您的支持！**
6. 【期望平台采购价】可输入您期望的采购价格，该价格将作为我们制定采购价格的参考标准之一；
7. 【申请报价】字段说明：

 1. 制造商建议零售价（MSRP）：表示该产品将在亚马逊listing页面进行售卖的价格；
 2. 期望平台采购价：指您希望我们以什么样的价格采购您的产品；
 3. 渠道站点：表示该报价单是针对具体的某一个渠道站点进行的报价；
 4. 是否SC销售：

 1. 是：表示该产品曾在亚马逊进行过售卖，需要您输入相关的信息；
 2. 否：表示该产品未曾在亚马逊进行过售卖；
 5. SC Referral Fee Rate：品牌佣金费率，请您根据产品实际情况填写，该费率将作为我们制定采购价格参考标准之一；
 6. SC Fulfillment Fee：物流配送费，请您根据产品实际情况填写，该费用将作为我们制定采购价格参考标准之一；
 7. 退货率：请您根据产品实际情况填写，该费率将作为我们制定采购价格参考标准之一；
 8. 过去一年销售额/过去一年平均售价：请您根据产品实际情况填写，该内容将作为我们制定采购价格参考标准之一。

 > 1. 可通过SKU/ASIN/商品名称/业务模式或其他条件搜索您所需要的数据
 > 2. 列表可直接查看具体业务模式下的价格信息，若需查看更多价格相关信息，可点击“详情”进行查看；
 > 3. **？显示为未通过/已拒绝的原因；**
 > 4. 列表分为2个Tab页，点击可进行切换：全部、待确认报价；

### 申请路径1【商品】-【商品管理】-【新增产品】

> 1. 输入对应的产品具体信息以及报价信息，若页面报错，请您根据报错提示进行处理；
> 2. PO/DF需分别进行报价，输入【MSRP】后，点击提交会进行必填项的校验，若仅提交了其中一个业务模式的报价，仅成功提交一个，余下业务模式报价需单独申请；
> 3. 若您未填写任何【报价信息】中的任何数据，需待商品审核通过后，通过【采购报价】单独申请报价；
> 4. 输入完成后，请点击【提交】
>
> 1. **商品是草稿状态以及不是“已生效”的状态下，采购报价不会生成报价数据，待商品是“已生效”的状态后，【采购报价】将自动生成对应数据。**

### 单个新增报价

申请路径3【销售】-【报价管理】-【采购报价】-【页面单个新增】

> 1. 文本框输入/列表选择对应产品数据，支持通过SKU/MSKU进行搜索；
> 2. 选择产品后根据所需申报的【业务模式】的报价类型，输入对应的报价信息，点击【提交】，提交成功后列表会生成对应的报价单，您可以随时查看报价单状态；
> 3. 【PO/DF销售价格制定】下“是否报价”选择说明：
>
> 1. 选择“是”表示对该业务模式进行报价；
> 2. 选择“否”表示暂不对该业务模式进行报价，未报价的情况下，无法进行VC listing跟卖操作；
> 4. 销售价格参考信息仅需填写一次；
> 5. 填写完成后，点击“提交”，若填写错误，请根据提示调整后重新提交。

### 申请路径4【销售】-【报价管理】-【申请报价】-【批量报价】

> 1. 若您已经提前下载好对应模板，可直接点击【上传文件】选择文件并确定；若需要获取最新的批量报价模板，请您点击【下载模板】

> 1. 若您直接点击的“取消’，表示放弃此次批量报价的操作，”校验成功“的数据，也不会生成对应的报价单，需重新进行申请；

### 重新报价

操作路径【销售】-【报价管理】-【采购报价】-【未通过/已拒绝】-【重新报价】

> 1. 针对【未通过/已拒绝】的报价，可再次发起报价的申请，提交后我们将为您重新制定采购价格；
> 2. 调整完报价信息后，请您点击【提交】；
> 3. 若两个业务模式均可重新报价，支持快捷批量重新报价，同时销售信息支持重新输入；
> 4. 若仅一个业务模式支持重新报价，仅需填写价格信息，销售信息暂不支持调整，待报价生效后，可通过【编辑销售信息】修改。

- 商品中心，针对已驳回的商品，您可以进行删除，删除商品后若存在对应的报价，将自动同步删除对应的报价信息。您可以重新进行【新增产品】的操作，录入商品与报价信息。
