Best Deals

当前版本v3.1.1

## 功能介绍

Best Deal指的是亚马逊平台上的特别优惠活动，属于Promotions中其中一种活动，包括折扣、促销和其他优惠方式，让消费者以更优惠的价格购买商品。

## 注意事项

参考文档：

1. 单个ASIN参加的促销活动在Promotions中会存在互斥，创建的时候需要注意
2. Best Deal的活动时间最长为31天，请注意活动时间
3. 亚马逊对Best Deal的参加条件较为严格，建议提高产品Listing页面与销量让产品达到参与活动的标准

#### 进入编辑页面，系统默认填充活动相关信息，如果活动有报错，会展示报错信息

> - 页面相关检验规则与创建功能一致，请参考
> - 活动类型，不支持修改，比如：当前活动类型是普通活动，不能修改为Prime Day等特殊活动
> - 活动起止日期：仅活动开始日期大于当天时，才支持修改活动开始日期，并且只能调大，不能调小
> - 库存数量：“生效中”和“异常”状态不支持修改，“待生效”支持修改，可调大也可调小
> - 折扣金额：值必须在获取到的Min和Max值之间，“待生效”支持调大调小，“生效中”和“异常”状态仅支持调大不能调小
> - 已经开始的活动，不管是“生效中”还是“异常”状态，都不支持删除产品，只有在活动还未开始时，支持删除
> - 已存在的产品，不支持重新获取参考价，如果获取失败，可以关闭窗口，重新进入
