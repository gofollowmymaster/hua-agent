# 飞书文档：优惠券



## 功能介绍

Coupon是指优惠券促销活动，消费者领取优惠券后，结算时可享受专属优惠。

## 注意事项

1. 每个ASIN在同一个时间段内只能存在一个活动组，请注意优惠券的活动起止时间
2. 优惠券可与Promotions存在同个时间段内的活动
3. 亚马逊对创建优惠券活动的ASIN有一定条件，若创建失败，请提升产品的竞争力
4. 优惠券名称会自动生成唯一值

## 操作流程


### 操作路径

【销售】-【营销推广】-【优惠券】

![亚马逊平台优惠券管理界面。左侧导航栏中“优惠券”选项被红色框突出显示。](./assets/images/图片展示了亚马逊平台优惠券管理界面-698dac52d588.png)

### 点击【创建Coupon】

![亚马逊卖家后台端优惠券管理界面。左侧导航栏中“优惠券”选项被红色箭头突出显示。](./assets/images/图片展示了亚马逊卖家后台端优惠券管理界面-3e53d93f4c58.png)

### 填写基本信息

1. 一条ASIN表示一张优惠券
2. 需填写ASIN、折扣、预算、Amazon显示名称、活动起止日期、是否领取一次
3. 最多可添加20个ASIN

![亚马逊优惠券创建页面。中间部分是填写基本信息区域，有ASIN、SKU、List Price、折扣、Amazon显示名称、活动起止日期、是否领取等必填项。](./assets/images/图片展示的是亚马逊优惠券创建页面-b2b6903b316d.png)

### 提交 Coupon

填写完成后，点击【提交】

![亚马逊优惠券创建页面。下方是Coupon列表，显示ASIN、SKU、List Price、折扣、Amazon显示名称、预算、活动起止日期等信息，每行右侧有“编辑”按钮。](./assets/images/图片展示的是亚马逊优惠券创建页面-31671ce1fd62.png)

### 创建失败

创建失败的Coupon，支持删除或编辑后再提交

![亚马逊平台优惠券创建页面。上方有“Coupon”标题，下方有“产品信息”“编辑规则”“活动起止日期”等板块，其中“产品信息”板块有ASIN输入框。](./assets/images/图片展示的是亚马逊平台优惠券创建页面-72987cdda686.png)

创建Coupon超时，支持点击确认再次提交

### Coupon 被抑制

### 预算使用率≥80%，系统自动发送站内通知

![显示了一条站内通知，内容为Coupon预算使用率已达80%，请及时处理。，通知时间为2024 - 10 - 29 18:11:05，下方列出了对应的ASIN和Promotion ID（具体内容被模糊处理）。](./assets/images/图片显示了一条站内通知-c7be53cd3ebd.png)
