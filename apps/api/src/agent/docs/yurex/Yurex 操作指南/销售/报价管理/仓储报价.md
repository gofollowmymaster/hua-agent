仓储报价

## 功能介绍

该模块旨在帮助运营和客户测算出仓储各费用明细，客户根据自身业务情况估算费用选择仓储方案。包括入库费、仓储费、出库费（B2C 出库和 B2B 出库）的费项、计费单位、计算规则及备注

## 注意事项

1. 装箱数量和箱数需填写整数，如填写小数，则采用四舍五入法为整数；
2. 当前版本暂无法支持物流费用测算。

## 操作流程

##

#### 操作路径

【销售】-【报价管理】-【仓储报价】

![图片展示了某平台的左侧导航栏界面。导航栏中“销售”选项被红色框和箭头突出显示。在“销售”选项下，有“报价管理”“调价管理”“仓储报价”“报价测算”等子选项，其中“仓储报价”被红色框和箭头标注。该图片与文档中“操作流程”部分的“操作路径”内容相关，直观呈现了进入“仓储报价”操作的路径，即从左侧导航栏的“销售”选项进入“仓储报价”选项。](./assets/images/图片展示了某平台的左侧导航栏界面-28a6c4df094a.png)

#### 填写【费用测算】左侧的必填项，点击【费用测算】

1. 仓库地区请根据实际情况选择，不同仓库地区对应的价格不同。
2. 产品/外箱尺寸/重量单位为**英制**
3. FBA/一件代发的费用测算分别对应B2B/B2C出库，对应的物流费用不在测算范围中。

![图片展示的是仓储报价系统中【费用测算】的操作界面。左侧红框区域为【费用测算】的必填项填写区域，包括仓库地区、产品/外箱尺寸、重量等信息（单位为英制），并有FBA/一件代发等选项。下方有黑色的【费用测算】按钮，用红色箭头指向突出显示。右侧为测算结果区域，展示了【仓储费】、【出、入库费用】等数据。该图片与上文提到的填写【费用测算】左侧必填项并点击【费用测算】操作流程相对应。](./assets/images/图片展示的是仓储报价系统中【费用测算】的-04567201e385.png)

修改测算数据后，需重新点击【费用测算】，测算结果才会进行更新。
