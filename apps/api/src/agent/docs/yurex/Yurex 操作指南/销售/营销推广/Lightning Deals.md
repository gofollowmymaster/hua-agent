# 飞书文档：Lightning Deals



## 功能介绍

Lightning Deal，简称LD，是亚马逊交易页面上限时的价格折扣活动，4至12小时，具体时长由亚马逊决定，SC卖家称之为秒杀

## 注意事项

1. 需提前3天提报Lightning Deal，比如现在是站点时间1月15号，那么Lightning Deal最早只能1月18号开始
2. Lightning Deal时长：通常为4至12小时，具体时长由亚马逊决定
3. 在同一促销时间段内，产品不能与Best Deal、Price Discount重叠参与
4. 不允许在7天内或Amazon指定的时间段内，对同一产品进行连续的秒杀活动
5. Lightning Deal报名费用：常规时间秒杀促销费用为150USD，特殊促销节点300～500USD不等
6. 如果创建Lightning Deal时，产品的ListPrice（建议零售价/MSRP）≠ Reference price（参考价），可能会出现下一轮Lightning Deal参考价变动，引发亚马逊抑制导致后续Lightning Deal提报受限，请谨慎提报

### 进入编辑页面，系统默认填充活动相关信息，如果活动有报错，会展示报错信息

> - 页面相关检验规则与创建功能一致，请参考
> - 活动类型，不支持修改，比如：当前活动类型是普通活动，不能修改为Prime Day等特殊活动
> - 秒杀活动日期：仅日期大于当天时，才支持修改，并且只能调大，不能调小
> - 库存数量：“生效中”和“异常”状态不支持修改，“待生效”支持修改，可调大也可调小
> - 折扣金额：值必须在获取到的Min和Max值之间，“待生效”支持调大调小，“生效中”和“异常”状态仅支持调大不能调小
> - 已经开始的活动，不管是“生效中”还是“异常”状态，都不支持删除产品，只有在活动还未开始时，支持删除
> - 已存在的产品，不支持重新获取参考价，如果获取失败，可以关闭窗口，重新进入
