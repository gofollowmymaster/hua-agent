仪表盘

当前版本：V2.0.0

## 功能介绍

仪表盘能够直观地呈现各类关键数据，提供精准的数据支持，助力实现高效决策。它可以全面监控销售动态、库存情况等多个重要方面，从而切实提升运营效率，增强企业在市场中的竞争力。

## 注意事项

1. 仪表盘内的数据指标来自于不同的模块，可能会存在一定的更新时差。
2. 数据更新时间可以参考板块右上角的统计日期，若没有统计日期表示此板块会实时更新，您查看到的已经是当时的最新数据。
