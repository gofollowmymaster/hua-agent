# 飞书文档：BTR销售进度监控



## 功能介绍

BTR整体情况：整合系统所有BTR订单各项指标、售罄时长分布及状态和售卖率占比情况

销售中BTR情况：统计系统进行中状态的BTR订单指标及售卖情况统计分析

## 页面路径

【仪表盘】-【订单】-【BTR销售进度监控】

## 操作流程

### BTR整体情况

1. 功能描述/操作步骤：默认显示全部BTR订单的各项指标及占比分析

 1. 可根据顶部筛选项查询对应维度的BTR数据情况

 ![BTR销售进度监控页面。页面上方有“BTR销售进度监控”标题及“BTR整体情况操作流程”说明。](./assets/images/图片展示的是BTR销售进度监控页面-b022edd7ae43.png)

### 销售中BTR情况

1. 功能描述/操作步骤：默认显示进行中状态的BTR订单各项指标及销售情况

 1. 顶部点击“销售中BTR情况”tab标签，显示订单状态=进行中的BTR销售情况看板

 ![BTR销售进度监控页面。页面上方有筛选项，可按订单状态、订单类型、订单来源、订单来源平台、订单来源平台等条件筛选。](./assets/images/图片展示的是BTR销售进度监控页面-fec7d46b66ed.png)
