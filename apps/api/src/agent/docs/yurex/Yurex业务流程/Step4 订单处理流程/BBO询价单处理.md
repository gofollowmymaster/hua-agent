# 飞书文档：BBO询价单处理

## BBO询价单处理

BBO，全称Bulk Buy Offer，亚马逊批量采购询价单，是在现有PO供货价的基础上，提供更多的采购数量以及更长的备货时间，以换取更低供货价的PO订单。当卖家接受BBO报价后，亚马逊会在BBO询价结束后下发采购订单，BBO-PO 接单、发货流程同正常PO一致。
