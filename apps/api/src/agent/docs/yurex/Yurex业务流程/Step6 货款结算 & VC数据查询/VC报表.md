# 飞书文档：VC报表


## 销售分析

## 操作步骤：【统计】-【销售分析】

销售分析数据源于亚马逊销售报表&品牌分析报表，Yurex将数据按不同维度拆分为以下功能模块：
1. 销量看板：销售与流量数据二合一。支持多时间维度（日/周/月等）筛选与联动分析，精准洞察销售趋势。
2. 实时销量：追踪过去 72 小时数据（小时级实时更新），帮助您快速掌握动销，敏捷调整策略。
3. 销量预测： 展示亚马逊未来 30 周预测数据。虽不等于最终 PO 单量，但为备货计划提供重要参考。
4. 库存报表：展示VC库存，细分展示可售库存、不可售库存（残损/退货）、 90 天以上滞销库存等。
5. 类目报表：展示所有Offer的类目归属及补货状态，卖家可在此监控，防止类目错误导致流量异常。
6. ABA搜索词：同步亚马逊热门搜索词数据，为Offer 优化、关键词收录、广告选词等提供官方依据。

### 销量看板

支持查看 ASIN 或品牌的历史销售趋势，可通过“添加指标”丰富图表维度。

注意：

- 历史数据会动态更新，请以当前显示为准
- PO 销量/销售额均已扣除 DF 订单，仅供参考

![“销售分析”页面。](./assets/images/图片展示的是亚马逊VC报表中“销售分析”-d8ebee0e59f2.png)

### 实时销量

源自亚马逊VC后台 Real time sales 报表，统计近 3 天/72h销量与销售额。

注意：

- 当天： 0点至最新1h的累计数据
- 前两天： 2\*24h=48h的完整2天数据

![“实时销量”页面。](./assets/images/图片展示的是“实时销量”页面-60385262a399.png)

### 销量预测

展示亚马逊未来 30 周的销量预测数据。

注意： 预测值仅供备货参考，不代表最终 PO 采购量。

![亚马逊VC后台的销量预测页面。](./assets/images/图片展示的是亚马逊VC后台的销量预测页面-233873f2583e.png)

### 库存报表

VC库存概览： 含在库、在途及滞销等数据。

![“销售分析”页面。](./assets/images/图片展示了VC报表中“销售分析”下的“库-0d49f0654e3b.png)

### 类目报表

展示各 ASIN 的类目及上线时间。

注意： 仅显示ASIN最新类目相关数据，不支持历史查询。

![“类目报表”页面。红框标注“产品类目”、“产品上线时间”。](./assets/images/图片展示了VC报表中“类目报表”的界面-e617ad1a3013.png)

### ABA搜索词

展示搜索词排名（值越小热度越高）、趋势变动，以及 TOP3 商品的点击与转化份额明细。

![ABA搜索词报表界面。](./assets/images/图片展示的是ABA搜索词报表界面-571d935ec116.png)

## 仓库分析

## 操作步骤：【统计】-【仓库分析】

### 在途库存分析

追踪海外仓录入Yurex系统的在途库存详情&预计送达时间。

注意：未录入本系统内的库存情况未知。

![在途库存分析界面。左侧有“商品”“物流”“统计”等导航栏。界面中部显示在途库存数量为4，有产品ID、入库批文号、仓库、仓库类型、预计到达日期、在途库存数量等信息。](./assets/images/图片展示的是在途库存分析界面-8dad5b9172ae.png)

#### 汇总

支持多维度筛选，默认按库龄区间统计库存总量及分布。

![“超库龄分析”汇总页面。页面左侧有导航栏，选中“超库龄分析”。右侧上方有“汇总”“明细”选项卡，当前选中“汇总”。](./assets/images/图片展示的是“超库龄分析”汇总页面-1598f2a46a59.png)
