# 飞书文档：VC渠道备货指南


## **一、目的**

1. 我们将为所有Yurex平台入驻供应商，根据不同发展阶段、产品类别及销售周期，提供系统化的VC模式备货方案参考。
2. 请各供应商依据自身品牌定位与商品特性，合理规划备货安排。
3. 借助平台数据工具，实现精准库存管理，优化备货效率，在减少缺货率与仓储费用的同时，促进利润持续增长。

## 二、合理备货的重要性

1. 亚马逊对库存周转要求高，断货/积压都会影响排名与利润
2. 不同运营阶段的供应商在备货上策略不同
3. 不同类目（季节性/非季节性）备货逻辑不同

## 三、供应商类型

| **发展阶段** | **核心特征** |
|-|-|
| **新手期** | 已初步掌握Yurex系统操作，并顺利完成商品由SC模式向VC模式的转换 |
| **成长期** | 具备VC商品的推广能力，能够实现订单的周度稳定增长并保持销售增速 |
| **稳健期** | 进入成熟运营阶段，主要聚焦于新品持续拓展与盈利结构优化 |

## 四、多维度备货策略

以下备货建议仅供参考，请供应商根据自身情况做灵活调整

### 针对不同阶段供应商的备货建议

#### **新手期供应商的首单订货策略**

若产品呈现明显增长趋势，可参考成长期供应商的备货策略进行后续规划。

#### **成长期供应商备货策略**

对于销售趋势显著提升的商品，当根据7天动销推算出海外仓在库+VC在途+VC在库的库存天数小于备货周期+海运周期时，库存预警，开始下返单（国内采购单）。

1. （海外仓+VC在途库存+VC仓库存）÷ 最近7天动销=库存天数
2. 补货下单决策依据：

 - 参考近7天实际销售情况；
 - 结合后续已规划的平台促销活动预期销量；
 - 补货量需至少满足覆盖国内备货与海运全程的时间需求。
3. 当产品销售趋于稳定，应每月定期审视补货计划，并逐步建立滚动式连续补货机制。

#### **稳健期供应商备货策略**

该阶段供应商应建立以月度为基础的滚动补货计划，确保库存持续供应与销售节奏的匹配。

1. 滚动返单依据：

 1. 为实现预期排名而需维持的日常销售水平；
 2. 针对大促期间（如Prime Day、PBDD、黑五网一等）的折扣促销销售节奏；
 3. 商品所处细分市场的整体波动趋势与增长情况。
2. 全年销售预测与安全库存规划：制定VC渠道的年度销售预测，并基于此规划安全库存：

 - 销售淡季：每两个月备置相当于半个月销量的安全库存；
 - 销售旺季：每月备置相当于一个月销量的安全库存；
 - 定期对销售预测与库存规划进行合理性评审（需使用全年销售预测模板进行系统管理）。
3. 优化仓储布局：在美国主要区域（美西、美东、美南）合理设置海外仓，缩短货物从海外仓发往亚马逊VC仓库的中段运输时间，同时尽可能避免货物被亚马逊系统进行跨区域分仓发货，以提升物流效率与控制成本。

### 销售周期维度备货策略

#### 全新产品链接入驻（无对应SC产品在售）：

1. 若供应商已有同类产品销售记录，可参考历史销量数据，首次备货量为预计2-3个月的销售量。
2. 若供应商无类似产品可作参考，则需结合市场规模、产品竞争力及竞品排名情况，首次备货量建议为预计1.5-2个月的销售量。

#### SC新品期入驻（上架90天内，已有SC在售）：

1. 备货量可参考公式：SC近7日日均销量 × 调节系数（1.1\~2.5） × 备货周期

 1. PO模式下备货周期 = 生产交期（下单至港口开船）+ 海运时间 + 提货入仓时间 + VC仓接收时间
 2. DF模式下备货周期 = 生产交期（下单至港口开船）+ 海运时间 + 提货入仓时间
2. 若动销表现良好（预计销量增长1.5\~2.5倍），建议提前3个月制定备货计划，审核后向工厂下单，并实施月度滚动补货。
3. 若动销表现一般（预计销量增长1.1\~1.5倍），且库存天数超过90天，则暂缓补货，待库存天数降至90天以下时重新制定备货计划，并评估该产品是否继续在VC渠道销售。

*注：上述涨幅系数仅供参考，请结合具体产品的生产与销售安排进行调整。*

#### SC成熟期产品入驻（上架超过90天，已有SC在售）：

1. 在销售淡季，建议提前3个月制定备货计划，审核后按月滚动下单。
2. 在销售旺季，同样提前3个月制定备货计划，按月滚动下单，并为旺季每月额外增加1个月的安全库存。

## 四、旺季大促筹备时间节点

VC提报deal的截止时间更晚，操作deal的空间更大。11月的BFCM的DEAL最迟提报时间可以在10月份进行提报。（\*数据来源于2024年VC提报deal截止时间，仅供参考。具体当年度的提报截止时间以当年度的提报规则为准）

## 五、亚马逊平台下PO逻辑

1. 库存覆盖周数基准：平台通常要求供应商库存可维持8-10周的销售，计算方式为：VC总库存 / 周均销量。
2. 头部产品库存要求：对于销售表现突出的产品，在仓库容量允许的情况下，平台可能将库存覆盖周数提升至8-12周，并相应提前8周下达采购订单。
3. 现有库存水平的影响：若VC仓库可用库存较少，未达到平台设定的库存覆盖周数，平台会增加单次采购订单的数量以补齐缺口。
4. 销量驱动的订单策略：产品销量越高，平台要求的库存覆盖周数可能越长，部分畅销品的库存覆盖周数可延伸至12周以上。

1. 可售库存周数说明：

1. 补充说明：补货周期定义：

 - 当（海外仓库存 + VC在途库存 + VC在库库存） ÷ 最近7天日均销量计算得出的“库存可销天数”，低于DF模式下的补货周期（DF-LT）时，供应商应依据后续已规划的促销活动情况，同步审核并启动补货下单流程。

 - PO模式补货周期 = 生产交期（工厂下单至港口开船）+ 海运时间 + 提货入仓时间 + VC仓库接收时间
 - DF模式补货周期 = 生产交期（工厂下单至港口开船）+ 海运时间 + 提货入仓时间

## 七、QA

问：如何在销售旺季确保亚马逊下达足够的采购订单，以应对销量爆发性增长？

答：

1. 无法完全保证亚马逊会下达与目标销量完全匹配的采购订单，供应商最终应关注产品在平台的实际销售表现，是否达到预期销量与排名，而非单纯追求订单数量。
2. 关键仍取决于产品动销情况。亚马逊将依据实际销量与市场需求，向供应商采购约6-8周库存量的货物。
3. 若亚马逊下达的订单量未能满足运营对未来销量的预估，可通过申请BTR（批量订单申请）主动发起补货，同时多承接BBO（批量订单机会），将VC库存补充至满足旺季销售所需水平。
4. 建议提前3个月规划并提交促销活动，覆盖旺季关键时段，并在填写commited units时可适当提高预估数量。
5. 提前3个月开始监测Yurex系统中的“报表-预测报表”数据，结合当前动销情况与往年旺季增长趋势，如未达预期，可尝试向Yurex运营负责人申请刷新FC数据，此举有可能获得系统数据更新。
6. 提升销售表现的方法包括：

 - 提前2个月开展1-2次大幅折扣BD促销；
 - 参与亚马逊联盟计划（如Amazon Influencer Program、Amazon Live、Amazon Post）；
 - 利用广告-创作者计划；
 - 通过站外KOL、测评网站等渠道进行推广。
