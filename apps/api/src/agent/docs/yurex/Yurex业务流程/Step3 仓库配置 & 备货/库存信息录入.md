# 飞书文档：库存信息录入


## 一、库存说明

1. 整箱库存：用于PO模式发货的商家仓可用库存；亚马逊下PO订单都是按照整箱下，发货也是按照整箱出。
2. 散件库存：用于DF模式发货的商家仓可用库存；DF一般都是散货，直接发给C端顾客。

## 二、仓库流程

![仓库及库存配置分支画板：确认使用Yurex平台仓或商家仓。选择商家仓时先配置仓库，再通过新增入库单录入PO整箱库存或DF散件库存，并为DF配置可售库存；选择平台仓时通过入库预约完成PO整箱或DF散件上架，DF散件上架后同样配置DF可售库存。](./assets/whiteboards/二、仓库流程-SG67woYUwhr3sFblOJzcUIJ9nZb.png)

## 三、操作流程

### PO Offer的库存设置

- **操作步骤：**步骤一：【仓储】＞【入库单列表】＞【新增入库单】步骤二：入库类型默认为“其他入库”，库存类型选择“整箱库存”步骤四：查看库存【库存管理】

 - 如果贵司使用的是**商家仓**：

 ![商家仓入库单列表界面。界面上方有“全部”“商品”“销售”“广告”“物流”等分类选项，当前选中“商品”。列表中显示了入库单号、入库单编号、入库类型、预计入库数量、实际入库数量、入库仓库、仓库类型、预计仓到时间、状态等信息，部分入库单状态为“已入库”，部分有“已取消”标识。](./assets/images/图片展示的是商家仓入库单列表界面-716c673e95ed.png)

 ![商家仓新增入库单界面。界面中“库存类型”处显示“整箱库存”，并有红色提示“选择整箱库存用于PC模式发货”。此外，还有“添加产品”按钮，可添加产品信息，如产品ID、产品名称、装箱数量等。](./assets/images/图片展示的是商家仓新增入库单界面-697932938bfb.png)

 步骤三：点击“添加产品”，填写装箱数量和预计入库箱数，点击“提交并入库”即可

 ![商家仓新增入库单页面中“添加产品”部分。页面显示可添加多个产品，已添加1个产品。关键信息是“装箱数量”和“预计入库箱数”两栏，其中“装箱数量”处显示数字6，且有红色框突出显示。](./assets/images/图片展示的是商家仓新增入库单页面中“添加-d36caadd8413.png)

 - 如果贵司使用的是**平台仓**：

 1. 新增入库需要通过**头程预约**，路径为“仓储>入库预约>新增入库预约”，上架方式选择整箱上架。入库预约界面生成数据，审核通过后状态变为“已通过”。
 2. 入库预约完成后，在“仓储管理>入库管理>入库单列表”生成入库数据，入库类型为“采购入库”。

 入库单列表数据状态显示为“已入库”，此时可在“仓储>库存管理”按ASIN搜索，查看当前产品的可用库存。

### DF Offer的库存设置

- **操作步骤：**步骤一：【仓储】＞【入库单列表】＞【新增入库单】步骤二：库存管理步骤三：设置DF可售库存

 - 如果贵司使用的是**商家仓**：路径为“仓储>入库单列表>新增入库单”，入库类型默认为“其他入库”，库存类型选择“散件库存”

 ![“新增入库单”界面，用于商家仓库存信息录入。界面中“预计入库数量”处被红色框突出显示，提示需填写。](./assets/images/图片展示的是“新增入库单”界面-415afcf38d66.png)

 - 如果贵司使用的是**平台仓**：新增入库需要通过**头程预约**，路径为“仓储>入库预约>新增入库预约”，上架方式选择散件上架。

 入库单列表数据状态显示为“已入库”，此时可在“仓储管理>库存管理”按ASIN搜索，查看当前产品的可售库存。

## 注意：

- 入库类型需区分整箱和散件，“整箱库存”用于PO订单发货，“散件库存”用于DF订单发货
- 请于每周五检查Yurex系统可用库存与商家仓实际可用库存数量是否匹配，系统内为虚拟库存数据，并不代表商家仓实际库存情况。此举是为了避免由于信息不匹配导致PO订单接单后无货可发**产生罚款**。
