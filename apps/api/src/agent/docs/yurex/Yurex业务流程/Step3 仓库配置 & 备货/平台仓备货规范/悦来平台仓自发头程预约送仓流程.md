# 飞书文档：悦来平台仓自发头程预约送仓流程


## 预约注意事项

1. 平台仓暂时仅⽀持邮件预约，不接受电话预约。预约前请在客⼾端完 成“确认到港”操作，否则系统⽆法登记预约，会耽误预约送仓时间。
2. 整柜、卡派预约送仓需要⾄少提前2-3⼯作⽇（仓库当地时间），临时预约可能产⽣额外费⽤
3. 修改或取消预约需要至少在所预约送仓日期前2个工作日12:00前联系平台仓履约中心，否则可能产生额外罚款。
4. 整柜、卡派送仓时请务必携带预约码，否则仓库将拒收货物。由此造成的任何费用仓库不承担。
5. 多SKU送仓时，请尽量每个SKU单独打托。

## 预约流程

### 物流商发送邮件向平台仓履约中心进行预约

**预约邮箱：**
[YR-FulfillmentCenter@yurexcc.com](mailto:YR-FulfillmentCenter@yurexcc.com)

**预约需提供信息：**

1. 预约入库ID： WEA-XXXXXXXXX 或者 入库单号：IBXXXXXXXXXX（二者提供一个即可）
2. 柜号（如整柜派送）
3. 铅封号（如整柜派送）
4. 托盘数（如打托送仓）
5. 是否混托（如打托送仓）
6. 预约送仓地址（或者平台仓编码 如：USWE-18 等信息以便平台仓履约中心核实是否派送的仓库和系统数据一致）
7. 预约送仓日期（美国当地日期）

### 平台仓履约中心审核送仓预约

1. 在收到物流商的预约邮件后，仓库将根据实时库容情况对预约送仓的日期进行审核。
2. 送仓预约通常会在工作日期间24小时内回复。

### 预约回执确认

1. 在仓库审核预约日期的库容后，会根据实际情况回复准确的送仓要求和预约码，请以预约回执的送仓时间为准安排货物送仓。
2. 如需修改送仓的日期，在收到预约回执前后，请尽快回复邮件与平台仓履约中心进行协商确认。

## Tips

1. 由于国内外时差问题，预约送仓时请务必记得提供“预约入库 ID”或者“入库单号”（都可在客户端查看），否则可能延误货物送仓。
2. 整柜/卡派模式送仓时，请司机务必携带预约码。
3. 仓库在收货时为避免额外的物流商待时费产生，不会当场清点货物数量，POD不能作为送仓货物数量的证明。如遇实际收货数量与预报货物数量不符，仓库将以实际收货数量为准并配合调查。
4. 如未按照回执邮件信息进行送仓，仓库可能拒收并不承担额外产生的任何费用。如仓库收货可能收取额外的罚款。
5. **重要：**由于美国快递丢件，错误派送率高，西邮平台仓暂不支持快递模式送仓。货物以快递模式送仓时，仓库仅以收货数量为准进行上架。POD不能作为货物准确投递到仓的证明，仓库不会对少件进行赔偿。建议尽量使用卡派和整柜模式送仓。
