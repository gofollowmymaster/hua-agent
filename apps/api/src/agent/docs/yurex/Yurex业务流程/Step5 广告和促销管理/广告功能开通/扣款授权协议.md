## 扣款授权协议

### **扣款授权协议**

本扣款授权协议由您和 **Yurex ChainTech Inc.（以下称“Yurex”）**就扣款授权事宜共同签订，具有法律效力。在使用Yurex账户受托转账服务（下称 “本服务”）前，请您务必审慎阅读并充分理解各条款内容，**特别是免除或者限制责任的条款，免除或者限制责任的条款可能以加粗划线字体显示，您应重点阅读。如您对本授权协议内容及页面提示信息有疑问，请勿进行下一步操作。您在页面通过点击或其他方式确认即表示您已同意本授权协议。**

您登录Yurex广告管理系统后，在页面通过点击或其他方式确认本授权协议即表示您已同意本授权协议全部内容。

#### **一、授权事项**

**您授权并同意Yurex按照亚马逊平台的扣款指令从您Yurex广告账户中划扣资金。请注意，由于您的资金充值可能包含第三方平台手续费，实际您的Yurex广告账户资金以Yurex实际收款到账金额为准。**

其中，您在Yurex广告账户中的资金类型包括：

1. **广告账户保证金 1000 美元**：此保证金只在初次开通广告账户时一次性充值，作为您开展广告业务的信用担保资金。该笔资金不会用作日常广告业务的费用支付，但在特定情况下可能会被用于抵扣您应承担的费用或损失。该笔资金的使用需遵循本协议约定的条件及相关法律法规。
2. **广告账户可用余额（不包括保证金）**：此余额是指您在Yurex广告管理平台中的账户可用余额，用于正常的广告投放及相关费用支付，此余额不包含广告账户保证金。

#### **二、广告账户可用余额使用限制**

1. 广告账户余额**仅可用于您广告投放相关的费用支出，包括但不限于广告投放费用、广告创意制作费用（如有，例如在Yurex平台内定制广告素材所产生的费用）、广告投放效果优化服务费用（如有）等，不得用于其他非广告业务相关的用途或转至其他未经授权的账户。**
2. 在未获得Yurex特别许可的情况下，广告账户余额不得用于支付任何形式的罚款、违约金、赔偿款给第三方（因正常广告投放业务产生的向Yurex或亚马逊支付的违约赔偿款除外）。
3. 若存在多个广告投放项目或活动，广告账户余额应按照您在Yurex广告系统上设置的投放预算分配规则在各项目或活动期间进行使用，**广告账户余额（不包括保证金）应当大于或等于您在Yurex广告账户中的未结账单金额。**

#### **三、广告账户可用余额退还条款**

1. **广告账户可用余额（不包括保证金）退还：**

广告账户可用余额（不包括保证金）支持灵活提现，但需要满足以下条件：

- 您在Yurex广告系统的未结清费用低于广告账户保证金（1000美元）
- 您与Yurex或亚马逊不存在任何纠纷
- 您没有违反本协议的相关约定

**同时满足以上条件后，您可向平台提出广告账户余额（不包括保证金）的提现或退还申请。Yurex审核通过后，将会在 [10个工作日内] 将相应余额退还至您指定的账户。**

**若您在广告投放过程中有“因违规行为被扣除的费用”或“应赔偿的未结清费用”超过广告账户保证金1000美元，Yurex有权在广告账户余额（不包括保证金）中先行扣除相应款项后，再将剩余部分金额退还至您指定账户，如余额不足扣除，Yurex暂不退还且您应另行补足。**

1. **广告账户保证金退还：**

**若您在广告投放期间遵守本协议及相关法律法规，未出现任何违约违法行为，在您终止广告合作关系后，自合作终止日起满 [40天] 且经Yurex确认无任何欠款、潜在风险或纠纷后，Yurex将把广告账户保证金退还至您指定账户。**

**若您存在违反本协议约定的行为，如虚假广告宣传、恶意欠费、侵犯他人权益等，Yurex有权根据违约情节的严重程度，部分或全部扣除广告账户保证金以弥补自身或第三方遭受的损失，剩余保证金（如有）将在上述风险解除后退还至您指定账户。**

1. 您理解并同意，**Yurex只是被授权指令的执行方，对亚马逊向Yurex发出的指令的真实性和准确性不负有审查义务。除非Yurex没有依照亚马逊的指令进行操作，或操作指令错误，否则Yurex不对您使用本服务产生的损失和责任负责。**
