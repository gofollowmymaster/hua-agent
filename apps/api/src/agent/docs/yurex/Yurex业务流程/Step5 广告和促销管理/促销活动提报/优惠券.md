# 飞书文档：优惠券

## 优惠券

### 提报路径：销售→营销推广→优惠券

![某平台的销售模块中优惠券提报路径。左侧为平台导航栏，点击“销售”后，右侧弹出下拉菜单，其中“营销推广”选项下有“优惠券”选项被红色框线突出显示。](./assets/images/图片展示了某平台的销售模块中优惠券提报路-f5ea2c35e962.png)

![亚马逊平台优惠券管理页面。](./assets/images/图片展示的是亚马逊平台优惠券管理页面-51ce9c6c277f.png)

### 详细操作指南

#### 提报条件知悉

![“创建Coupon”页面。](./assets/images/图片展示了创建Coupon页面的“提报注-4c74b4efa482.png)

> - 参与门槛：仅状态为 “生效成功 Offer” 的产品可提报（可跳转至 “Catalog” 核查状态）
> - 提报时效：Coupon需在太平洋时间提前1天创建
> - 活动时长：最短1天，最长30天（每个ASIN在同一个时间段内只能存在一个活动组，请注意优惠券的活动起止时间）
> - 变更限制：活动创建成功后可自行编辑或取消，特殊情况需联系平台运营经理处理

#### 配置Coupon活动信息

![创建Coupon页面。](./assets/images/图片展示的是创建Coupon的界面-e8e160fc28c9.png)

| 配置项 | 操作说明 |
|-|-|
| 选择活动产品 | 选择提报ASIN，点击+添加产品，支持添加多个ASIN批量提报（最多可添加20个ASIN） |
| 设置折扣规则 | 输入折扣比例（%）或折扣金额（USD）：折扣比例 % 范围为5%～50%，折扣金额 USD 必须在当前前台售价的5%～50% off之间 |
| 设置预算 | 输入预算：范围为100.00USD～10,000,000.00USD |
| Amazon前台名称 | 优惠券在Amazon前台页面展示的名称 |
| 选择活动时间 | 自主选择活动开始与结束日期，最短1天，最长30天（每个ASIN在同一个时间段内只能存在一个活动组，请注意优惠券的活动起止时间） |
| 设置领取限制 | 一个客户是否只能领取并兑换一次 |

#### 提报注意事项

1. 折扣叠加：在同一促销时间段内，Coupon活动可与Best Deal、Price Discount、Lightning Deal重叠参与，请注意折扣叠加可能引发的利润损失
2. 处于待生效/生效中/预算不足状态的Coupon，可编辑预算、取消Coupon

#### 促销状态解读&进度查看

![优惠券管理界面中状态筛选功能。在“状态”下拉框中，有“全部”“审核中”“创建失败”“待生效”“生效中”“处理中”“预算不足”“已取消”“已结束”等选项，其中“已结束”选项被勾选。](./assets/images/图片展示的是优惠券管理界面中状态筛选功能-cefbbb791852.png)

| 状态项 | 说明 |
|-|-|
| 审核中 | 提报后此条数据状态 |
| 创建失败 | 点击？可查看失败的具体原因，点击编辑重新修改后提交或点击删除重新创建 |
| 待生效/生效中 | 审核完成后流转此状态，可编辑，取消 |
| 处理中 | 操作“编辑”，流转此状态 |
| 预算不足 | 可编辑预算、取消 |
| 已取消 | 活动已取消 |
| 已结束 | 活动已结束 |

![优惠券列表页，右下角有“领取数”“兑换数”“预算进度条”三个关键信息。其中“预算进度条”以红色框突出显示。](./assets/images/图片展示的是优惠券列表页-2bde64e3bdce.png)

- 列表页可查看Coupon使用情况：当Coupon预算使用率≥80%，系统自动发送站内通知
