# Airwallex 空中云汇新用户注册指南

> 来源：[空中云汇注册指引.pdf](./%E7%A9%BA%E4%B8%AD%E4%BA%91%E6%B1%87%E6%B3%A8%E5%86%8C%E6%8C%87%E5%BC%95.pdf)

![Airwallex 空中云汇新用户注册指南第1页](./%E7%A9%BA%E4%B8%AD%E4%BA%91%E6%B1%87%E6%B3%A8%E5%86%8C%E6%8C%87%E5%BC%95.assets/pages/page-01.png)

Airwallex 空中云汇｜新用户注册指南

注册注意事项
1、涉及到月回款和流水部分，务必选择大于5W的档位，否则会被系统自动拒绝，申诉过程非常漫长。
2、美国主体注册需要企业邮箱。
3、需要证件：营业执照、法人实名手机号（无需接收验证码）、法人身份证件照片，股东身份证件照片。
4、业务相关地点务必不选择制裁国家（如俄罗斯）。
5、注册时不开VPN，独立设备独立网络注册。
6、法人是否能人脸，大陆抬头如果无法配合人脸请在指引中3.9-以下哪位是您本人-选择以上都不是，并
且提交验证人的身份证件和人脸。
7、如果是境外主体注册，法人扫码验证请使用相机扫码。

具体注册步骤：
1. 第一步：打开链接
注册链接：https://www.airwallex.com/app/signup?sfcid=701Q800001G0fEMIAZ
1   点击页面“立即注册”按钮。
