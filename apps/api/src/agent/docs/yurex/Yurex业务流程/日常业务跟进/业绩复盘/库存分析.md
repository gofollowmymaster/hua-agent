# 飞书文档：库存分析


## 操作步骤：【统计】-【仓库分析】

### 在途库存分析

追踪海外仓录入Yurex系统的在途库存详情&预计送达时间。

注意：未录入本系统内的库存情况未知。

![在途库存分析界面。左侧有“商品”“物流”“统计”等导航栏。](./assets/images/图片展示的是在途库存分析界面-97fcce1b4d8c.png)

### 超库龄分析

#### 汇总

支持多维度筛选，默认按库龄区间统计库存总量及分布。

![“统计 > 超库龄分析 > 汇总”页面。红框标注“超库龄分析”、“汇总”。](./assets/images/图片展示的是库存分析中超库龄分析的汇总页-1e305230b18c.png)

#### 明细

支持多维度筛选，默认按入库批次展示库存详情及具体在库时长。

![“超库龄分析 > 明细”页面。红框标注“明细”。](./assets/images/图片图片展示的是库存分析中“明细”页面-4fd394ede6bb.png)
