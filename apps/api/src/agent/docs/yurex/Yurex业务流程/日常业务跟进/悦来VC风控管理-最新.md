# 飞书文档：悦来VC风控管理-最新


**说明：**
**一、制定目的**
- 为保障双方合作期间的资金安全、账户安全及整体经营稳定性，有效规避品牌风险、Listing异常、客诉异常、合规违规、链接运营故障、库存及促销异常等各类经营隐患，减少各类异常问题造成的合作损失。
- 本手册依据AMZ平台规则、双方合作协议及实际运营场景制定，为双方合作风控处置的标准依据。
**二、适用与处置原则**
- 当合作供应商出现品牌风险、退换退款数据异常、客诉纠纷、合规违规、链接运营异常、经营数据异动，或发生其他影响平台运营稳定、合作安全的情形时，均适用本手册。
- 双方将严格依据本手册内容，结合实际情况及时开展风险评估、双向沟通与问题处置，有效化解经营风险，保障双方合作合规、稳定、持续开展。

### **Q：暂扣款会在什么时候进行暂扣？**

当期触发风控后，相关暂扣费用将优先纳入后续未下发的月度账单核算范围，并在对应账单生成的结算金额中进行暂扣。若账单待结算金额不足以覆盖全部暂扣金额，则剩余暂扣部分将继续在系统里已有的付款计划中进行暂扣。付款计划的暂扣顺序按照付款日期由晚到早依次执行。
例子：
该供应商的结算周期为T+30。5月18日发现ASIN A触发风控S2，需暂扣400美金。悦来财务会将该暂扣金额纳入【最近即将下发的月度账单】中，即5月25日下发的5月1日—5月14日账单中进行体现。
- 在月度账单未纳入暂扣款时，若该供应商5月25日下发的月度账单应收金额为500美金，则会暂扣400美金风险资金，最终实际应收金额为100美金。
- 在月度账单未纳入暂扣款时，若该供应商5月25日下发的月度账单应收金额为300美金，6月10日下发的月度账单应收金额为200美金，则5月25日月度账单会先暂扣300美金，剩余100美金将在6月10日月度账单对应生成的付款计划中继续进行暂扣。
- 在月度账单未纳入暂扣款时，若该供应商5月25日及之后月度账单的应收金额合计为300美金，但5月21日付款计划付款金额为200美金、5月28日付款计划付款金额为100美金。按照由晚到早的顺序，先扣5月28日付款计划100美金，恰好覆盖剩余100美金，故5月21日付款计划正常支付。

### **Q：暂扣款是否会进行返还？返还的条件是什么？**

会。返还的条件是满足风控处理规则的相应恢复条件后，悦来将把对应的暂扣款纳入【即将下发的最近的一个账单】，然后根据供应商签署的结算周期进行返还。
例子：
该供应商的结算周期为T+30。5月18日发现ASIN A触发风控S2，需暂扣400美金。悦来财务会将该暂扣金额纳入最近即将下发的月度账单中，即5月25日下发的5月1日—5月14日账单中进行体现。
在月度账单未纳入暂扣款时，若该供应商5月25日下发的月度账单应收金额为500美金，则会暂扣400美金风险资金，最终实际应收金额为100美金。
若供应商于5月28日恢复ASIN A对应风控指标，且后续未触发其他风控规则，则悦来财务会将此前暂扣的400美金纳入6月10日下发的5月15日—5月31日月度账单中，并根据T+30结算周期安排付款，预计付款计划时间为6月28日，实际付款时间预计为7月2日。

### **Q：什么是AMZ利润风险？**

AMZ利润风险，是指商品在AMZ销售过程中，实际利润未达到AMZ要求的盈利标准而产生的利润缺口。AMZ会综合商品采购成本、物流费用、仓储费用、退货成本、促销折扣及其他运营成本等因素，对商品盈利能力进行测算。当商品利润低于AMZ的盈利标准时，即视为存在AMZ利润风险。

### **Q：哪些因素会导致AMZ利润风险？**

AMZ会持续评估商品的盈利能力，并设有相应的利润标准。商品的利润会受到多种因素影响，包括但不限于：
- 商品采购成本过高；
- 促销折扣等费用增加；
- 退货率上升，导致退货运费、处理费等成本增加；
- 仓储费用、物流费用持续上涨；
- 商品售价下降或市场竞争加剧；
- AMZ整体运营成本调整。
上述因素均可能导致商品实际利润低于AMZ的利润标准。当商品长期未达到AMZ利润标准时，AMZ可能采取采购价格调整、减少采购订单、抑制DF、抑制广告、抑制促销等经营措施，以降低经营风险。

### **Q：**为什么要补偿AMZ？

AMZ Vendor Central（VC）属于采购合作模式，AMZ会持续评估商品的盈利能力。当商品实际利润持续未达到AMZ利润标准时，为降低经营风险，AMZ可能采取相应的经营调整措施，包括但不限于：
- **降低采购价格**
> 如有在途和可售的VCPO/BBO/BTR库存，将伴随价格保护罚款直接补偿AMZ利润损失
- **减少PO订单**
> 具体表现有：
>
> ① AMZ预测销量迟迟未提升到ASIN真实销售水平
>
> ② 常规PO订单量减少或直接为0，仅不定期收到大额降价的BBO订单
>
> ③ 短期内无法成功申请BTR订单
- **抑制DF订单**
> 即DF订单减少，或DF可售库存无法设置库存；
>
> 更严重者，DF仓库无法设置，或DF功能直接被AMZ关闭
- **抑制广告投放**
> 即使ASIN的评分和销量很好，VC也无法投放广告活动（CR看起来好、但ROI极低或亏损）
>
> 或者商品只能投放部分类型的广告活动
- **抑制促销活动**
> 常见被AMZ收取additional funding，或者reference price被提高
>
> 此外还可能有ASIN直接无法被添加到创建促销的商品名单
- **降低商品曝光及流量支持**
> listing权重下降，CDQ质量得分低，对比同类商品/相似价格商品的曝光更低或转化更低
- **停止采购或终止合作**
> 情节较轻者，可能只是短期受限，表现为上述的“减少PO订单、抑制DF订单”
>
> 情节严重者，将收到AMZ或者VM邮件明确告知某些ASIN或品类将永久停止采购，已经接单的还有剩余VC库存的ASIN，供应商仍需负责清库存的责任、并承担相关清库成本
上述措施可能导致商品销量下降、运营受限，甚至影响双方的长期合作。
为降低因商品实际利润未达到AMZ利润标准而产生的经营风险，保障商品的持续销售能力及双方合作的稳定性，当商品未达到AMZ利润风险标准时，平台将依据《合作协议》及《风控规则》的相关约定，对相应利润缺口实施风险补偿，以降低商品因盈利能力不足而导致的经营风险。

### **Q：资金补偿的金额会返还吗？有没有申诉的途径？**

- **不能返还：**资金补偿不属于保证金或临时冻结款项，而是针对商品经营过程中因未达到AMZ利润标准所产生的利润缺口、售后损失、退货成本及相关风险处置成本进行的风险补偿。因此，补偿金额不适用于暂扣款项的返还规则。
- **可以申诉（仅数据复核）：**若供应商对补偿结果存在疑问，可在结果发布后**7个工作日**内申请数据复核。平台将对AMZ利润数据关联、ASIN匹配关系、统计周期及补偿计算过程进行核查，确认是否存在数据同步异常、系统计算错误或规则执行偏差。如发现相关异常，平台将根据实际情况调整补偿结果。
- **其他补充：**AMZ利润数据属于AMZ官方内部经营数据，平台无法对该数据进行修改或向AMZ发起利润结果申诉，相关利润结果以AMZ官方提供的数据为准。

### **Q：AMZ利润标准是什么？如何计算？**

1. AMZ利润目标划分规则 按类目 (GL) 区分，目标高低受**市场 & 类目成熟度、商品竞争类型、供应商管理模式、是否新品**四大因素影响。
2. AMZ利润目标有三种计算方式：

 - 百分位数法：参考同类可比商品“除去运输成本的贡献利润”实际值，按百分位排名设定目标；
 - 匹配法：对标同款商品现有 Offer 的“除去运输成本的贡献利润” 真实水平；
 - 绝对值法：直接指定固定“除去运输成本的贡献利润” 绝对值作为目标。
3. 促销工具中，AMZ系统自动调取对应类目AMZ利润目标值，核算「Deal 促销利润与类目目标利润差值」，用来评估促销活动对盈利水平造成的影响。
**总结：**因为市场在随时变化，AMZ通过不同方式计算出的利润标准也会存在差异，无法简单定义某一个数值作为永久性指标或者目标。保持产品成本、质量、功能、价格、评价在市场中的竞争力，并尽可能按AMZ供应链要求履约，才能长远。

### **Q：风控触发后是否可以申诉？**

可以。供应商可在对应申诉周期内提交整改方案、补充资料或平台申诉结果，平台将结合整改情况及经营数据进行综合评估。

### **Q：为什么会限制采购？**

采购限制主要用于避免风险进一步扩大，包括库存风险、售后风险及平台经营风险持续增加。在相关指标恢复正常后，将逐步恢复正常采购。
