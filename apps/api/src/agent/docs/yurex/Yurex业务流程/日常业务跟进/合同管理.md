# 飞书文档：合同管理


注意：客户端被超级管理员配置了权限的内部人员才能查看/下载


## 功能介绍

合同管理有以下2点核心功能：

（1）电子合同管理。支持将纸质合同转化为电子合同，方便客户查阅和管理；

（2）合同状态管理。通过设定合同状态，提醒客户合同时间节点和到期情况；

## 注意事项

### 上传合同流程

1. 步骤1：线下与客户达成合作协议，签署纸质合同；
2. 步骤2：邀请客户入驻平台；
3. 步骤3：由运营在系统录入合同扫描件；
4. 步骤4：客户在系统查看合同详情；
