如何维护平台采购价

#### 亚马逊为保障自身利润空间，现需根据产品的动销、Listing Rating评分、C端消费者退货率、仓库布局及履约绩效、接单情况等触发平台采购价调整机制，需您配合选择接受/拒绝调价。

平台采购价调整区分为以下两类：
- **平台调价**：由亚马逊系统根据贵司产品的实际销售表现、退货率、订单履约质量及亚马逊利润模型等综合数据，不定期发起审核与调整。请务必密切关注平台推送的调价单。
- **自主调价：**由贵司或我方主动发起的价格调整申请。贵司可自主决定是否提交申请，但需注意控制调价频次，过于频繁的调价行为可能对产品的正常销售产生负面影响。

## **平台**采购价调整影响因素

### 平台采购价下调部分情况

- 产品月销量不足；
- 实际退货率高于行业平均退货率；
- 亚马逊利润不足；
- 产品抑制（直接Offer抑制、DF、广告、促销抑制等）；
- Listing Rating评分＜4.0（链接质量不达标）；
- 若使用自己合作的海外仓，海外仓履约绩效未达标；
- 亚马逊罚款占总接单金额占比超过30%；
- 同一ASIN的季度POA次数超过5次；

**基于实际退货率情况的平台采购价调整示例：**A产品，采购报价时退货率输入值为\*%，首次来单时间为1月，2月退货率较\*%有大幅上涨（一般是2%），系统对应推送平台调价单，您可手动选择接受/拒绝

### 平台采购价上调

- 亚马逊一般不会主动上调采购价，若采购价在初次报价基础上有下调且产品各方面表现较好则有再次上调采购价的机会。

注意：初次平台采购价为上限，亚马逊上调也不会超过这个价格。

## 平台采购价调整流程

- 【产品调价】有“平台调价‘单后，您需要在倒计时7天内进入系统页面操作接受/拒绝，到期未有任何操作，系统自动拒绝，您共有2次拒绝次数。若拒绝次数变为0，后续系统不再自动拒绝，而是调价单默认接受该调价，调价单状态变为已生效，采购报价更新为调价后的价格。
- 若您主动选择接受调价，则调价单状态变为已生效，采购报价更新为调价后的价格。

## 如何稳定平台采购价

### 进销存管理

1. VC如何备货：无论是DF模式还是PO模式，产品都需要有足够库存。VC正式上线销售前，在海外仓的备货数量至少是产品SC日销量水平或预估VC日销量水平的10-12周的库存量。备货指南参考：

为什么要备至少10-12周的库存：

- 海运头程：头程走快船4周、走普船至少6周
- 港口入海外仓：至少1周
- VC下单到上架可售：至少3周
- 安全库存量/生产周期：至少2周

总的逻辑来讲，VC前面不断动销，后面的货从各个环节持续补，避免VC仓库和海外仓出现断货。

1. 优化发货计划：严格遵守亚马逊的送货窗口（Shipping Window） 和承运人要求，确保准时送达，避免因延迟收仓影响库存；和仓库沟通提前拣货，确保按时出库，出库后及时在系统提交出库操作
2. PO绩效管理：详情请参考帮助中心——[供应商PO绩效指标指南](https://wiki.yurexcc.com/wiki/SNmBwwzkUicdQekB5FacZXuwnJc?objType=docx)
3. DF绩效管理：详情请参考帮助中心——[供应商DF绩效指标指南](https://wiki.yurexcc.com/wiki/EBExwMyvbihQazkjs1Vc2dXJnCb?objType=docx)
4. 动销管理：主动规划并使用广告或者优惠券（Coupons）、促销（Promotions） 来刺激产品销量和亚马逊更多的来单

### 控制与优化退货率

1. 确保产品和亚马逊图文内容的真实性。如产品描述尽可能贴合产品，使用高分辨率、多角度的图片（白底主图+场景图），避免过度美化导致消费者到货后的期望落差
2. 在要点和描述中明确列出产品的局限性（例如，“最大承重50kg”、“仅适用于室内”）
3. 利用A+页面的对比图表和常见问题模块，预先解答消费者疑问
4. 产品出厂质量把控和做好产品包装确保产品在运输中不会损坏
5. 深入分析退货原因，对产品功能、外观等进行迭代升级和优化

### 全平台MSRP价格管控

1. VC定价控制权属于亚马逊官方，不能像SC那样自由调整；如自定\$100，AMZ测到库存过多或者其他站内外有其他更低的价格，前台可能会自动降低到\$95；故供应商在报价环节，务必定好MSRP，避免调整MSRP
2. **价格匹配机制介绍**

1. **定义：**是指亚马逊的Vendor Central (VC) 平台会自动匹配其商品在全渠道的价格（无论高价还是低价，低价匹配概率更大），并可能因此自动调整VC卖家在平台上的售价
2. **匹配范围：**
- AMZ站内（FBA/FBM，尤其同一个ASIN的不同SC跟卖）
- AMZ站外（独立站、walmart、ebay、wayfair、homedepot、tiktok、temu等等）
- AMZ官方据市场自行调价（不认可MSRP/ AMZ利润不足/ VC库存滞销）
1. **解决方案：**
- 调整SC价格与VC MSRP保持一致；close FBA listing/ FBM 库存调0
- 自行找到其它渠道同产品（高度相似产品）售价，保持与VC MSRP一致
- 转VC初期被AMZ调价，增加推广/广告力度以加快动销，积累一定时间后AMZ会自动恢复原MSRP
- 供应商发起调价操作，增加AMZ利润（如在保持MSRP不变的情况下，降低平台采购价）
- 与VM沟通解决办法
