# 产品信息填写指南

## Product Identity（产品标识）

### Package Level（包装层级）

- Unit：适用于单个出售的商品，如一部手机，通常选择此项。
- Case：适用于整箱出售的商品，如18瓶饮料为一箱，以箱为单位销售。
- Pallet：托盘，极少使用。

### Package Contains SKU Identifier（包装内包含的 SKU 标识）

填写该产品对应的 SKU 编号即可。

### Is Package Level Orderable（是否可订购）

选择 `Yes`，表示该商品可供亚马逊订购。

## Product Details（产品详情）

### Release Date（发布日期）

若非必填，可不用填写；必填时通常填写 Listing 上传当天的日期。

### Product Site Launch Date（上架日期）

若非必填，可不用填写；必填时一般也填写 Listing 上传当天的日期。

## Shipping（物流信息）

### Item Dimension（产品尺寸）

- Item Length（产品长度）
- Item Width（产品宽度）
- Item Height（产品高度）
- Item Weight（产品重量）

提示：床垫、帐篷等产品应填写展开后的尺寸。

### Item Package Dimension（包装尺寸）

- Item Package Length（包装长度）
- Item Package Width（包装宽度）
- Item Package Height（包装高度）
- Package Weight（包装重量）：指产品本身加包装的总重量。

提示：填写包装完成后的发货包装尺寸。

### Items per Inner Pack（每箱产品数量）

这是重要字段，一定要填写正确。填写每个外箱内包含的产品数量。

示例：

| 外箱装箱情况 | 填写值 |
| --- | --- |
| 一箱装 1 件产品 | 1 |
| 一箱装 10 件产品 | 10 |

## Important Notes（重要提醒）

1. 装箱数量准确性至关重要：亚马逊采购订单（PO）按整箱倍数下单，填写错误会导致无法正确发货，甚至需要取消订单。
2. 如装箱数量变更：请在上一批 PO 订单发货完成、新 PO 未下达前及时修改，避免实际装箱与系统记录不符，否则可能产生拆箱/合箱的额外成本。
