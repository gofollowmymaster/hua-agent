# 产品信息填写指南

> 来源：[产品信息填写指南.pdf](./%E4%BA%A7%E5%93%81%E4%BF%A1%E6%81%AF%E5%A1%AB%E5%86%99%E6%8C%87%E5%8D%97.pdf)

## 第 1 页

![产品信息填写指南第1页](./%E4%BA%A7%E5%93%81%E4%BF%A1%E6%81%AF%E5%A1%AB%E5%86%99%E6%8C%87%E5%8D%97.assets/pages/page-1.png)

一、Product Identity（产品标识）
1. Package Level（包装层级）
- Unit：适用于单个出售的商品，如一部手机，通常选择此项。
- Case：适用于整箱出售的商品，如18瓶饮料为一箱，以箱为单位销售。
- Pallet：托盘，极少使用。

2. Package Contains SKU Identifier（包装内包含的SKU标识）
填写该产品对应的SKU编号即可。
3. Is Package Level Orderable（是否可订购）
选择 Yes，表示该商品可供亚马逊订购。

二、Product Details（产品详情）
4. Release Date（发布日期）
若非必填，可不用填写，必填的话，通常填写Listing上传当天的日期。
5. Product Site Launch Date（上架日期）
若非必填，可不用填写，必填的话，一般也填写Listing上传当天的日期。

三、Shipping（物流信息）
6. Item Dimension（产品尺寸）
- Item Length（产品长度）
- Item Width（产品宽度）
- Item Height（产品高度）
- Item Weight（产品重量）
提示：床垫、帐篷等产品应填写展开后的尺寸。

## 第 2 页

![产品信息填写指南第2页](./%E4%BA%A7%E5%93%81%E4%BF%A1%E6%81%AF%E5%A1%AB%E5%86%99%E6%8C%87%E5%8D%97.assets/pages/page-2.png)

7. Item Package Dimension（包装尺寸）
- Item Package Length（包装长度）
- Item Package Width（包装宽度）
- Item Package Height（包装高度）
- Package Weight（包装重量）：指产品本身加包装的总重量。
提示：产生包装完成后的发货包装尺寸。
8. Items per Inner Pack（每箱产品数量）—— 重要字段，一定要填写正
确！！！
填写每个外箱内包含的产品数量。例如：
- 一箱装1件产品，填写 1
- 一箱装10件产品，填写 10

📌 Important Notes（重要提醒）：
1. 装箱数量准确性至关重要：亚马逊采购订单（PO）按整箱倍数下单，填写错误会导致无法正确发
货，甚至需要取消订单。
2. 如装箱数量变更：请在上一批PO订单发货完成、新PO未下达前及时修改，避免实际装箱与系统记
录不符，否则可能产生拆箱/合箱的额外成本。
