# 飞书文档：商品采购报价


**在Yurex系统中申请并且接受Yurex反馈的采购报价的商品，才能进行listing上传。**
> 注: 即使在入驻系统前双方已经沟通过报价，仍需要走系统流程存档数据，便于后续业务开展。
系统为便于客户快速完成报价流程，**现支持三种提交方式：“商品中心提交”、“单个ASIN提交”、“批量通过表格提交”。**

## 方式一：商品中心提交

1. 【商品-商品管理-新增产品】填写的采购报价，会自动生成一条数据在采购报价模块，无需二次填写

![图片展示的是 addCriterion()](./assets/images/图片展示的是-addCriterion(-f5310761d1b7.png)

1. PO/DF需分别进行报价，输入【MSRP】后，点击提交会进行必填项的校验，若仅提交了其中一个业务模式的报价，仅成功提交一个，余下业务模式报价需单独申请；

![图片展示了商品中心提交采购报价时的页面操作细节。在【商品 - 商品管理 - 新增产品】界面中，有 PO 和 DF 两种业务模式的报价设置区域，均以红色边框突出显示。其中 PO/DF 报价需分别进行，都有是否报价的选项，输入【MSRP】等报价信息后可操作编辑平台采购价等设置。该图片与上下文关系紧密，是对上下文提到的在商品中心填写采购报价操作的具体界面展示，直观呈现了报价时的必填项校验等相关设置。](./assets/images/图片展示了商品中心提交采购报价时的页面操-00b7070703c3.png)

1. 若您未填写任何【报价信息】中的任何数据，需待商品审核通过后，回到【商品-商品管理】里，状态为已生效的产品，可点击【报价】，进行采购报价；或者通过下述方式二【销售-采购报价】单独申请报价；

![图片展示的是商品管理系统中商品管理页面的局部截图。其中可看到列表中某商品状态显示为“已生效”，其操作栏处有“报价”按钮，以红色框突出显示。结合上下文，该图片展示了文档中提及的方式一进行商品采购报价的操作场景，即当商品审核通过且状态为已生效时，可点击此“报价”按钮进行采购报价；也说明了在【商品 - 商品管理 - 新增产品】中填写采购报价的相关操作情况。](./assets/images/图片展示的是商品管理系统中商品管理页面的-774252b6d261.png)

## 方式二：单个ASIN提交报价

1. 操作路径：【销售】>【采购报价】>【申请报价】>【添加报价】
2. 操作步骤：

 1. 进入单个添加页面

 ![图片展示的是商品电商采购报价系统中“添加报价”页面。页面左侧有“添加报价”“批量报价”选项，右侧是报价申请表格，包含报价单ID、品牌、产品属性、](./assets/images/图片展示的是商品电商采购报价系统中“添加-5507932dadce.png)

 1. 文本框输入/列表选择对应产品数据，支持通过SKU/MSKU进行搜索后，需分别对PO/DF模式进行报价。

 > 【PO/DF销售价格制定】下“是否报价”选择说明：
 >
 > 1. 选择“开启”表示对该业务模式进行报价；
 > 2. 选择“关闭”表示暂不对该业务模式进行报价，未报价的情况下，无法进行VC listing跟卖操作；
 >
 > ![图片展示了商品采购报价中“单个ASIN提交报价”方式下，填写制定销售价格参考信息的界面。界面中以红色框突出显示了“PO/DF销售价格制定”部分，包含“是否报价”选择项，当前选中“是”；“制造商建议零售价（MSRP）”为100.00美元；“期望平台采购价”和“期望平台采购折扣”为必填项，当前显示“请输入”；“SC Referral Fee Rate”和“SC Fulfillment Fee”为必填项，当前显示“请输入”；“退货率”“目标销量（月）/目标GMV（月）”“过去一年销售额/过去一年平均售价”为必填项，当前显示“请输入”。该图片与上下文紧密相关，直观呈现了填写参考信息的具体位置和内容。](./assets/images/图片展示了商品采购报价中“单个ASIN提-355b4fa6c6c0.png)

 1. 填写制定销售价格参考信息

 ![图片展示的是商品采购报价中填写制定销售价格参考信息的界面。界面中，有多个需填写的项目，如期望平台采购价，以百分比形式呈现；还有渠道站点可选择，如“Asia Crafts & Sewing”；是否SC销售选择“是”或“否”；以及目标销量（月）、目标GMV（月）、过去一年销售额、过去一年平均售价等需输入具体数值的项目。此图与文档中介绍填写制定销售价格参考信息的内容对应，直观呈现了相关填写区域。](./assets/images/图片展示的是商品采购报价中填写制定销售价-79aef03d5b11.png)
3. 填写注意事项：

 1. **制造商建议零售价（MSRP）**：表示该产品将在亚马逊listing页面进行售卖的价格；
 2. **期望平台采购价**：指您希望我们以什么样的价格采购您的产品；
 3. **渠道站点**：表示该报价单是针对具体的某一个渠道站点进行的报价；
 4. **是否SC销售**：

 1. 是：表示该产品曾在亚马逊进行过售卖，需要您输入相关的信息；
 2. 否：表示该产品未曾在亚马逊进行过售卖；
 5. **SC Referral Fee Rate**：品牌佣金费率，请您根据产品实际情况填写，该费率将作为我们制定采购价格参考标准之一；
 6. **SC Fulfillment Fee**：物流配送费，请您根据产品实际情况填写，该费用将作为我们制定采购价格参考标准之一；
 7. **退货率**：请您根据产品实际情况填写，该费率将作为我们制定采购价格参考标准之一；
 8. **目标销量（月）/目标GMV（月）：**入驻后您每月目标销量/目标GMV，为预估值；
 9. **过去一年销售额/过去一年平均售价**：请您根据产品实际情况填写，该内容将作为我们制定采购价格参考标准之一。
4. 信息填写完成后点击提交，Yurex平台运营经理会尽快完成审核，请注意查看该条记录状态。报价审核完成后需要您操作点击**“接受报价”、“拒绝报价”或“重新报价”**。您点击接受报价后，该产品的报价流程完结。

![图片 addCriterion图片展示的是商品采购报价系统中“待确认报价”页面。页面上方有“全部”“](./assets/images/图片-addCriterion图片展示的-3aeab160e144.png)

![图片展示了Yurex平台商品采购报价单界面，报价单ID状态为“待确认”。界面右侧上方有“拒绝”和“接受”两个按钮，以红色框突出显示。界面中还呈现了报价采购信息，包括MSRP（制造商建议零售价）、期望平台采购价、渠道站点、是否SC销售、退货率等，这些信息与文档中填写注意事项所提及内容对应，用于商品采购报价流程操作。](./assets/images/图片展示了Yurex平台商品采购报价单界-1a88df5f4d85.png)

## 方式三：批量提交报价

1. 路径：【销售】>【采购报价】>【申请报价】>【批量报价】
2. 操作步骤：

 1. 进入功能页面

 ![图片展示了Yurex平台“销售 - 采购报价 - 申请报价”功能页面。页面中有多个筛选选项，如报价状态、业务模式等。画面左下方“申请报价”下拉菜单处，“批量报价”选项被红色框突出显示。该图片与文档中“方式三：批量提交报价”的操作步骤相关，对应步骤1中提到的进入【批量报价】功能页面的操作，直观呈现了从该页面找到“批量报价”功能入口的界面情况。](./assets/images/图片展示了Yurex平台“销售-采购-0f2c2650cd3d.png)

 1. 下载模板

 ![图片展示的是Yurex addCriterion()](./assets/images/图片展示的是Yurex-addCrite-69b5af8ccaa7.png)

 1. 在模板里填写产品销售情况

 ![图片展示的是商品采购批量报价时需下载填写的模板。模板中包含SKU、制造商建议零售价、期望平台采购价、目标销量、目标GMV等多列信息，且各列下方有填写说明，部分必填项以红色字体标注。该模板对应文档中“方式三：批量提交报价”操作步骤里需下载填写的内容，在填写完成后需上传，之后点击提交，等待Yurex平台运营经理审核，审核完成后可进行“接受报价”等操作。](./assets/images/图片展示的是商品采购批量报价时需下载填写-effe648563f1.png)

 1. 上传模板

 ![图片展示的是Yurex平台批量申请](./assets/images/图片展示的是Yurex平台批量申请-44b501b106fe.png)

 1. 信息填写完成后点击提交，Yurex平台运营经理会尽快完成审核，请注意查看该条记录状态。报价审核完成后需要您操作点击**“接受报价”、“拒绝报价”或“重新报价”**。您点击接受报价后，该产品的报价流程完结。
