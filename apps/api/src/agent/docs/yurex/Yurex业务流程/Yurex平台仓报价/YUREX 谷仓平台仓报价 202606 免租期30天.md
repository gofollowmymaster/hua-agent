## 索赔标准

### 丢失

#### 盘点

- **索赔项目**：库内丢失
- **类型描述**：仓库周期性或非周期性盘点：实际库存数＜系统库存数。
- **受理参考期限**：1、系统盘亏日期次日起算；<br>2、无限期
- **解决措施**：1、库内丢失产品赔付：系统进口申报价值，单品最高赔付费用上限100 USD。<br>2、库内找回产品扣回<br>   a.扣回周期为自然日90天，当仓库找回产品当天向前推90天（包含当天），90天内有赔付过，则将扣回已赔付的金额，频率为每月一次。<br>   b.扣回标准为当找回数量小于等于90天内已赔付的数量，按照找回数量扣回；当找回数量大于90天内已赔付的数量，按照已赔付数量扣回；<br>   c.扣回金额按照该SKU最近一次赔付单价金额计算。
- **客户提供材料**：1、索赔申请表：<br>  a.仓库；<br>  b.平台仓SKU编码；<br>  c.件数。

### 操作 / 失误

#### 漏发

- **索赔项目**：库内<br>操作失误
- **类型描述**：仓库处理多件订单，遗漏内件出库
- **受理参考期限**：1、订单签出日期次日起算；<br>2、60个自然日内。
- **解决措施**：1、补发<br>   a.返还补发订单费用(尾程费用、库内费用)。<br>2、不补发<br>   a.返还原订单50%费用（尾程费用、库内费用）。
- **客户提供材料**：1、漏发（补发）<br>   a.原发件平台仓订单号；<br>   b.补发平台仓订单号；<br>   c.漏发SKU编码以及数量；<br>   d.提供已收到商品整体照片（照片清晰可见收到产品SKU条码以及数量）；<br>   e.与买家/平台沟通截图或清晰的实收面单图片（要求面单图片能清晰看到跟踪号以及买家信息）。<br>2、漏发（不补发）<br>   a.原发件平台仓订单号；<br>   b.漏发SKU编码以及数量；<br>   c.提供已收到商品整体照片（照片清晰可见收到产品SKU以及数量）；<br>   d.与买家/平台沟通截图或清晰的实收面单图片。
- **补充说明**：与买家沟通的截图上需看的到能对应到此订单的信息（对应平台仓系统订单的参考号/订单号/跟踪号等）；

#### 多发

- **客户提供材料**：1、提供证明材料<br>   a.原发件平台仓订单号；<br>   b.多发平台仓编码以及数量；<br>   c.卖家提供多收到商品照片（照片清晰可见收到产品SKU条码以及数量）；<br>   d.与买家/平台沟通截图或清晰的实收面单图片（要求面单图片能清晰看到跟踪号以及买家信息）。

#### 错发

- **类型描述**：仓库处理订单，错发产品出库
- **受理参考期限**：1、订单签出日期次日起算；<br>2、60个自然日内。
- **解决措施**：1、赔付错发订单产品货值：系统进口申报价值，单品最高赔付费用上限100 USD。<br>2、返还订单费用（尾程费用、库内费用）<br>3、错发货商品在库找回-扣回货值<br>   a.扣回周期为自然日90天，当仓库找回产品当天向前推90天（包含当天），90天内有赔付过，则将扣回已赔付的金额，频率为每月一次。<br>   b.扣回标准为当找回数量小于等于90天内已赔付的数量，按照找回数量扣回；当找回数量大于90天内已赔付的数量，按照已赔付数量扣回；<br>   c.扣回金额按照该SKU最近一次赔付货值单价金额计算。
- **客户提供材料**：1、提供证明材料<br>   a.原发件平台仓订单号；<br>   b.应发平台仓SKU编码及数量；<br>   c.卖家提供错发商品照片（照片清晰可见收到产品SKU条码以及数量）；<br>   d.与买家/平台沟通截图或清晰的实收面单图片（要求面单图片能清晰看到跟踪号以及买家信息）；

### 破损

#### 库内破损

- **索赔项目**：库内破损
- **类型描述**：1、发现节点：盘点或出库；<br>2、仅指仓库管理不当导致的货物破损。

### 增值

#### 平台仓换标

- **索赔项目**：换标错误
- **类型描述**：1、换标节点：转仓入库和库内换标；<br>2、应客户（增值服务）需要，标签更换错误；<br>3、不含客户提供错误指令的情形。
- **受理参考期限**：1、订单签出日期次日起计算；<br>2、60个自然日内。
- **解决措施**：1、赔付丢失产品货值：系统进口申报价值，单品最高赔付费用上限100 USD。<br>2、返还订单费用（尾程费用、库内费用）。<br>3、免费（平台仓换标费用）更换正确标签：<br>   a.换标费用标准请见“平台仓增值服务”；<br>   b.换标费用含下架与上架操作费。
- **客户提供材料**：1、标签贴错的平台仓订单号；<br>2、需更换的平台仓SKU编码；<br>3、买家收到货物照片。

#### 第三方可重新贴标

- **类型描述**：1、转第三方仓更换错误标签；<br>2、第三方仓支持重新换标。
- **受理参考期限**：1、订单签出日期次日起计算；<br>2、60个自然日内。
- **解决措施**：依据平台仓换标费用标准（标准请见“平台仓增值服务”）赔付换标费用。
- **客户提供材料**：1、第三方收货信息（对应货值费用标准）：<br>   a.清单；<br>   b.入库单。<br>2、单号及相关信息：<br>   a.平台仓原订单号；<br>   b.贴错标明细或第三方换标明细。<br>3、第三方收到贴错标的货物照片；

#### 第三方退回

- **类型描述**：1、转第三方仓更换错误标签；<br>2、货物退回平台仓重新上架。
- **受理参考期限**：1、订单签出日期次日起计算；<br>2、60个自然日内。

- **客户提供材料**：1、第三方收货信息（对应货值费用标准）：<br>   a.清单；<br>   b.入库单。<br>2、单号及相关信息：平台仓原订单号；<br>3、第三方收到贴错标的货物照片；
