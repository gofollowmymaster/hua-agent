# 飞书文档：2026年7月更新


## 2026年07月31日

### 主要变更内容

【仓库】-【仓储配置】-【仓储配置】

1. 新增/编辑仓库 限制不能输入中文字符
2. 新增/编辑仓库 州/省支持按简称检索
3. 新增/编辑仓库 增加上传附件
4. 编辑系统仓库，可修改 UPS账号、UPS文件
5. 仓库驳回后再编辑，自动带出上一次维护的 UPS账号、UPS文件

【仓库】-【入库管理】-【入库单列表】

1. SKU首次入仓（入库仓库），实际入库尺寸重量默认为空
2. 批量入库模版调整：仓库名称改为仓库编号、产品ID改为SKU
3. 页面体积/重量单位支持公制/英制切换：查看页面默认英制、编辑页面默认公制

【仓库】-【出库管理】-【出库单列表】

1. 提交出库前，可修改 "仓库实出箱数" 或 "仓库实出数量"
2. 批量出库，增加显示处理进度条

## 2026年07月30日

### 主要变更内容

【订单】-【渠道订单】-【FBA/一件代发订单】

1. FBA/一件代发订单增加其他附件的上传入口
2. FBA订单快递+平台合作物流增加上传箱唛入口
3. FBA兼容AWD补货订单录入

【物流】-【渠道物流】-【FBA/一件代发货件】

1. FBA和一件代发货件卡派模式平台合作物流也可编辑上传空白BOL和托盘标附件
2. FBA货件单详情发货信息增加显示裁剪后的箱唛附件

## 2026年07月22日

### 主要变更内容

【订单】-【VC订单】-【BBO询价单】

1. 全部询价单页面 筛选项增加“还价状态”筛选项
