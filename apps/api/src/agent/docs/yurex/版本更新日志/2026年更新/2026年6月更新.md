# 飞书文档：2026年6月更新


## 2026年06月24日

主要变更内容

【物流】-【VC物流】-【VCPO货件】

1. 货件单状态【处理中】变更为【待推送Amazon】，包含筛选、导出、列表
2. 在VC后台创建Shipment推单前支持修改预计打托数、总重量、总体积
3. 列表新增显示推单时间
4. 新增亚马逊预计提货时间变更系统通知

【订单】-【VC订单】-【VCDF订单】

1. 地址解析开通界面增加“同意亚马逊DF数据保护政策”
2. DF订单列表字段优化

## 2026年06月23日

### 主要变更内容

【销售】-【报价管理】-【报价测算】

1. 调整为通过商品中心选择ASIN，之前是通过Catalog选择SKU
2. 选择ASIN后，查询商品中心自动填充尺寸、重量等相关指标
3. 新增采购折扣字段

【仪表盘】-【订单】-【BTR销售进度监控】

1. BTR整体情况

 1. 筛选：可按订单、产品、售卖率等筛选数据
 2. 核心指标卡片：可自定义显示BTR接单总量、售卖率、ASIN通过率、滞销ASIN数等指标
 3. 售罄时长分析：按售罄天数分组显示ASIN售罄频次，及汇总未售罄ASIN数
 4. 占比情况分析：按订单状态和售卖率显示占比情况
2. 销售中BTR情况

 1. 筛选：可按订单、产品、销售进度状态等筛选进行中的BTR数据
 2. 核心指标卡：可自定义显示进行中BTR的核心指标，如：已售/未售总量、预计滞销金额、销售进度异常数等
 3. 趋势查询：按日期显示进行中的BTR每日销量曲线
 4. 占比及排行：按销售进度状态分别统计占比情况，按ASIN维度显示售卖率排行
 5. 销售情况明细：按明细列表显示BTR订单的ASIN当前销售进度、时间进度、预计滞销数量、预计罚款金额、预警情况等

【订单】-【VC订单】-【VCPO订单】

1. VCPO订单列表可售库存和发货仓库选择弹窗增加显示距离信息
2. 新订单可按距离分配距离最近的发货仓库和接单数量

【订单】-【渠道订单】-【FBA订单】

1. FBA订单新增编辑界面上传shipping label增加气泡说明
2. 创建FBA订单-产品列表增加序号，且支持排序，FBA货件单按产品排序裁减分配shipping label附件

## 2026年06月17日

### 主要变更内容

【商品】-【产品刊登】-【合规认证】

1. 系统内可直接查询需要和已经完成合规认证的产品清单
2. 线上提交合规认证申请，无需线下递交材料，简化流程

【商品】-【产品监控】-【ASIN售后监控】

1. 新增 ASIN 售后风控指标查询能力，可查看各 ASIN 风控异常情况，方便遇到资金暂扣、订单止付时核对原因

## 2026年06月10日

### 主要变更内容

【仓储】-【出库管理】-【出库单列表】

1. 一件代发销售出库单详情增加“装箱信息”列表
2. 一件代发销售出库单自动出库后根据谷仓返回计算实出信息

### 主要变更内容

【商品】-【产品管理】-【商品管理/货品管理/辅料管理】

2. 【普通商品/货品/辅料】电池信息填写内容调整
3. 【普通商品/货品/辅料】平台仓区分服务类型及外部平台

5. 【商品/货品/辅料】批量上传模版调整
