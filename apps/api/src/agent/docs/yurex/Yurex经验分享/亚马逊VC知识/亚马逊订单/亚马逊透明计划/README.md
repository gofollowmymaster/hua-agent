# 飞书文档：亚马逊透明计划

亚马逊透明计划

## 一、定义

Transparency——透明计划是一项商品序列化服务，可防止销售和配送假冒伪劣商品，验证商品真伪，提高买家参与度并优化供应链。

## 二、优点

### 验证商品真伪

使用唯一代码，确保仅向买家配送准确的正品。无论商品是由亚马逊配送，还是由卖家直接配送。未经授权的卖家无法在亚马逊上架已注册Transparency计划的产品。（FBA模式下，亚马逊仓库在接收您的商品时，会扫描唯一的 Transparency代码。无法提供有效正品代码的商品将被拦截销毁，根本无法上架销售。）

### 与买家互动

在消费者购买商品后，与其建立联系。通过亚马逊购物APP或Transparency透明计划APP都可以让消费者扫描验证码，验证正品，并且访问有关品牌商品的促销、视频、帖子或其他内容。

### 优化供应链

获取批量或批次商品的更多洞察信息，帮助确定供应链问题，诊断根本原因，并且在尽可能减少业务中断的情况下实施解决方案。

## 三、硬性要求

1. 品牌商需持有R标并且在亚马逊完成品牌备案
2. 拥有商品的全球贸易项目代码(GTIN)，例如通用商品编码(UPC)、ISBN或欧洲商品编号(EAN)

## 四、标签费用

这是透明计划的主要费用，采用分段计费的方式。具体来说，如果12个月内申请的标签数量在100万以下，每个标签的费用为0.05美元；若申请数量在100万到1000万之间，超出部分每个标签的费用为0.03美元；而当申请数量超过1000万时，超出部分的费用则降至0.01美元每个。此外，对于年销量超过40K的品牌，每个ASIN可以获得10万张免费的CODE。

## **五、申请流程**

### 获取邀请链接

联系透明计划经理进行报名，提交品牌方资料和ASIN信息申请表。或者直接访问申请页面[Amazon Transparency: Counterfeit and brand protection](https://sell.amazon.com/brand-registry/transparency)，提交品牌和产品信息等待审核。审核无误后，亚马逊会发送透明计划的邀请链接到申请表格中填写的邮箱。

### 创建账户

在收到邀请邮件后，点击其中的【创建账户】链接，按照页面提示完成账户的创建过程。这包括勾选参与透明计划的品牌、填写订约方信息（即注册商标时使用的公司名称）、设置账单信息等。

账户创建成功后，点击【Get started】开始注册ASIN。按照表格批注上的要求填写ASIN信息，并选择合适的标签样式。标签样式的选择需根据ASIN对应的FNSKU数量来决定，以确保发货时贴标正确。

### 请求代码

进入Transparency网站，点击【请求代码】，输入ASIN/SKU/GTIN等信息，并指定请求的数量、生产地点和批号。确认无误后提交请求，并在【代码历史记录】中下载T-code。

### 申请运营绩效审查（OPR）

OPR是验证标签是否正确应用于注册ASIN的关键步骤。在提交OPR申请前，需确保所有货件已贴标并上架。申请通过并完成必要的缓冲期后，注册的ASIN将正式受到保护。

1. 含FBA配送产品：发货考核，最少发10个产品，建议发100个起。考核产品接收后，请查看流程状态或者OPR报告。
2. 纯自配送产品：照片考核。有假货跟卖的ASIN需要通过30天缓冲期（亚马逊判定）。

## **六、SC转VC后关于透明计划的注意事项**

1. T-code标签上禁止有FNSKU条码
2. 确认ASIN在Transparency计划中仍受保护
3. 务必在每一个产品的彩盒包装上贴好T-code标签
