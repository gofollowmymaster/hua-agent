# 飞书文档：广告组状态分析

## 广告组状态分析

### 一、正常状态的广告：

1. **Delivering：**运行中
2. **Paused（Campaign Paused/Ad Group Paused）：**暂停
3. **Archived（Campaign Archived/Ad Group Archived）：**作废归档

### 二、异常状态的广告：

1. **Ineligible**

 1. 原因：

 - Buybox缺失
 - 亚马逊利润率不足
 - 图片不合规等
 - 缺货或查询不到库存信息
 - 成人用品
 2. 建议操作：

 - 检查buybox状态
 - 找我司运营尝试下调平台采购价
 - 检查图片
 - 检查库存
 - 检查类目
2. **Out of Budget：**

 1. 原因：预算不足
 2. 建议操作：提高预算
3. **Payment Failure：**

 1. 原因：付款失败
 2. 建议操作：检查广告账户余额
4. **Campaign Ended：**

 1. 原因：广告组设置了结束日期，已到期
 2. 建议操作：重新开启
