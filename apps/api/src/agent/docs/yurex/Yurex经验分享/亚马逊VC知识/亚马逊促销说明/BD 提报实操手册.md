# 飞书文档：BD 提报实操手册


## 提报核心规则（必看）

### 产品准入条件

- 状态：VC 可售（亚马逊可采购、客户可购买）
- 评分：评分≥4.0，Rating 数量＞5
- 素材：合规主图
- 风控：非高退货率商品（亚马逊评估）
- 定价：需有参考价（List Price/MSRP 或 Was Price）

 - List Price：卖家提供的建议零售价（需有实际销售依据）
 - Was Price：亚马逊计算的 T90 价格中位数（不含限时促销，含长期不间断促销）
- 类目限制：禁售电子烟、酒类、成人用品、医疗器械 / 药品、亚马逊即时视频、婴儿配方奶粉

### 提报关键要求

- 时效：需提前 3 天申请
- 时长：单次最长 31 天（建议 “7 天活动 + 3 天间隔”）
- 频率：普通时段连续提报间隔≥14 天，大促前后≥30 天
- 折扣：常规≥10% off，大促≥15% off
- 资金：符合 Min Funding 要求
- 产品：支持单个 / 多个 ASIN（一次最多添加 20 个）
- 库存：合理填报（避免超卖 / 库存不足导致活动提前结束，销售进度条同步展示进度）

## 活动管理规范

### 生效时间

- 按太平洋时间，设置的开始日期当天 0 点生效

### 修改规则

| **阶段** | **可修改内容** | **限制条件** |
|-|-|-|
| 活动开始前 | 起止时间、ASIN 增减、Funding（≥Min Funding）、Deal Price、提报数量 | 起止时间修改只能延后，不能提前 |
| 活动进行中 | 结束时间（提前 / 延长）、Funding（≥当前金额）、Deal Price | 不可修改提报数量 |
| 活动结束后 | - | - |

> 新版 BD 系统暂不稳定，修改可能失败，失败后可取消并重新提报近期活动

### **取消规则**

- 支持随时取消，正在运行的活动需整组取消（暂无法删除单个 ASIN）

## 标准化处理流程

1. 需求提报：明确 ASIN、模式（PO/DF）、提报数量、折扣比例 / 金额
2. 信息填写：按要求填报，确保信息准确
3. 提报结果查询：确认是否通过，核对实际促销价等信息
4. 状态监控：实时跟踪（重点关注开跑前、进行中状态、促销价、折扣、库存）
5. 修改 / 异常处理：按系统提示或亚马逊反馈调整报错内容
6. 复盘规划：活动结束后分析销售数据，规划后续提报

## 收费标准

**BD 费用 = 已售商品数量 ×Funding**

## 重点注意事项

### **参考价（Reference Price）说明**

若 Reference Price≠MSRP，原因

- MSRP 销售数据不足
- 亚马逊抓取 Was Price（不可控）

### **Min Funding 计算**

- 常规：Min Funding = 参考价 ×10%（产品价格 / 利润稳定）
- 特殊：Min Funding≥参考价 ×10%（需额外支付亚马逊计算的 additional funding，因出单少 / 利润低，依据不公开）

### **Deal Price 要求**

- 需低于近 30 天最低价（影响 T30 最低价的活动：BD、PD、LD、PED、Coupon）
- 提报后需核查，不满足则调整 Funding

### **活动叠加限制**

- 不可同时提报：BD 与 LD、DOTD、PD（会报错 overlap）
- 可同时提报：BD 与 SC 的 PED/PMP（BD 优先展示）

## 常见异常及解决方案

| 异常原因 | 处理建议 |
|-|-|
| 无参考价 | 转 VC 后积累销售数据，后续再尝试 |
| 不符合亚马逊利润要求 | 积累 VC 销售数据、提升产品动销后重新提报 |

## 高频问题速答

### VC 的 BD 节奏怎么安排？

- 普通时段两次间隔≥14 天，大促前后≥30 天，确保系统抓取 MSRP 为参考价，活动时长可自行调节

### 正在运行的 BD 能取消吗？

- 可以，需整组取消（暂无法删除单个 ASIN），建议单个 ASIN 提报

### Funding 为什么不是MSRP的 10%？

- 亚马逊按产品价格曲线、动销情况计算，额外部分为 additional funding（不可控）

### BD 进度条能取消吗？

- 不能

### BD 数量能增加吗？

- 开跑前可增加，Running 状态不可编辑

### DF 的 BD 库存耗完，PO 会续跑吗？

- 会

### 断货后补货，活动会继续吗？

- 会

### 无 Deal 标志仅显示划线价 / Deal Price，会扣 Funding 吗？

- 会，亚马逊不承担该损失
