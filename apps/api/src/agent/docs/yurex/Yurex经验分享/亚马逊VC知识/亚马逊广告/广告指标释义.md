# 飞书文档：广告指标释义

## 广告指标释义

- **曝光量（Impressions）：**广告展示给用户的次数，反映广告的可见性。
- **点击次数（Clicks）：**用户点击广告的次数，表示用户对广告的兴趣。
- **每次点击费用（CPC）：**用户点击广告时支付的费用，反映广告的成本效益。
- **点击率（CTR）：**点击次数与曝光量的比率，衡量广告的吸引力。
- **转化率（CR）：**点击广告后完成购买的用户比例，反映广告的有效性。
- **广告销售额（Sales）**：通过广告产生的销售总额，衡量广告的直接收益。
- **广告支出（Spend）：**在广告上花费的总金额，帮助评估广告投资回报率。
- **广告订单（Orders）：**广告订单（出单不一定是打广告的产品），比如点了产品①的广告，但是下了产品②的订单，也算产品①的广告订单（SB广告orders需在广告报表查看）
- **广告成本销售比（ACOS）：**广告支出与销售额的比率，衡量广告的盈利能力。Acos=Spend/Sales \*100%
- **广告支出回报（ROAS）：**即总收入除以广告成本得到的结果。一个健康的ROAS表明您的广告投资正在产生正向回报。ROAS=Sales/Spend
- **New-to-brand (NTB) orders：**品牌新客订单
- **% of orders new-to-brand (NTB)：**品牌新客订单量占比
- **New-to-brand (NTB) sales：**品牌新客订单销售额
- **% of sales new-to-brand (NTB)：**品牌新客订单销售额占比
