### 2.4 ASIN 配置注意事项/失败原因
#### A. 注意事项
⚫ 配置以ASIN为单位，即便多个站点有不同的SKU，ASIN号相同则只需配置一次，可选择
方便识别的SKU填写。后续按照ASIN维度请求代码，即便是不同的店铺/站点/SKU发货，
都按照对应ASIN号来一物一码应用Transparency透明计划二维码。
#### B. 配置失败原因（视频讲解）
当您使用电子表格模板配置ASIN，上传后任务状态出现“失败”字样，说明配置失败，请单击
