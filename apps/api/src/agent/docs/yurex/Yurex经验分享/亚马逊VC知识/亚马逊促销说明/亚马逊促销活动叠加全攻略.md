## 促销叠加规则

- 叠加优先级：LD/BD > 会员专享折扣
- 会员专享折扣：LD/BD 开始前 2 小时被禁止显示，结束后最早 1 小时恢复生
- 互斥规则：LD/BD/PD 不可同时提报
- 计算逻辑：先算固定折扣（LD/BD/PD/ 会员专享），再叠加 Coupon
